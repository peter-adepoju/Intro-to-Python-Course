How this course works

This page explains the plan, how long it really takes, and how to get the most out of every day. Read it once before Day 1, and again whenever you feel stuck or slow.

The honest timeline

Going from never having coded to real mastery of Python takes a lot of practice. This course plans it as 104 weeks: 576 lesson days of about three hours each, six days a week. That's roughly 1,700 hours of focused work, plus the projects you'll build. The final phase takes you as far as a course can: a large capstone, real open-source contributions (including to CPython itself) and interview practice.

PhaseWeeksYou'll be able to
1. Foundations1–13Write programs with input, decisions, loops, functions, lists, dictionaries and files.
2. Thinking like a programmer14–27Solve problems methodically; use recursion; analyse algorithms; use Git, the shell, tests and the standard library.
3. Objects and design28–40Design programs with classes, Python's data model, type hints, design principles and patterns.
4. Data structures and algorithms41–58Build every core data structure yourself and solve interview-level algorithm problems.
5. Advanced Python59–71Understand generators, decorators, the memory model, metaclasses, CPython internals, performance and concurrency.
6. Professional engineering72–86Ship tested, packaged, secure software with databases, web APIs and system design; use Python for data and ML.
7. Mastery87–104Lead a large project, contribute to open source, and pass demanding technical interviews.

If you can only manage an hour or two a day, follow the same order at half the speed. That's completely fine. What matters is that you practise most days and never move on from something you don't understand.

A day, step by step

  1. Review (10 minutes). Open Daily review and answer the cards that are due.
  2. Warm-up. Each lesson opens with a few predictions about yesterday's ideas.
  3. Learn. Read a section, play with its figure, run and X-ray its examples. Change the examples and run them again.
  4. Practise. Do every exercise. Use hints. Look at a solution only after a real attempt, and then type it out yourself rather than copying.
  5. Quiz and challenge. The quiz shows what you've really understood. The challenge stretches you.
  6. Reflect. Answer the "Before you go" questions in your own words, out loud or on paper.

Each lesson shows a suggested three-hour plan at the top. Take breaks: 50 minutes of focus and 10 minutes away from the screen works well for most people.

The tools on every page

Run
Runs the code in the box. Ctrl + Enter does the same. If the program asks for input, type it at the yellow cursor.
X-ray
Steps through the program one line at a time. The yellow line is about to run; the pale line just ran. On the right you see every name and the object it points at; new or changed things are outlined in yellow. Use it whenever code surprises you.
Check my answer
Runs hidden tests against your code and tells you which pass, and what went wrong in the ones that don't.
Predict
Some boxes ask you to type what you expect before running. Do it honestly, wrong predictions are the most useful ones.
Ask the tutor
An AI tutor that can see the lesson you're on and the code or error you're stuck on. It gives hints and asks questions first; ask it for more if you need it.
Colab notebook
Each day has a Google Colab notebook with the same code, for practising in a real notebook environment.

How to learn faster

  • Type, don't paste. Typing code builds the habit in your fingers and makes you notice details.
  • Predict before you run. Every time. It turns reading into thinking.
  • Break things on purpose. Remove a bracket, misspell a name, divide by zero. Learn what each error looks like while you know what caused it.
  • Explain it. If you can explain a concept in plain words, you understand it. If you can't, that's what to review.
  • Struggle a little, not a lot. Twenty minutes stuck on one exercise is useful; two hours isn't. Take a hint, ask the tutor, or come back tomorrow.
  • Rest. Memory is built while you sleep and while you're away from the problem. Rest days are part of the course.

Questions

Do I need to install anything?
No. Python runs in your browser. From Week 22 you'll also set up Python on your own computer, because professionals need to.
Do I need an account?
No. Everything works without one, and progress is saved in your browser. An account keeps it safe and the same on every device, and unlocks the tutor.
I'm behind the schedule.
The schedule is a guide, not a deadline. Days and weeks have no dates, so you can start, pause and pick up again at any time.
Can I skip ahead?
You can open any day that's ready. But every week builds on the ones before it; skipping usually costs more time later than it saves now.
