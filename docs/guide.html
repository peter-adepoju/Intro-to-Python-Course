A day, step by step

Each lesson shows its own plan at the top. Most look like this:

  1. Review 10 min

    Answer the cards due in Daily review.

  2. Warm-up 15 min

    A few predictions about yesterday's ideas.

  3. Learn about 95 min

    Read a section, play with its figure, run and X-ray its examples, then change them and run again.

  4. Practise about 45 min

    Do every exercise. Use hints. Look at a solution only after a real attempt, then type it out yourself.

  5. Quiz and challenge 10 min

    The quiz shows what you really understood. The challenge stretches you.

  6. Reflect 5 min

    Answer "Before you go" in your own words, out loud or on paper.

Take breaks: 50 minutes of focus and 10 minutes away from the screen works well for most people.

The tools on every page

Run

Runs the code in the box. Ctrl + Enter does the same. If the program asks for input, type it at the yellow cursor.

X-ray

Steps through a program one line at a time. The yellow line is about to run. On the right, every name and the value it points at, with changes outlined.

Check my answer

Runs hidden tests on your code and shows which pass, and what went wrong in the ones that don't.

Predict

Some boxes ask what you expect before you run. Answer honestly: wrong predictions teach the most.

Ask the tutor

An AI tutor that sees your lesson and the code or error you share. It gives hints and asks questions first. Needs an account.

Colab notebook

Every day has a Google Colab notebook with the same code, for practising in a real notebook.

How to learn faster

  1. Type, don't paste

    Typing builds the habit in your fingers and makes you notice details.

  2. Predict before you run

    Every time. It turns reading into thinking.

  3. Break things on purpose

    Remove a bracket, misspell a name, divide by zero. Learn each error while you know its cause.

  4. Explain it

    If you can explain an idea in plain words, you understand it. If you can't, that's what to review.

  5. Struggle a little, not a lot

    Twenty minutes stuck is useful; two hours isn't. Take a hint, ask the tutor, or come back tomorrow.

  6. Rest

    Memory is built while you sleep and while you're away from the problem. Rest days are part of the course.

Questions

Do I need to install anything?
No. Python runs in your browser. In Week 22 you'll also set up Python on your own computer, so you can work the same way outside the course.
Do I need an account?
No. Everything works without one, and progress is saved in your browser. An account keeps it safe and the same on every device, and unlocks the tutor.
I'm behind the schedule.
The schedule is a guide, not a deadline. Days and weeks have no dates, so you can start, pause and pick up again at any time.
Can I skip ahead?
You can open any day that's ready. But every week builds on the ones before it, and skipping usually costs more time later than it saves now.
What is a Forge day?
Day 6 of most weeks. Instead of new ideas, it brings the week together: a bigger challenge, a weekly quiz and a review of everything so far.
