Week 11, Day 3

CSV files

CSV (comma-separated values) is the most common format for tables of data: every spreadsheet program can open and save it, and most data you’ll download comes in it. It looks simple enough to split on commas, but real CSV files have commas inside quoted fields and other surprises. Today you’ll use the csv module, which handles all of that, to read and write tables as lists and as dictionaries.

By the end of today you can

  • Explain the CSV format, including quoted fields, and why split(",") isn’t enough
  • Read rows with csv.reader, and records with csv.DictReader
  • Convert fields from text to numbers as you read them
  • Write rows with csv.writer and records with csv.DictWriter, opening files with newline=""
  • Read a table, change it, and write it back out

The CSV format

A CSV file is a text file holding a table:

  • each line is one row;
  • fields are separated by commas;
  • the first row is usually a header with the column names;
  • a field containing a comma, a quote or a newline is wrapped in double quotes, and a quote inside it is doubled: "She said ""hi""".

Everything in a CSV file is text. The file doesn’t say that 93 is a number; your program decides that.

Tip

Open students.csv in the box above and compare it with what the programs below print. Then try saving any spreadsheet as CSV on your own computer and opening it in a text editor: it’s the same format.

Writing

Rows with csv.writer

csv.writer writes lists as rows, adding commas and quotes wherever they’re needed:

writerow(row) writes one row; writerows(rows) writes them all. Numbers are turned into text for you. Check the output: the field with a comma was quoted, and the quotes inside said "hi" were doubled. Writing CSV by joining strings with commas gets this wrong.

Records with csv.DictWriter

csv.DictWriter writes dictionaries. You tell it the column names, in order, with fieldnames, and write the header with writeheader():

Common mistake

Without newline="" when writing, some systems (Windows in particular) put an extra blank line between the rows. Use it every time you open a CSV file, for reading or writing.

Other separators

Some “CSV” files use semicolons or tabs instead of commas (common in countries where the comma is the decimal point). Tell the reader and writer with delimiter:

csv.reader(f, delimiter=";")
csv.writer(f, delimiter="\t")
