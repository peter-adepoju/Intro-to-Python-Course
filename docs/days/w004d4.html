Week 4, Day 4

Loop patterns

Experienced programmers don’t invent each loop from nothing. They recognise the job, say “that’s a find-first” or “that’s a best-so-far”, and write the pattern they’ve written a hundred times. Today you’ll learn the ten patterns that cover most loops you’ll ever write, and practise spotting which one a problem needs.

By the end of today you can

  • Name and write the ten common loop patterns, from accumulate to compare-with-previous
  • Choose the right pattern for a problem described in words
  • Track the position of the best value as well as the value itself
  • Write all-of and any-of checks with flags, and know which way round the flag starts
  • Combine two patterns in one loop

Warm-up

That loop does two jobs at once: it accumulates a total and keeps the best so far. Both are patterns you’ve already used. Today they get names, along with eight more.

Why name patterns?

When you read “count the words that start with a capital”, you could stare at a blank screen. Or you could think: count (a counter that goes up), and filter (only some items). Two patterns you know, joined together. Naming patterns turns a new problem into a combination of old ones.

Each pattern below has three parts: what you set up before the loop, what you do inside, and what you have after.

1. Accumulate

Combine every item into one result.

Start with 0 for sums, 1 for products, "" for strings.

2. Count

Count the items that pass a test. It’s accumulate, adding 1 at a time.

3. Filter

Keep only the items that pass a test, building a new result.

4. Transform

Change every item, building a new result. No test, or a test that chooses between two changes.

5. Find first

Stop at the first item that passes a test. Afterwards, you need to know whether one was found.

6. All of

Is every item OK? Start by assuming yes, and look for one that isn’t. One failure is enough to decide, so you can break.

Are all the characters letters?

7. Any of

Is at least one item OK? Start by assuming no, and look for one that is. One success is enough to decide.

Is there at least one digit?
Key idea

All of starts True and looks for a failure. Any of starts False and looks for a success. Neither ever sets the flag back the other way inside the loop.

The flag that flips back

A common bug in an all-of check is an else that sets the flag back to True. Then only the last item decides the answer:

ok = True
for ch in "ab3d":
    if ch.isalpha():
        ok = True      # wrong: this undoes an earlier failure
    else:
        ok = False

Here ok ends up True because the last character, d, is a letter, even though 3 isn’t.

8. Best so far

Find the largest or smallest. Start with the first item, and replace the record whenever it’s beaten. Often you also want where the best was, so keep its position too:

The latest letter in the alphabet, and its position

Should a tie replace the record? With >, the first of several equal bests is kept. With >=, the last one is. Decide on purpose.

9. Running total

Print (or keep) the total so far at every step, not just the final one. Bank statements and scoreboards do this.

A running balance

10. Compare with the previous

Each item is compared with the one before it: is it bigger, the same, part of a run? Keep the previous item in a variable, and update it at the end of each pass.

How many times does the temperature rise?

When the items are in a string, you can use positions instead, comparing s[i] with s[i - 1] for i from 1, as you did yesterday with neighbours.

Choosing and combining

Here are some problems and the patterns they need:

Problem Patterns
Average of the readings accumulate + count
Is this word a valid code (only capitals and digits)? all of
Where is the first space? find first
How long is the longest run of the same letter? compare with previous + best so far
Remove the vowels and count what’s removed filter + count
Does the password contain a symbol? any of

Several patterns can share one loop. Each keeps its own variables, set up before the loop:

Three patterns, one loop
Tip

Before writing a loop, say the pattern names out loud. Then write the before lines for each one first. Most loop bugs are a missing or misplaced “before” line.

Practice

Exercise10 points
Name the patterns

For each problem, choose the pattern it mainly needs: "accumulate", "count", "filter", "transform", "find first", "all of", "any of", "best so far", "running total" or "previous".

  1. Does the sentence contain any question marks?
  2. Turn every letter of a word into its code number, separated by spaces.
  3. What’s the highest mark in the class?
  4. Is every character in the PIN a digit?
  5. Where is the first capital letter?
  6. Print the score after each round of a game.
Exercise10 points
Shouting?

Ask for a message with the prompt Message:. It’s shouting if every letter in it is a capital (ignore non-letters) and it has at least one letter. Print Shouting: True or Shouting: False.

Exercise10 points
Where is the biggest digit?

Ask for a string of digits with the prompt Digits: and print Biggest: and the largest digit, then First at position: and the position of its first appearance.

Exercise10 points
Running score

A game has rounds. Read each round’s points with the prompt Points: until a blank line, printing Total: and the total so far after each round. Finally print Rounds: and the number of rounds.

Exercise15 points
Longest run

Ask for a string with the prompt Text: and print Longest run: and the length of the longest run of one character repeated. aabbbbcc has a longest run of 4. Empty text has a longest run of 0.

Exercise15 points
First repeated letter

Ask for a word with the prompt Word: and print the first letter that appears for the second time as you read from left to right, like First repeat: l for hello. If no letter repeats, print No repeats.

Exercise10 points
Count the words

Ask for a sentence with the prompt Sentence: and print Words: and the number of words. Words are separated by one or more spaces, and there may be spaces at the start or end.

What do they print?

Work out each answer without running anything.

# A
best = "m"
for ch in "python":
    if ch < best:
        best = ch
print(best)

# B
s = ""
for ch in "a1b2c3":
    if ch.isdigit():
        s = ch + s
print(s)

# C
prev = ""
count = 0
for ch in "aaabbaa":
    if ch != prev:
        count += 1
    prev = ch
print(count)
