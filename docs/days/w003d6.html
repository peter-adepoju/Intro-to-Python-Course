Exercise50 points
Forge: the cash machine

A cash machine starts with a balance of 5,000. It shows a menu and keeps going until the customer quits.

The menu. Each time round, print the balance and ask for a choice exactly like this:

Balance: 5,000
d = deposit, w = withdraw, q = quit
Choice:

Deposit (d). Ask Amount:. Keep asking, printing Whole numbers above 0 only each time, until the answer is a whole number above 0. Then add it to the balance.

Withdraw (w). Ask Amount: with the same check as a deposit. Then:

  • if it’s not a multiple of 500, print Notes are 500 each and go back to the menu;
  • if it’s more than the balance, print Not enough money and go back to the menu;
  • otherwise take it from the balance.

Quit (q). Print Deposits: and the number of successful deposits, Withdrawals: and the number of successful withdrawals, then Goodbye, and stop.

Anything else. Print Unknown choice and show the menu again.

Compare with last week’s Forge

Last week, every “stop” in the ticket machine meant one more level of nesting. This week continue and break let you deal with the odd cases early and keep the main path flat. Look at how deep your cash machine goes, and whether continue could flatten it further.

Forge bonus: the computer guesses

Exercise30 points
Forge bonus: the computer guesses your number

Now the computer guesses. The player thinks of a number from 1 to 100. The computer always guesses the middle of the range still possible (rounding down), and the player answers h (my number is higher), l (lower) or c (correct).

Print Is it 50? as the prompt for the first guess, and so on. When the answer is c, print Got it in and the number of guesses. If the answers contradict each other so that no number is left, print You're cheating! and stop.

Is it 50? h
Is it 75? l
Is it 62? c
Got it in 3

That strategy is binary search: every guess halves what’s left, so even 1 to 1,000,000 never needs more than 20 guesses. You’ll study it properly in Week 17.
