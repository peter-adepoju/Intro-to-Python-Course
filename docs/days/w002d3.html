if and else

Until today, every line of every program ran, top to bottom, every time. Today that changes. With if and else your program asks a question and runs different lines depending on the answer. You’ll also meet indentation, the way Python knows which lines belong to which choice.

  • Predict which lines run for a given input, and confirm it with X-ray
  • Make sure a variable gets a value whichever branch runs
  • Write short choices as a conditional expression, a if condition else b

The parts of an if statement:

if age >= 18:
    print("You can vote.")
  1. The word if.
  2. A condition: any expression Python can treat as true or false. Everything you learned this week fits here.
  3. A colon :. It means “here comes the part that depends on this”.
  4. An indented block: one or more lines, each pushed in by 4 spaces. These run only when the condition is true.

The line after the block, print("Thanks for checking."), is back at the left edge. That’s how Python knows the block has ended, so it runs whatever the answer was.

Key idea

Python runs an if block only when its condition is true. Otherwise it skips the whole block and carries on with the first line after it.

else: one or the other

Often you want one thing when the answer is yes and something else when it’s no. That’s else:

else has no condition of its own: it means “if the condition above was false”. It lines up with its if, ends with a colon, and has its own indented block. Exactly one of the two blocks runs, every time.

Indentation is part of the language

In most languages, indentation is just for looks. In Python it’s how you say which lines belong to which block. The standard is 4 spaces per level; the editors on this site insert them for you when you press Tab or Enter after a colon.

Tip

Every line in a block must start at exactly the same column. If an error mentions indentation, look at the left edge of the reported line and the line above it.

Any condition will do

The condition can be anything from the last two days: a comparison, a combination with and and or, a bool variable, or any value at all, which Python treats by its truthiness.

A bool variable as the condition
Truthiness: an empty string is false

if name: reads as “if there is a name”. Python treats the empty string as false.

Common mistake
