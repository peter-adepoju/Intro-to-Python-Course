How this course works

Welcome. This course takes you from never having written a line of code to real mastery of Python. It’s a long road, and the only way along it is to write a lot of code. So every day here is built around one thing: a Python console right in the page, where you type code, run it and watch what it does.

Every grey box with line numbers like the one below is a real Python console. It runs in your browser: nothing to install, nothing to set up. Try it now: press Run.

Your very first run

That’s it: you’ve run a Python program. Now try three things in that same box:

  1. Change the words between the quotes to your own name, and press Run again. (Or press Ctrl + Enter.)
  2. Press X-ray. The X-ray steps through the program one line at a time and shows you what Python is doing. The yellow line is always the line that is about to run. You’ll see this yellow pointer everywhere in this course: it always means “Python is here now”.
  3. Press Reset to get the original code back. You can’t break anything.

You’ll meet five kinds of boxes:

Box What you do
Example Run it, change it, X-ray it. Play.
Predict Write down what you think will be printed before running. Then compare. This is the fastest way to build a picture of Python in your head.
Exercise Write code to solve a task, then press Check my answer. Hidden checks test your program and tell you what’s wrong.
Bug hunt Code with a mistake in it. Find it and fix it.
Puzzle Put scrambled lines of code in the right order.
The habit that makes this work

Before you run anything, say (or write) what you expect it to do. Then run it. If you were right, your picture of Python is getting sharper. If you were wrong, you’ve just found the exact spot where your picture needs fixing. That’s the most valuable moment in learning to code.

What is a computer?

A computer is a machine that follows instructions very fast and very exactly. It doesn’t understand anything. It doesn’t guess what you meant. It does exactly what it’s told, billions of times a second.

Inside, there are two parts you need to know about today:

  • Memory (also called RAM): a long row of numbered cells. Each cell holds a number. Your programs and all their data live here while they run.
  • The processor (CPU): the part that does the work. It repeats one cycle forever: fetch the next instruction from memory, decode what it means, execute it. Then on to the next.

A special counter inside the processor, the program counter, remembers which cell holds the next instruction. Step through this toy computer and watch it work. The yellow arrow is the program counter.

Think about it

In the counting program, how does the computer know when to stop? Find the instruction that decides.

Real processors work the same way, just with thousands of kinds of instruction and billions of steps per second. When you write Python, you never write LOAD or STORE yourself. Python turns your code into instructions like these for you.

Everything is numbers

Memory cells only hold numbers. So how does a computer store text, pictures and music? It stores numbers that stand for them, and it agrees on a code for what each number means.

Inside the machine, each number is made of bits: tiny switches that are either off (0) or on (1). Eight bits make a byte. Each switch is worth double the one to its right: 1, 2, 4, 8, 16, 32, 64, 128. Add up the switches that are on and you get the number.

The same eight switches can mean the number 65 or the letter A. What decides? The type of the data: whether the program treats it as a number or as text. You’ll meet types properly tomorrow. For now, remember this: the computer only stores numbers; types tell it how to read them.

What is a program?

A program is a list of instructions for a computer, written in a language the computer (with some help) can follow. A programming language is a language designed for writing those instructions precisely, with no room for misunderstanding.

Python is a programming language. It was created by Guido van Rossum and first released in 1991. It’s designed to be easy to read, which makes it a great first language, and it’s also one of the most used languages in the world: for websites, science, data, artificial intelligence, automation, games and more. Learning Python well opens a huge number of doors.

When you press Run, a program called the Python interpreter reads your code and carries it out. You write text; the interpreter does the rest. Here’s what it actually does with your text, step by step, this figure is calculated live by real Python:

You don’t need to understand the syntax tree or the bytecode yet. We’ll come back to them in Phase 5, when you study how Python works inside. Today, take away two ideas:

  1. Python first reads all your code. If any of it breaks the grammar rules, it stops before running anything and reports a SyntaxError.
  2. Then it runs your code, one instruction at a time, from top to bottom.

Your first program: print

The print() function shows something on the screen. Let’s take one line apart. Click each coloured part:

The text between the quotes is printed exactly as it is: spaces, punctuation, capital letters and all.

You can use single quotes or double quotes. Both make a string. Pick one style and stick to it; this course uses double quotes.

Each print() starts on a new line. A program with three print() lines prints three lines.

print() with nothing inside prints an empty line. That’s handy for spacing out your output.

Printing numbers

Numbers don’t need quotes. And if you give print() a calculation, Python works it out first and prints the answer.

Did you predict the last line? "2 + 3" is in quotes, so it’s text. Python prints it exactly as written and doesn’t calculate anything. Quotes change everything.

Common mistake

print(hello) without quotes doesn’t print the word hello. Without quotes, Python thinks hello is the name of something, looks for it, can’t find it and reports a NameError. When you mean text, use quotes.

Printing several things at once

You can give print() several things, separated by commas. It prints them all on one line with a single space between each.

Notice that Python added the spaces for you. On Day 6 you’ll learn how to control exactly what goes between the items.

Comments

A comment is a note for humans. It starts with #, and Python ignores everything from the # to the end of the line.

Use comments to explain why your code does something. Programmers also “comment out” lines to switch them off for a moment while testing, as in the last line above.

Code runs from top to bottom

Python runs your program one line at a time, from the first line to the last, in order. Use X-ray on this program and watch the yellow pointer move down. Watch the “Printed so far” box grow as each line runs.

Watch the order

This sounds obvious. But “Python does exactly one thing at a time, in order” is the most important idea in all of programming, and every confusing bug you’ll ever meet is easier once you trace it line by line like this.

Errors are clues, not failures

You will see errors. Every programmer sees them every day, experts included. An error message is Python telling you exactly what went wrong and where. Learning to read errors is one of the most valuable skills you’ll build.

Pick a broken program below. Then click each part of the real error to learn how to read it.

Run this one. Read the error, then fix it.

Fix me

When you see an error:

  1. Read the last line first: the error type and message.
  2. Look at the line number. Go to that line. If it looks fine, check the line before it.
  3. Fix one thing, run again. Repeat.

The console on this site adds a plain-English explanation under each error, and you can always press Ask the tutor about this error.

Before you go

Take two minutes to write, in your own words (on paper or in the playground):

  1. What does the processor do with the instructions in memory?
  2. Why does print("2 + 3") print something different from print(2 + 3)?
  3. What’s the first thing you look at when you see an error?

Explaining something in your own words is how you find out whether you really understand it. Tomorrow you’ll learn the different kinds of values Python works with, and you’ll start using Python as a very powerful calculator.
