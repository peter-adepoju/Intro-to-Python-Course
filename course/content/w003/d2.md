## Warm-up

:::predict
n = 1
while n <= 4:
    print(n * n, end=" ")
    n += 1
:::

The loop *printed* each square, then forgot it. What if you wanted their **total**? Then each pass has to add its square to something that survives from one pass to the next.

## The accumulator pattern

An **accumulator** is a variable that collects a result as the loop runs. It always has the same shape:

```python
total = 0              # 1. start it before the loop, at a neutral value
n = 1
while n <= 4:
    total += n * n     # 2. add this pass's contribution
    n += 1
print(total)           # 3. use it after the loop
```

Watch it grow. Predict each row before you reveal it:

:::widget tracetable caption="total collects one square per pass. It starts at 0 because adding 0 changes nothing."
{"code": "total = 0\nn = 1\nwhile n <= 4:\n    total += n * n\n    n += 1\nprint(total)"}
:::

The **starting value** matters. For a sum, start at `0`, because adding 0 changes nothing. For a product, start at `1`, because multiplying by 1 changes nothing:

:::example title="A running product: 5 factorial"
product = 1
n = 1
while n <= 5:
    product *= n
    n += 1
print(product)
:::

`5 × 4 × 3 × 2 × 1` is written **5!** and called "5 factorial". It counts the ways to put 5 things in order: 120.

:::mistake title="Resetting inside the loop"
If you put `total = 0` inside the loop, it starts again from zero on every pass, and you're left with only the last value. Accumulators are created **before** the loop.
:::

:::example title="The bug, so you recognise it"
n = 1
while n <= 4:
    total = 0
    total += n
    n += 1
print(total)
:::

### Counting is accumulating 1

A count is an accumulator that adds 1 whenever something happens. You did this yesterday with multiples of 7. Several accumulators can run in the same loop:

:::example title="Sum and count of the even numbers"
total = 0
count = 0
n = 1
while n <= 10:
    if n % 2 == 0:
        total += n
        count += 1
    n += 1
print("Even numbers:", count, "Sum:", total)
:::

### Accumulating a string

`+` joins strings, so a string can be an accumulator too. Start with the empty string `""`:

:::example title="Build a row of numbers"
row = ""
n = 1
while n <= 5:
    row += str(n) + "-"
    n += 1
print(row)
:::

Strings are a natural thing to walk through with a counter, since you can index them:

:::example title="Reverse a word, letter by letter"
word = "stressed"
backwards = ""
i = 0
while i < len(word):
    backwards = word[i] + backwards
    i += 1
print(backwards)
:::

Each letter is put at the **front** of what's been built so far, so the first letter ends up last. (You know a shortcut, `word[::-1]`, but building it yourself is how you learn the pattern.)

## The best so far: maximum and minimum

To find the largest value, keep a variable holding **the largest seen so far**, and replace it whenever something bigger turns up:

:::example title="Largest of four readings"
r1, r2, r3, r4 = 23, 31, 18, 35
largest = r1
if r2 > largest:
    largest = r2
if r3 > largest:
    largest = r3
if r4 > largest:
    largest = r4
print(largest)
:::

Every value gets the same treatment: compare it with the record, and replace the record if it's beaten. With four separate variables you have to write that out four times. With values arriving one at a time in a loop, you write it once, as you'll see in a moment. (Lists, in Week 8, let you loop over stored values too.)

:::key
Start a "best so far" variable with the **first** value, not with 0. If every value is negative, a maximum that starts at 0 would wrongly report 0.
:::

## Reading until the user says stop

Often you don't know how many values are coming. The user keeps typing, and a special value, called a **sentinel**, means "that's all". The cleanest shape uses a **priming read**: read the first value before the loop, and the next one at the end of the body.

:::example title="Add up numbers until 0" try=5,10,20,0
total = 0
n = int(input("Number (0 to stop): "))
while n != 0:
    total += n
    n = int(input("Number (0 to stop): "))
print("Total:", total)
:::

Trace why this works:

- The first read happens before the condition is ever checked, so the condition has something to test.
- Inside the loop, the value is **used first**, then the next value is read.
- When the sentinel arrives, the condition is checked straight away, and the sentinel is never added.

If the user types `0` first, the body never runs and the total is 0. Press X-ray and try it.

:::example title="The average of numbers until a blank line" try=12,15,9,
total = 0
count = 0
text = input("Mark (blank to stop): ")
while text != "":
    total += int(text)
    count += 1
    text = input("Mark (blank to stop): ")
if count > 0:
    print("Average:", total / count)
else:
    print("No marks entered")
:::

An empty line is a good sentinel for text. Notice the guard after the loop: if nothing was entered, `total / count` would divide by zero.

### Largest of the numbers typed

Now "best so far" works naturally. The first value starts the record:

:::example try=7,3,12,5,0
n = int(input("Number (0 to stop): "))
largest = n
while n != 0:
    if n > largest:
        largest = n
    n = int(input("Number (0 to stop): "))
print("Largest:", largest)
:::

## Keep asking until it's valid

Last week a bad answer could only be rejected. With a loop, you can **ask again**:

:::example title="Ask until it's in range" try=150,-3,42
age = int(input("Age (0-120): "))
while age < 0 or age > 120:
    print("That isn't a sensible age.")
    age = int(input("Age (0-120): "))
print("Thank you. Age:", age)
:::

It's the same priming-read shape: read once, then loop **while the answer is bad**. When the loop ends, you know the value is good.

Combine it with `.isdigit()` from last week, and nothing the user types can crash it:

:::example title="Crash-proof" try=abc,,12
text = input("Quantity: ")
while not text.isdigit():
    print("Please type a whole number.")
    text = input("Quantity: ")
quantity = int(text)
print("Quantity:", quantity)
:::

### A limited number of tries

Some things should only let you try a few times, like a PIN. The loop needs two reasons to stop, so the condition joins them with `and`:

:::example title="Three tries" try=1111,2222,1234
PIN = "1234"
tries = 0
entered = input("PIN: ")
tries += 1
while entered != PIN and tries < 3:
    print("Wrong PIN.")
    entered = input("PIN: ")
    tries += 1
if entered == PIN:
    print("Welcome.")
else:
    print("Card blocked.")
:::

When the loop stops, you don't know which reason stopped it, so the `if` afterwards checks. This is a very common shape: a loop with two exit conditions, followed by a test of which one happened.

:::exercise id=challenge points=25 title="Challenge: the till receipt"
Write a till. Read item prices, which may have decimals, with the prompt `Price: ` until a blank line. Ignore (and don't count) any line that isn't a valid price: print `Not a price, ignored` for those. A valid price here is digits with at most one full stop, such as `350` or `12.5`. Then print:


@@starter

@@tests
def test_normal():
    "three items"
    p = "Price: "
    expect_output(f"{p}350\n{p}1200\n{p}312.5\n{p}\nItems: 3\nTotal: 1,862.50\nMost expensive: 1,200.00", inputs=["350", "1200", "312.5", ""], echo=True)
def test_bad():
    "ignores bad lines"
    p = "Price: "
    expect_output(f"{p}abc\nNot a price, ignored\n{p}10\n{p}1.2.3\nNot a price, ignored\n{p}2.5\n{p}\nItems: 2\nTotal: 12.50\nMost expensive: 10.00", inputs=["abc", "10", "1.2.3", "2.5", ""], echo=True)
def test_empty():
    "no items"
    expect_output("Price: \nItems: 0", inputs=[""], echo=True)
@@hint
A valid price: remove one full stop with `text.replace(".", "", 1)`, and what's left must be all digits.
@@hint
Keep three accumulators: count, total and the most expensive so far. Since prices are never negative, the most expensive can start at 0 here.
@@solution
count = 0
total = 0
dearest = 0
text = input("Price: ")
while text != "":
    if text.replace(".", "", 1).isdigit():
        price = float(text)
        count += 1
        total += price
        if price > dearest:
            dearest = price
    else:
        print("Not a price, ignored")
    text = input("Price: ")
print("Items:", count)
if count > 0:
    print(f"Total: {total:,.2f}")
    print(f"Most expensive: {dearest:,.2f}")
:::
