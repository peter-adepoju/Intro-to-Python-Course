for line in text.splitlines():
    name, mark = line.split(",")
    print(name, int(mark) + 1)

That string is exactly what a small file looks like inside: lines of characters, each ended by `"\n"`. Today the text comes from a real file instead of a string in your code.

## What a text file is

A **text file** is a sequence of characters stored on a disk, with a name like `marks.txt`. There is nothing special about lines: a line is just the characters up to a newline character, `"\n"`. Most text files end with a newline after the last line too.

Here are the files the programs on this page use. In a real project they'd be in the same folder as your program. Here, every program starts with a fresh copy, so you can't damage them:

:::files
=== marks.txt
Ada,93
Bo,41
Cy,78
Di,55
=== poem.txt
The woods are lovely, dark and deep,
But I have promises to keep,
And miles to go before I sleep,
And miles to go before I sleep.
=== numbers.txt
12
7
30

18
=== server.log
INFO start
WARN disk 81%
INFO request /home
ERROR timeout /shop
INFO request /about
ERROR timeout /home
:::

(The poem is the last verse of Robert Frost's "Stopping by Woods on a Snowy Evening", from 1923.)

## Opening and closing

To use a file, you **open** it, which gives you a **file object**. You read from the file object, then **close** it:

:::example
f = open("poem.txt")
text = f.read()
f.close()
print(text)
:::

`open("poem.txt")` looks for the file in the **current folder**, the folder the program is running in. `f.read()` reads the whole file into one string. `f.close()` tells the operating system you've finished, so it can free what it set aside.

Forgetting `close`, or crashing before you reach it, leaves the file open. For reading that's usually harmless; for writing (tomorrow) it can lose data. So Python has a statement that closes the file for you, however the block ends:

:::example
with open("poem.txt") as f:
    text = f.read()
print(len(text), "characters")
print(f.closed)
:::

`with open(...) as f:` opens the file and names it `f`. When the indented block ends, normally or with an error, the file is closed. Notice `text` is still there after the block: only the file is closed.

:::key
Always open files with `with open(name) as f:`. Do the reading inside the block, keep the results in variables, and work with them after.
:::

### Encodings

A file stores **bytes**, and an **encoding** says how to turn bytes into characters. Almost every text file today uses **UTF-8**, which can store every alphabet and emoji. Python usually assumes UTF-8, but on some computers (older Windows set-ups in particular) it assumes something else, and names like "Adébáyọ̀" come out garbled. To be safe, say so:

```
with open("names.txt", encoding="utf-8") as f:
```

The examples on this site are short; in your own programs, write `encoding="utf-8"`.

## Ways to read

There are four ways to read a text file. Try them on a real file, and watch the red position marker:

:::widget fileread caption="Each button runs that read on a real file. The red bar is where the next read starts. Try read() twice, or readline() three times then read()."
:::

### The whole file: read()

`f.read()` gives the whole file as one string, newlines included. It's simplest for small files.

:::example
with open("marks.txt") as f:
    text = f.read()
print(repr(text))
print(text.splitlines())
:::

`text.splitlines()` splits it into lines **without** the newline characters, which is often what you want.

### One line: readline()

`f.readline()` gives the next line, **including** its `"\n"`. At the end of the file it gives `""`.

:::example
with open("marks.txt") as f:
    first = f.readline()
    second = f.readline()
print(repr(first), repr(second))
:::

### All lines as a list: readlines()

`f.readlines()` gives a list of every line, each still ending in `"\n"`.

:::example
with open("marks.txt") as f:
    lines = f.readlines()
print(lines)
:::

### Loop over the file

The most common way of all: a file object can be looped over directly, one line at a time:

:::example
with open("marks.txt") as f:
    for line in f:
        print(repr(line))
:::

This reads only one line at a time, so it works even for a file far bigger than your computer's memory.

### Removing the newline

Every line from `readline`, `readlines` or a `for` loop ends in `"\n"`. Print it and you get a blank line between lines, because `print` adds its own newline:

:::example
with open("marks.txt") as f:
    for line in f:
        print(line)
:::

So the first thing to do with a line is usually `line.strip()` (or `line.rstrip("\n")` if spaces at the ends matter):

:::example
with open("marks.txt") as f:
    for line in f:
        line = line.strip()
        print(line)
:::

:::mistake
Comparing a line straight from a file to a string usually fails: `"Ada,93\n" == "Ada,93"` is `False`. Strip first.
:::

## The file position

A file object remembers a **position**: where the next read will start. Each read moves it forward. Once it reaches the end, every read gives an empty result:

:::example
with open("marks.txt") as f:
    first = f.read()
    second = f.read()
print(len(first), repr(second))
:::

That's why a file can only be looped over once. Just like a `zip` from Week 9, it's used up:

:::example
with open("marks.txt") as f:
    count = 0
    for line in f:
        count += 1
    total = 0
    for line in f:
        total += 1
print(count, total)
:::

If you need the lines more than once, read them into a list first (`lines = f.read().splitlines()`), then use the list as often as you like.

## Processing line by line

Almost every file program has the same shape: open, loop over the lines, strip and split each one, and do something with the pieces. All the patterns from earlier weeks still work:

:::example title="Totals and the best"
total = 0
best_name, best_mark = "", -1
with open("marks.txt") as f:
    for line in f:
        name, mark = line.strip().split(",")
        mark = int(mark)
        total += mark
        if mark > best_mark:
            best_name, best_mark = name, mark
print("Total:", total)
print("Best:", best_name, best_mark)
:::

:::example title="Count by kind"
from collections import Counter
with open("server.log") as f:
    levels = Counter(line.split()[0] for line in f)
print(levels)
:::

### Blank lines

Real files often have blank lines, especially at the end. `int("")` fails, so skip them:

:::example
total = 0
with open("numbers.txt") as f:
    for line in f:
        line = line.strip()
        if not line:
            continue
        total += int(line)
print(total)
:::

### A file that isn't there

Opening a file that doesn't exist raises `FileNotFoundError`. You'll learn to handle it gracefully on Day 4.

:::example error=yes
with open("results.txt") as f:
    print(f.read())
:::

The message names the file Python looked for. When this happens in your own projects, check the spelling, and check which folder your program is running in.

:::exercise id=total points=10 title="Add them up"
Write `file_total(name)` that returns the sum of the numbers in a file with one number per line, skipping blank lines.
@@starter

@@tests
def test_values():
    "several files"

    write_file("more.txt", "1.5\n\n2.5\n")

Use `float` so that decimals work. `float("12")` is 12.0, and `12.0 == 12` is `True`.
@@solution
def file_total(name):
    total = 0
    with open(name) as f:
        for line in f:
            line = line.strip()
            if line:
                total += float(line)
    return total

:::exercise id=errors_only points=10 title="Just the errors"
Write `errors(name)` that returns a list of the lines of a log file that start with `ERROR`, without their newlines.
@@starter

@@tests
def test_values():
    "the log"
    assert errors("server.log") == ["ERROR timeout /shop", "ERROR timeout /home"]
    write_file("quiet.log", "INFO a\nINFO b\n")
    assert errors("quiet.log") == []
@@solution
def errors(name):
    found = []
    with open(name) as f:
        for line in f:
            if line.startswith("ERROR"):
                found.append(line.rstrip("\n"))
    return found

:::exercise id=to_dict points=10 title="Into a dictionary"
Write `load_marks(name)` that reads a file of `name,mark` lines into a dictionary from name to mark (an int).
@@starter

@@tests
def test_values():
    "the marks"
    assert load_marks("marks.txt") == {"Ada": 93, "Bo": 41, "Cy": 78, "Di": 55}
    write_file("x.txt", "Zed,1\n\n")
    assert load_marks("x.txt") == {"Zed": 1}
@@solution
def load_marks(name):
    marks = {}
    with open(name) as f:
        for line in f:
            line = line.strip()
            if line:
                person, mark = line.split(",")
                marks[person] = int(mark)
    return marks
:::

:::exercise id=longest points=10 title="The longest line"
Write `longest_line(name)` that returns the longest line of a file (without its newline). If several are equally long, return the first. Return `""` for an empty file.
@@starter

@@tests
def test_values():
    "several files"
    assert longest_line("poem.txt") == "The woods are lovely, dark and deep,"
    write_file("t.txt", "ab\ncd\nx\n")

@@solution
def longest_line(name):
    best = ""
    with open(name) as f:
        for line in f:
            line = line.rstrip("\n")
            if len(line) > len(best):
                best = line
    return best

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: word count, like wc"
Unix systems have a tiny program called `wc` that counts lines, words and characters in files. Write `wc(names)` that takes a list of file names and returns a report: one line per file with the line, word and character counts each right-aligned in 7, then a space and the name, and, if there's more than one file, a final `total` line.

For example, `wc(["marks.txt", "poem.txt"])` returns:

```
      4      4     25 marks.txt
      4     27    130 poem.txt
      8     31    155 total
```

Count lines as the number of newline characters (like `wc` does) and characters with `len` of the whole text.
@@starter

@@tests
def ref(names):
    rows, tl, tw, tc = [], 0, 0, 0
    for n in names:
        with open(n) as f:
            t = f.read()
        l, w, c = t.count("\n"), len(t.split()), len(t)
        tl += l; tw += w; tc += c
        rows.append(f"{l:>7}{w:>7}{c:>7} {n}")
    if len(names) > 1:
        rows.append(f"{tl:>7}{tw:>7}{tc:>7} total")
    return "\n".join(rows)
def test_two():
    "two files"
    names = ["marks.txt", "poem.txt"]
    assert wc(names) == ref(names), "Expected:\n" + ref(names)
def test_one():
    "one file, no total"
    assert wc(["server.log"]) == ref(["server.log"]), "Expected:\n" + ref(["server.log"])
def test_odd():
    "no final newline"
    write_file("odd.txt", "no newline at the end")
    assert wc(["odd.txt", "numbers.txt"]) == ref(["odd.txt", "numbers.txt"])
@@hint
Read each file whole with `f.read()`. `text.count("\n")` gives the lines, `len(text.split())` the words.
@@solution
def wc(names):
    rows = []
    totals = [0, 0, 0]
    for name in names:
        with open(name) as f:
            text = f.read()
        counts = [text.count("\n"), len(text.split()), len(text)]
        totals = [t + c for t, c in zip(totals, counts)]
        rows.append("".join(f"{c:>7}" for c in counts) + " " + name)
    if len(names) > 1:
        rows.append("".join(f"{t:>7}" for t in totals) + " total")
    return "\n".join(rows)
:::
