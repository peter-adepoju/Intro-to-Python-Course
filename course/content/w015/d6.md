## Mixed review

:::exercise id=mix_pal points=10 title="Palindromic numbers"
Write `is_pal_number(n)` that checks, recursively, whether a whole number of 0 or more reads the same backwards, working on its digits as a string.
@@starter

@@tests
def test_values():
    "several"
    assert [is_pal_number(n) for n in (0, 7, 11, 121, 123, 1221, 12321, 10)] == [True, True, True, True, False, True, True, False]
    assert "[::-1]" not in source and "for " not in source and "while " not in source
@@solution
def is_pal_number(n):
    return _pal(str(n))

def _pal(s):
    if len(s) < 2:
        return True
    return s[0] == s[-1] and _pal(s[1:-1])
:::

:::exercise id=mix_merge points=10 title="Merge, recursively"
Write `merge(a, b)` that merges two sorted lists into one sorted list, recursively: the smaller of the two first items comes first, followed by the merge of what's left.
@@starter

@@tests
def test_values():
    "several"
    assert merge([1, 4, 9], [2, 3, 10]) == [1, 2, 3, 4, 9, 10]
    assert merge([], [1]) == [1] and merge([2], []) == [2] and merge([], []) == []
    assert "sort" not in source and "for " not in source and "while " not in source
@@solution
def merge(a, b):
    if not a:
        return b
    if not b:
        return a
    if a[0] <= b[0]:
        return [a[0]] + merge(a[1:], b)
    return [b[0]] + merge(a, b[1:])
:::

:::exercise id=mix_keys points=10 title="All the keys"
Write `all_keys(data)` that returns a sorted list of every distinct dictionary key anywhere inside nested dictionaries and lists.
@@starter

@@tests
def test_values():
    "several"
    d = {"a": 1, "b": [{"c": 2}, {"a": 3, "d": {"e": []}}]}
    assert all_keys(d) == ["a", "b", "c", "d", "e"]
    assert all_keys([1, 2]) == [] and all_keys({}) == []
@@solution
def all_keys(data):
    return sorted(_keys(data))

def _keys(data):
    found = set()
    if isinstance(data, dict):
        for k, v in data.items():
            found.add(k)
            found |= _keys(v)
    elif isinstance(data, list):
        for item in data:
            found |= _keys(item)
    return found
:::

def last_digit_sum(n):
    while n >= 10:
        n = sum(int(d) for d in str(n))

## Forge: a folder explorer

A folder is a dictionary from names to entries: a file's entry is its size in bytes (an int), and a sub-folder's entry is another dictionary of the same kind. Here's the folder used in the checks:

```
project = {
    "README.md": 1200,
    "src": {
        "main.py": 5400,
        "utils": {"text.py": 2100, "maths.py": 3300, "__pycache__": {}},
        "data.csv": 48000,
    },
    "tests": {"test_main.py": 1800},
    "build": {"tmp": {}, "logs": {}},
}
```

:::exercise id=forge points=50 title="Forge: a folder explorer"
Write these recursive functions. All of them take a folder dictionary and none of them change it.

1. `size(folder)`: the total size of every file inside, at any depth.
2. `find(folder, suffix)`: a sorted list of the paths of every file whose name ends with `suffix`, written from the top like `src/utils/text.py`.
3. `largest_folder(folder)`: the `(path, size)` of the sub-folder (at any depth, not counting the top folder itself) with the biggest total size. Ties go to the path that comes first alphabetically. `None` if there are no sub-folders.
4. `prune(folder)`: a **new** folder with every empty sub-folder removed, including folders that only become empty once their own empty sub-folders are removed.
5. `tree(folder)`: the folder drawn as lines of text, like the `tree` command. Entries are shown in alphabetical order; each sub-folder's name ends with `/`; each line is prefixed with `├── ` for every entry but the last at that level and `└── ` for the last; and under an entry, deeper lines are indented with `│   ` if that entry wasn't the last, or four spaces if it was. It returns the lines as a list.

For `project`, `tree` gives:

```
├── README.md
├── build/
│   ├── logs/
│   └── tmp/
├── src/
│   ├── data.csv
│   ├── main.py
│   └── utils/
│       ├── __pycache__/
│       ├── maths.py
│       └── text.py
└── tests/
    └── test_main.py
```
@@starter

@@tests
import copy
PROJECT = {
    "README.md": 1200,
    "src": {"main.py": 5400, "utils": {"text.py": 2100, "maths.py": 3300, "__pycache__": {}}, "data.csv": 48000},
    "tests": {"test_main.py": 1800},
    "build": {"tmp": {}, "logs": {}},
}
TREE = """├── README.md
├── build/
│   ├── logs/
│   └── tmp/
├── src/
│   ├── data.csv
│   ├── main.py
│   └── utils/
│       ├── __pycache__/
│       ├── maths.py
│       └── text.py
└── tests/
    └── test_main.py""".split("\n")
def test_size():
    "size"
    assert size(PROJECT) == 61800 and size({}) == 0 and size({"a": {"b": {"c": 5}}}) == 5
def test_find():
    "find"
    assert find(PROJECT, ".py") == ["src/main.py", "src/utils/maths.py", "src/utils/text.py", "tests/test_main.py"]
    assert find(PROJECT, ".md") == ["README.md"] and find(PROJECT, ".zip") == []
def test_largest():
    "largest_folder"
    assert largest_folder(PROJECT) == ("src", 58800)
    assert largest_folder({"a.txt": 3}) is None
    assert largest_folder({"x": {"f": 1}, "a": {"g": 1}}) == ("a", 1)
def test_prune():
    "prune"
    before = copy.deepcopy(PROJECT)
    p = prune(PROJECT)
    assert PROJECT == before, "prune changed the original"
    assert "build" not in p and "__pycache__" not in p["src"]["utils"] and p["src"]["main.py"] == 5400
    assert prune({"a": {"b": {"c": {}}}, "f": 1}) == {"f": 1}
def test_tree():
    "tree"
    got = tree(PROJECT)
    assert got == TREE, "Expected:\n" + "\n".join(TREE) + "\n\nGot:\n" + "\n".join(got)
    assert tree({}) == []
@@hint
For `find` and `largest_folder`, give your function (or a helper) a `path` parameter for "where am I?", and join names with `/` (no `/` before the first name).
@@hint
`largest_folder`: for each sub-folder, the candidates are the sub-folder itself, `(path, size(sub))`, and whatever `largest_folder` finds inside it. Compare with a key such as `(size, reversed alphabetical)`, or keep the best by hand: bigger size wins, equal size goes to the smaller path.
@@hint
`tree`: a helper `lines(folder, prefix)` loops over the sorted names. The connector is `"└── "` for the last name and `"├── "` otherwise. For a sub-folder, the lines inside it come from `lines(sub, prefix + ("    " if last else "│   "))`.
@@solution
def size(folder):
    total = 0
    for entry in folder.values():
        total += size(entry) if isinstance(entry, dict) else entry
    return total

def _join(path, name):
    return f"{path}/{name}" if path else name

def find(folder, suffix, path=""):
    found = []
    for name, entry in folder.items():
        full = _join(path, name)
        if isinstance(entry, dict):
            found += find(entry, suffix, full)
        elif name.endswith(suffix):
            found.append(full)
    return sorted(found)

def largest_folder(folder, path=""):
    best = None
    for name, entry in folder.items():
        if not isinstance(entry, dict):
            continue
        full = _join(path, name)
        for candidate in ((full, size(entry)), largest_folder(entry, full)):
            if candidate is None:
                continue
            if best is None or candidate[1] > best[1] or (candidate[1] == best[1] and candidate[0] < best[0]):
                best = candidate
    return best

def prune(folder):
    result = {}
    for name, entry in folder.items():
        if isinstance(entry, dict):
            inner = prune(entry)
            if inner:
                result[name] = inner
        else:
            result[name] = entry
    return result

def tree(folder, prefix=""):
    lines = []
    names = sorted(folder)
    for i, name in enumerate(names):
        last = i == len(names) - 1
        entry = folder[name]
        lines.append(prefix + ("└── " if last else "├── ") + name + ("/" if isinstance(entry, dict) else ""))
        if isinstance(entry, dict):
            lines += tree(entry, prefix + ("    " if last else "│   "))
    return lines
:::

:::think title="Five functions, one shape"
Look at your five functions side by side. Every one loops over the entries of one folder and, for each sub-folder, makes the **same** recursive call on it. What differs is only what each one does with a file, and how it combines the results. `find` and `tree` pass information **down** (the path, the prefix); `size` and `largest_folder` pass results **up**; `prune` builds a new tree on the way up. Once you see that shape, every new question about a tree is a small variation.
:::

## Forge bonus: expression trees

When Python reads `1 + 2 * 3`, it first builds a **tree**: a `+` whose left side is `1` and whose right side is a `*` of `2` and `3`. Then it works out the value recursively, from the leaves up. Here's that tree written as nested lists, operator first: `["+", 1, ["*", 2, 3]]`.

:::exercise id=forge2 points=30 title="Forge bonus: expression trees"
An expression is either a number, or a list `[op, left, right]` where `op` is one of `+ - * /` and `left` and `right` are expressions. Write:

- `evaluate(expr)`: its value (`/` is ordinary division);
- `to_text(expr)`: the expression as text with every operation in brackets: `["+", 1, ["*", 2, 3]]` gives `"(1 + (2 * 3))"`; a number on its own is just the number;
- `count_ops(expr)`: how many operations it contains;
- `depth(expr)`: the number of levels of operations (a number on its own has depth 0).

Raise a `ValueError` with the message `unknown operator: '^'` (or whatever the operator is) in `evaluate` for an operator that isn't one of the four.
@@starter

@@tests
E = ["-", ["*", ["+", 1, 2], 4], ["/", 9, 3]]
def test_evaluate():
    "evaluate"
    assert evaluate(7) == 7 and evaluate(["+", 1, ["*", 2, 3]]) == 7 and evaluate(E) == 9
    try:
        evaluate(["^", 2, 3])
    except ValueError as e:
        assert str(e) == "unknown operator: '^'"
    else:
        raise AssertionError("an unknown operator should raise a ValueError")
def test_text():
    "to_text"
    assert to_text(5) == "5" and to_text(["+", 1, ["*", 2, 3]]) == "(1 + (2 * 3))"
    assert to_text(E) == "(((1 + 2) * 4) - (9 / 3))"
def test_shape():
    "count_ops and depth"
    assert count_ops(5) == 0 and count_ops(E) == 4
    assert depth(5) == 0 and depth(["+", 1, 2]) == 1 and depth(E) == 3
def test_matches_python():
    "agrees with Python"
    assert evaluate(E) == eval(to_text(E))
@@hint
Every function starts the same way: if `expr` isn't a list, it's a number (the base case). Otherwise unpack it: `op, left, right = expr`, and recurse on `left` and `right`.
@@solution
OPS = {"+": lambda a, b: a + b, "-": lambda a, b: a - b, "*": lambda a, b: a * b, "/": lambda a, b: a / b}

def evaluate(expr):
    if not isinstance(expr, list):
        return expr
    op, left, right = expr
    if op not in OPS:
        raise ValueError(f"unknown operator: {op!r}")
    return OPS[op](evaluate(left), evaluate(right))

def to_text(expr):
    if not isinstance(expr, list):
        return str(expr)
    op, left, right = expr
    return f"({to_text(left)} {op} {to_text(right)})"

def count_ops(expr):
    if not isinstance(expr, list):
        return 0
    return 1 + count_ops(expr[1]) + count_ops(expr[2])

def depth(expr):
    if not isinstance(expr, list):
        return 0
    return 1 + max(depth(expr[1]), depth(expr[2]))
:::
