def grid_paths(r, c):
    table = [[1] * c for _ in range(r)]
    for i in range(1, r):
        for j in range(1, c):
            table[i][j] = table[i - 1][j] + table[i][j - 1]
    return table[r - 1][c - 1]

space = "O(r*c)"

## Forge: make it fast

A school has asked for help. Its data scripts work on a class of 30, but take hours on the whole district's records. Here are the five slow functions, all correct:

```
def shared_students(club_a, club_b):
    """Names in both clubs, in the order of club_a."""
    return [name for name in club_a if name in club_b]

def first_unrepeated(text):
    """The first character that appears exactly once, or None."""
    for ch in text:
        if text.count(ch) == 1:
            return ch
    return None

def has_gap(scores, d):
    """Do any two scores differ by exactly d (d > 0)?"""
    for a in scores:
        for b in scores:
            if b - a == d:
                return True
    return False

def range_totals(values, queries):
    """For each (start, end) in queries, the total of values[start:end]."""
    return [sum(values[s:e]) for s, e in queries]

def most_common_pair(names):
    """The pair of neighbouring names (a, b) that appears most often in
    the list, the alphabetically first if tied; None if fewer than 2 names."""
    pairs = [(names[i], names[i + 1]) for i in range(len(names) - 1)]
    if not pairs:
        return None
    best = None
    for p in pairs:
        if best is None or pairs.count(p) > pairs.count(best) or \
           (pairs.count(p) == pairs.count(best) and p < best):
            best = p
    return best
```

@@hint
`shared_students`: make a set of `club_b`. `first_unrepeated`: count every character in a dictionary first, then go through the text again. `has_gap`: a set of the scores, then check `a + d in scores_set` for each `a`.
@@hint
`range_totals`: `prefix[i]` is the total of the first `i` values, so `prefix[0] = 0` and the total of `values[s:e]` is `prefix[e] - prefix[s]`. Note that `range_totals` is O(n × q) before because each slice and sum can be O(n) long.
@@hint
`most_common_pair`: count the pairs in a dictionary in one pass, find the highest count, then take the smallest pair with that count. That's O(n). Each `pairs.count` in the slow version is O(n), and it's called up to 4 times for each of the n pairs.
@@solution
def shared_students(club_a, club_b):
    in_b = set(club_b)
    return [name for name in club_a if name in in_b]

def first_unrepeated(text):
    counts = {}
    for ch in text:
        counts[ch] = counts.get(ch, 0) + 1
    for ch in text:
        if counts[ch] == 1:
            return ch
    return None

def has_gap(scores, d):
    present = set(scores)
    return any(a + d in present for a in scores)

def range_totals(values, queries):
    prefix = [0]
    for v in values:
        prefix.append(prefix[-1] + v)
    return [prefix[e] - prefix[s] for s, e in queries]

def most_common_pair(names):
    counts = {}
    for p in zip(names, names[1:]):
        counts[p] = counts.get(p, 0) + 1
    if not counts:
        return None
    top = max(counts.values())
    return min(p for p, c in counts.items() if c == top)

analysis = {
    "shared_students": ("O(n*m)", "O(n + m)"),
    "first_unrepeated": ("O(n^2)", "O(n)"),
    "has_gap": ("O(n^2)", "O(n)"),
    "range_totals": ("O(n*q)", "O(n + q)"),
    "most_common_pair": ("O(n^2)", "O(n)"),
}
:::

:::think title="The same three tricks"
Look at what made each function fast. Three ideas did nearly all the work: **a set or dictionary** to replace a search through a list (`in`, `count`); **precomputing** once what was being recomputed every time (the counts, the running totals); and **sorting first** when order makes the answer easy to find. Most everyday speed-ups are one of these three. Each one spends O(n) memory to save time, a trade you'll make again and again.
:::

## Forge bonus: counting inversions

An **inversion** in a list is a pair of positions `i < j` where `items[i] > items[j]`: two items in the wrong order. A sorted list has 0; a list sorted backwards has the most, n(n − 1)/2. Counting inversions measures how far from sorted a list is, and it's used to compare rankings: two people's top-10 films, say, or a search engine's results against what users clicked.

Checking every pair is O(n²). Divide and conquer does it in O(n log n): split the list in half, count the inversions inside each half recursively, and while **merging** the two sorted halves, count the inversions that cross between them. When the merge takes an item from the right half, it jumps ahead of every item still waiting in the left half, and each of those is one inversion.

@@hint
In the merge, when `left[i] <= right[j]` take `left[i]`; otherwise take `right[j]` and add `len(left) - i` to the count, because every item still waiting in the left half is bigger than it. The total is the left count plus the right count plus the crossing count. Using `<=` means equal items aren't counted as inversions.
@@hint
For `similarity`, make a dictionary of each item's position in `ranking_b`, then build `[where_b[x] for x in ranking_a]` and count its inversions.
@@solution
def inversions_slow(items):
    count = 0
    for i in range(len(items)):
        for j in range(i + 1, len(items)):
            if items[i] > items[j]:
                count += 1
    return count

def sort_and_count(items):
    if len(items) <= 1:
        return list(items), 0
    mid = len(items) // 2
    left, a = sort_and_count(items[:mid])
    right, b = sort_and_count(items[mid:])
    merged = []
    crossing = 0
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            merged.append(left[i])
            i += 1
        else:
            merged.append(right[j])
            crossing += len(left) - i
            j += 1
    merged += left[i:] + right[j:]
    return merged, a + b + crossing

def inversions(items):
    return sort_and_count(items)[1]

def similarity(ranking_a, ranking_b):
    where_b = {x: i for i, x in enumerate(ranking_b)}
    return inversions([where_b[x] for x in ranking_a])
