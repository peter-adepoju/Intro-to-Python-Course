## Mixed review

:::exercise id=mix_refactor points=10 title="Break it into functions"
This program works, but it's one long block. Rewrite it with two functions, `is_palindrome(word)` returning `True` or `False` (ignoring case), and `count_palindromes(text)` returning how many words in the text are palindromes. Keep the output the same.
@@starter
text = input("Text: ")
count = 0
for word in text.split():
    w = word.lower()
    if w == w[::-1]:
        count += 1
print("Palindromes:", count)
@@tests
def test_functions():
    "the two functions"
    assert is_palindrome("Level") and not is_palindrome("python") and is_palindrome("a")
    assert count_palindromes("Anna saw a racecar at noon") == 4
def test_output():
    "same output"
    expect_output("Text: Anna saw a racecar\nPalindromes: 3", inputs=["Anna saw a racecar"], echo=True)
@@solution
def is_palindrome(word):
    """Return True if word reads the same backwards, ignoring case."""
    w = word.lower()
    return w == w[::-1]

def count_palindromes(text):
    """Return how many words in text are palindromes."""
    count = 0
    for word in text.split():
        if is_palindrome(word):
            count += 1
    return count

text = input("Text: ")
print("Palindromes:", count_palindromes(text))
:::

:::exercise id=mix_shift points=10 title="A reusable shift"
Define `shift_letter(ch, k)` that returns a letter shifted `k` places (keeping case; non-letters unchanged), and `caesar(text, k)` that uses it on every character. Then `caesar("Hello, World!", 3)` should return `"Khoor, Zruog!"`.
@@starter

@@tests
def test_letter():
    "shift_letter"
    assert shift_letter("a", 1) == "b" and shift_letter("Z", 1) == "A" and shift_letter("!", 5) == "!" and shift_letter("c", -3) == "z"
def test_text():
    "caesar"
    assert caesar("Hello, World!", 3) == "Khoor, Zruog!"
    assert caesar(caesar("Round trip", 11), -11) == "Round trip"
@@solution
def shift_letter(ch, k):
    """Return ch shifted k places along the alphabet, keeping its case."""
    if "a" <= ch <= "z":
        return chr((ord(ch) - ord("a") + k) % 26 + ord("a"))
    if "A" <= ch <= "Z":
        return chr((ord(ch) - ord("A") + k) % 26 + ord("A"))
    return ch

def caesar(text, k):
    """Return text with every letter shifted k places."""
    out = ""
    for ch in text:
        out += shift_letter(ch, k)
    return out
:::

:::exercise id=mix_plural points=10 title="Plurals"
Define `plural(n, word, suffix="s")` that returns strings like `1 apple`, `3 apples`, `0 apples`, and with a different suffix, `2 boxes` from `plural(2, "box", "es")`.
@@starter

@@tests
def test_values():
    "several counts"
    assert plural(1, "apple") == "1 apple"
    assert plural(3, "apple") == "3 apples"
    assert plural(0, "apple") == "0 apples"
    assert plural(2, "box", "es") == "2 boxes"
    assert plural(1, "box", suffix="es") == "1 box"
@@solution
def plural(n, word, suffix="s"):
    """Return n followed by word, with suffix added unless n is 1."""
    return f"{n} {word}" if n == 1 else f"{n} {word}{suffix}"
:::

:::exercise id=mix_digits points=10 title="Digit tools"
Define `digits(n)` returning the number of digits of a whole number of at least 0 (so `digits(0)` is 1), and `reverse_number(n)` returning the number with its digits reversed (so `reverse_number(1200)` is 21). Use arithmetic, not strings.
@@starter

@@tests
def test_values():
    "both functions"
    for n, d, r in [(0, 1, 0), (7, 1, 7), (1200, 4, 21), (98765, 5, 56789)]:
        assert digits(n) == d, f"digits({n}) should be {d}."
        assert reverse_number(n) == r, f"reverse_number({n}) should be {r}."
    assert "str(" not in source
@@solution
def digits(n):
    """Return how many decimal digits n has. n must be at least 0."""
    count = 1
    while n >= 10:
        n //= 10
        count += 1
    return count

def reverse_number(n):
    """Return n with its decimal digits in reverse order."""
    r = 0
    while n > 0:
        r = r * 10 + n % 10
        n //= 10
    return r

## Forge: the results processor

About an hour. This time the specification tells you **which functions** to write. Write them one at a time, and test each one in the playground or with a quick `print` before moving on. Every function needs a docstring.

:::exercise id=forge points=50 title="Forge: the results processor"
A teacher types a class's results on one line, like `Ada:93, Grace:88, Alan:57, Kemi:41`. Write these functions:

- `parse_entry(entry)` takes one entry like `" Grace:88 "` and returns two values: the name (stripped) and the mark as an int.
- `grade(mark)` returns `"A"` (70 or more), `"B"` (60 to 69), `"C"` (50 to 59) or `"F"`.
- `class_stats(line)` takes the whole line and returns four values: the number of students, the average mark (rounded to 1 decimal place), the highest mark and the number who passed (50 or more).
- `report_line(name, mark, width)` returns one line of the report: the name left-aligned in `width` characters, a space, the mark right-aligned in 3, a space, and the grade.

Then the main program asks `Results: `, prints a report line for each student, with the name column as wide as the longest name, and finally prints `Students: 4  Average: 69.8  Highest: 93  Passed: 3` (two spaces between the parts).

```
Results: Ada:93, Grace:88, Alan:57, Kemi:41
Ada    93 A
Grace  88 A
Alan   57 C
Kemi   41 F
Students: 4  Average: 69.8  Highest: 93  Passed: 3
```

None of your functions may use `global`, and only the main program may print.
@@starter
def parse_entry(entry):
    ___

def grade(mark):
    ___

def class_stats(line):
    ___

def report_line(name, mark, width):
    ___

@@tests
def test_parse():
    "parse_entry"
    assert tuple(parse_entry(" Grace:88 ")) == ("Grace", 88)
    assert tuple(parse_entry("Ada Lovelace:100")) == ("Ada Lovelace", 100)
def test_grade():
    "grade"
    for m, g in [(70, "A"), (69, "B"), (60, "B"), (59, "C"), (50, "C"), (49, "F")]:
        assert grade(m) == g
def test_stats():
    "class_stats"
    assert tuple(class_stats("Ada:93, Grace:88, Alan:57, Kemi:41")) == (4, 69.8, 93, 3)
    assert tuple(class_stats("Solo:50")) == (1, 50.0, 50, 1)
def test_line():
    "report_line"
    assert report_line("Ada", 93, 5) == "Ada    93 A"
    assert report_line("Kemi", 7, 4) == "Kemi   7 F"
def test_output():
    "the whole report"
    expect_output("Results: Ada:93, Grace:88, Alan:57, Kemi:41\nAda    93 A\nGrace  88 A\nAlan   57 C\nKemi   41 F\nStudents: 4  Average: 69.8  Highest: 93  Passed: 3",
                  inputs=["Ada:93, Grace:88, Alan:57, Kemi:41"], echo=True)
def test_style():
    "no global; the functions don't print"
    assert "global" not in source
    for name in ["parse_entry", "grade", "class_stats", "report_line"]:
        start = source.find("def " + name)
        body = source[start:].split("\ndef ")[0]
        body = body.split("\n\n")[0]
        assert "print(" not in body, name + " should return, not print."
@@hint
`parse_entry`: `name, mark = entry.split(":")`, then strip the name and convert the mark.
@@hint
`class_stats`: loop over `line.split(",")`, call `parse_entry` on each, and keep four accumulators. Return them all at the end: `return count, round(total / count, 1), highest, passed`.
@@hint
The main program needs the width before printing, so loop over the entries once to find the longest name, then again to print.
@@solution
def parse_entry(entry):
    """Return the name and the mark from an entry like 'Ada:93'."""
    name, mark = entry.split(":")
    return name.strip(), int(mark)

def grade(mark):
    """Return the letter grade for a mark out of 100."""
    if mark >= 70:
        return "A"
    if mark >= 60:
        return "B"
    if mark >= 50:
        return "C"
    return "F"

def class_stats(line):
    """Return the count, average (1 place), highest mark and number passed."""
    count = 0
    total = 0
    highest = -1
    passed = 0
    for entry in line.split(","):
        name, mark = parse_entry(entry)
        count += 1
        total += mark
        highest = max(highest, mark)
        if mark >= 50:
            passed += 1
    return count, round(total / count, 1), highest, passed

def report_line(name, mark, width):
    """Return one report line: the name, the mark and the grade, aligned."""
    return f"{name:<{width}} {mark:>3} {grade(mark)}"

line = input("Results: ")
width = 0
for entry in line.split(","):
    name, mark = parse_entry(entry)
    width = max(width, len(name))
for entry in line.split(","):
    name, mark = parse_entry(entry)
    print(report_line(name, mark, width))
count, average, highest, passed = class_stats(line)
print(f"Students: {count}  Average: {average}  Highest: {highest}  Passed: {passed}")
:::

:::think title="Why so many functions?"
Each function was small enough to get right on its own, and the checks could test each one separately. If the average had been wrong, you'd have known exactly where to look: `class_stats`, nowhere else. That's the real power of functions: not just less repetition, but problems you can check one piece at a time.
:::

## Forge bonus: numbers in words

:::exercise id=forge2 points=30 title="Forge bonus: numbers in words"
Write `in_words(n)` that returns any whole number from 0 to 999,999 in English words, like a cheque:

- `0` → `zero`, `7` → `seven`, `13` → `thirteen`, `42` → `forty-two`
- `100` → `one hundred`, `305` → `three hundred and five`, `999` → `nine hundred and ninety-nine`
- `1000` → `one thousand`, `1005` → `one thousand and five`, `21400` → `twenty-one thousand four hundred`
- `123456` → `one hundred and twenty-three thousand four hundred and fifty-six`

Build it from helper functions: `under_100(n)` for 0 to 99 (except that 0 isn't needed there), `under_1000(n)` for 1 to 999 using `under_100`, then `in_words` using `under_1000`. British English puts `and` before the last part when it's less than 100 and something comes before it.
@@starter
ONES = "zero one two three four five six seven eight nine ten eleven twelve thirteen fourteen fifteen sixteen seventeen eighteen nineteen".split()
TENS = "_ _ twenty thirty forty fifty sixty seventy eighty ninety".split()

@@tests
O = "zero one two three four five six seven eight nine ten eleven twelve thirteen fourteen fifteen sixteen seventeen eighteen nineteen".split()
T = "_ _ twenty thirty forty fifty sixty seventy eighty ninety".split()
def u100(n):
    return O[n] if n < 20 else T[n // 10] + ("-" + O[n % 10] if n % 10 else "")
def u1000(n):
    h, r = divmod(n, 100)
    if not h:
        return u100(r)
    return O[h] + " hundred" + (" and " + u100(r) if r else "")
def W(n):
    if n == 0:
        return "zero"
    th, r = divmod(n, 1000)
    parts = []
    if th:
        parts.append(u1000(th) + " thousand")
    if r:
        parts.append(("and " if th and r < 100 else "") + u1000(r))
    return " ".join(parts)
def test_small():
    "under 100"
    for n in [0, 7, 13, 19, 20, 42, 90, 99]:
        assert in_words(n) == W(n), f"in_words({n}) should be {W(n)!r}."
def test_hundreds():
    "hundreds"
    for n in [100, 305, 999, 110, 520]:
        assert in_words(n) == W(n), f"in_words({n}) should be {W(n)!r}."
def test_thousands():
    "thousands"
    for n in [1000, 1005, 21400, 123456, 999999, 100001, 7070]:
        assert in_words(n) == W(n), f"in_words({n}) should be {W(n)!r}."
@@hint
`under_100(n)`: below 20, it's `ONES[n]`. Otherwise `TENS[n // 10]`, plus `-` and `ONES[n % 10]` if the last digit isn't 0.
@@hint
`under_1000(n)`: split into hundreds and the rest with `//` and `%`. If there are hundreds, write `ONES[h] + " hundred"`, and add `" and " + under_100(rest)` if the rest isn't 0.
@@hint
`in_words(n)`: split into thousands and the rest. The thousands part is `under_1000(thousands) + " thousand"`. The rest needs an `and` in front only if there were thousands and the rest is under 100.
@@solution
ONES = "zero one two three four five six seven eight nine ten eleven twelve thirteen fourteen fifteen sixteen seventeen eighteen nineteen".split()
TENS = "_ _ twenty thirty forty fifty sixty seventy eighty ninety".split()

def under_100(n):
    """Return n (0 to 99) in words."""
    if n < 20:
        return ONES[n]
    word = TENS[n // 10]
    if n % 10:
        word += "-" + ONES[n % 10]
    return word

def under_1000(n):
    """Return n (1 to 999) in words."""
    hundreds, rest = n // 100, n % 100
    if hundreds == 0:
        return under_100(rest)
    word = ONES[hundreds] + " hundred"
    if rest:
        word += " and " + under_100(rest)
    return word

def in_words(n):
    """Return n (0 to 999,999) in words, British style."""
    if n == 0:
        return "zero"
    thousands, rest = n // 1000, n % 1000
    word = ""
    if thousands:
        word = under_1000(thousands) + " thousand"
    if rest:
        part = under_1000(rest)
        if thousands and rest < 100:
            part = "and " + part
        word = part if word == "" else word + " " + part
    return word
:::

## Weekly quiz

:::quiz id=weekly
- q: When does the body of a function run?
  options: ["When def is reached", "Each time the function is called", "Once, at the end", "Never"]
  answer: 1
  explain: "def only creates the function."
- q: What does this print?
  type: output
  code: |
    def f():
        print("x")
    f
    print("y")
  answer: "y"
  explain: "Without brackets, f isn't called."
- q: Which call matches `def f(a, b=2, c=3)` and gives c the value 9?
  options: ["`f(9)`", "`f(1, 9)`", "`f(1, c=9)`", "`f(c=9)`"]
  answer: 2
  explain: "a is required; name c to skip b."
- q: Which def is a SyntaxError?
  options: ["`def f(a, b=1):`", "`def f(a=1, b):`", "`def f():`"]
  answer: 1
  explain: "Defaults must come last."
- q: What does a function return when it has no return statement?
  type: text
  answer: "None"
  explain: "None means no value."
- q: What does this print?
  type: output
  code: |
    def f(n):
        return n + 1
        return n + 2
    print(f(1))
  answer: "2"
  explain: "The first return ends the function."
- q: What does this print?
  type: output
  code: |
    def f(n):
        n = n * 10
    x = 4
    f(x)
    print(x)
  answer: "4"
  explain: "Reassigning a parameter doesn't change the caller's variable."
- q: 'What error comes from this?'
  code: |
    n = 0
    def inc():
        n = n + 1
    inc()
  type: text
  answer: ["UnboundLocalError", "unbound local error"]
  explain: "n is local in inc because it's assigned there."
- q: In what order does Python look up a name?
  options: ["Local, enclosing, global, built-in", "Built-in, global, local", "Global first"]
  answer: 0
  explain: "LEGB."
- q: What does this print?
  type: output
  code: |
    def mm(a, b):
        return a // b, a % b
    q, r = mm(17, 5)
    print(q, r)
  answer: "3 2"
  explain: "Two values returned and unpacked."
- q: Where does a docstring go?
  options: ["Above def", "First statement in the body", "Last line", "In a comment"]
  answer: 1
  explain: "Otherwise Python doesn't store it."
- q: What does `return n % 2 == 0` return for n = 7?
  type: text
  answer: "False"
  explain: "7 % 2 is 1."
- q: Why prefer return over print in most functions?
  options: ["It's shorter", "The caller can use the value", "print is slow", "Python requires it"]
  answer: 1
  explain: "A printed value can't be used by the program."
- q: How do you show a string result in a doctest example?
  options: ["Without quotes", "With quotes, as repr shows it"]
  answer: 1
  explain: "Doctest compares with what the shell would show."
- q: What does `help(f)` show?
  options: ["f's code", "f's name, parameters and docstring", "Nothing", "f's result"]
  answer: 1
  explain: "Everything a caller needs."
