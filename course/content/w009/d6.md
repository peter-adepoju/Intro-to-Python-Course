def rotate(grid):
    return [list(col) for col in zip(*grid[::-1])]

def spread(values):
    lo, hi = min(values), max(values)
    return lo, hi, hi - lo

def differences(a, b):
    return [(i, x, y) for i, (x, y) in enumerate(zip(a, b)) if x != y]

## Forge: the league table

In most football leagues a win earns **3 points**, a draw **1** and a loss **0**. Teams are ranked by points; teams level on points are separated by **goal difference** (goals scored minus goals conceded), then by **goals scored**. Today you'll build the table from the raw results.

:::exercise id=forge points=50 title="Forge: the league table"
Each result is a line like `Red Stars 2-1 Blue Union`: the home team, the score, the away team. Team names may contain spaces. Write:

- `parse_result(line)` returns a tuple `(home, home_goals, away_goals, away)`, with the names stripped and the goals as ints. The score is the only word made of digits, a `-`, and digits.
- `league(results)` takes a list of such tuples and returns the table as a list of tuples `(team, played, won, drawn, lost, goals_for, goals_against, points)`, sorted by points, then goal difference, then goals for (all highest first), then team name (A to Z).
- `format_table(rows)` returns the table as one string, lines joined with `"\n"`: a header, then one line per team. `Pos` is right-aligned in 3, then a space, the team left-aligned as wide as the longest name or `Team`, then `P`, `W`, `D`, `L` each right-aligned in 3, `GF`, `GA`, `GD` and `Pts` each right-aligned in 4. The goal difference always shows its sign, as in `+4`, `-2` or `+0`.
- The main program reads results with the prompt `Result: ` until an empty line, then prints the table.

For example:

```
Result: Lions 2-0 Tigers
Result: Tigers 1-1 Red Stars
Result: Red Stars 3-1 Lions
Result: Tigers 2-1 Lions
Result:
Pos Team       P  W  D  L  GF  GA  GD Pts
  1 Red Stars  2  1  1  0   4   2  +2   4
  2 Tigers     3  1  1  1   3   4  -1   4
  3 Lions      3  1  0  2   4   5  -1   3
```

You haven't met dictionaries yet, so you'll need another way to find a team's running totals. A list of lists, one per team, with a function that finds (or adds) a team's row, works well.

def ref_parse(line):
    words = line.split()
    for i, w in enumerate(words):
        a, dash, b = w.partition("-")
        if dash and a.isdigit() and b.isdigit():
            return (" ".join(words[:i]), int(a), int(b), " ".join(words[i + 1:]))
def ref_league(results):
    rows = []
    def get(name):
        for r in rows:
            if r[0] == name:
                return r
        r = [name, 0, 0, 0, 0, 0, 0, 0]
        rows.append(r)
        return r
    for h, hg, ag, a in results:
        for me, mine, theirs in ((get(h), hg, ag), (get(a), ag, hg)):
            me[1] += 1; me[5] += mine; me[6] += theirs
            if mine > theirs: me[2] += 1; me[7] += 3
            elif mine == theirs: me[3] += 1; me[7] += 1
            else: me[4] += 1
    return sorted([tuple(r) for r in rows], key=lambda r: (-r[7], -(r[5] - r[6]), -r[5], r[0]))
def ref_format(rows):
    w = max([4] + [len(r[0]) for r in rows])

@@solution
def parse_result(line):
    """Return (home, home_goals, away_goals, away) for one result line."""
    words = line.split()
    for i, word in enumerate(words):
        left, dash, right = word.partition("-")
        if dash and left.isdigit() and right.isdigit():
            return " ".join(words[:i]), int(left), int(right), " ".join(words[i + 1:])

def find(rows, name):
    for row in rows:
        if row[0] == name:
            return row
    row = [name, 0, 0, 0, 0, 0, 0, 0]
    rows.append(row)
    return row

def record(row, scored, conceded):
    row[1] += 1
    row[5] += scored
    row[6] += conceded
    if scored > conceded:
        row[2] += 1
        row[7] += 3
    elif scored == conceded:
        row[3] += 1
        row[7] += 1
    else:
        row[4] += 1

def league(results):
    """Return the sorted table as a list of (team, P, W, D, L, GF, GA, Pts) tuples."""
    rows = []
    for home, home_goals, away_goals, away in results:
        record(find(rows, home), home_goals, away_goals)
        record(find(rows, away), away_goals, home_goals)
    table = [tuple(row) for row in rows]
    return sorted(table, key=lambda r: (-r[7], -(r[5] - r[6]), -r[5], r[0]))

def format_table(rows):
    """Return the table as one string."""
    w = max([len("Team")] + [len(row[0]) for row in rows])
    lines = [f"{'Pos':>3} {'Team':<{w}}{'P':>3}{'W':>3}{'D':>3}{'L':>3}{'GF':>4}{'GA':>4}{'GD':>4}{'Pts':>4}"]
    for pos, (team, p, won, drawn, lost, gf, ga, pts) in enumerate(rows, start=1):
        lines.append(f"{pos:>3} {team:<{w}}{p:>3}{won:>3}{drawn:>3}{lost:>3}{gf:>4}{ga:>4}{gf - ga:>+4}{pts:>4}")
    return "\n".join(lines)

results = []
line = input("Result: ")
while line != "":
    results.append(parse_result(line))
    line = input("Result: ")
print(format_table(league(results)))
:::

:::think title="The slow part"
Every result calls `find` twice, and `find` looks through every team until it finds the right one. With 20 teams that's fine. With 20,000 players in a ranking system it's painfully slow, and the code that searches for a name is clutter. Next week's **dictionaries** look up a name in one step, however many there are, and `find` disappears.
:::

## Forge bonus: the referee

:::exercise id=forge2 points=30 title="Forge bonus: the referee"
A noughts and crosses board of any size `n` is a list of `n` strings, each `n` characters long, using `X`, `O` and `.` for an empty square. A player wins by filling a whole row, column or diagonal.

1. Write `lines(board)` that returns a list of every line on the board as a string: all rows (top to bottom), then all columns (left to right), then the diagonal from top left, then the diagonal from top right. For a 3 by 3 board that's 8 lines.
2. Write `winner(board)` that returns `"X"` or `"O"` if that player has a full line, and `None` if nobody does.
3. Write `status(board)` that returns `"X wins"`, `"O wins"`, `"Draw"` (no winner and no empty squares) or whose turn it is: `"X to play"` or `"O to play"`. X always goes first, so it's X's turn when both players have played the same number of times.

```
board = ["XOX",
         ".XO",
         "..X"]
status(board)  ->  "X wins"
```
@@starter

@@tests
def test_lines():
    "lines"
    b = ["XOX", ".XO", "..X"]
    assert lines(b) == ["XOX", ".XO", "..X", "X..", "OX.", "XOX", "XXX", "XX."]
    assert lines(["A"]) == ["A", "A", "A", "A"]
    assert len(lines(["....", "....", "....", "...."])) == 10
def test_winner():
    "winner"
    assert winner(["XOX", ".XO", "..X"]) == "X"
    assert winner(["OOO", "XX.", "X.."]) == "O"
    assert winner(["XO.", "...", "..."]) is None
    assert winner(["...", "...", "..."]) is None
    assert winner(["O..X", ".O.X", "..OX", "...X"]) == "X"
def test_status():
    "status"
    assert status(["XOX", ".XO", "..X"]) == "X wins"
    assert status(["OOO", "XX.", "X.X"]) == "O wins"
    assert status(["XOX", "XOO", "OXX"]) == "Draw"
    assert status(["...", "...", "..."]) == "X to play"
    assert status(["X..", "...", "..."]) == "O to play"
    assert status(["X..", ".O.", "..."]) == "X to play"
@@hint
The columns are `zip(*board)`, which gives tuples of characters: join each one with `"".join(...)`. The diagonals are `[board[i][i] for i in range(n)]` and `[board[i][n - 1 - i] for i in range(n)]`, joined.
@@hint
A line is a win for a player `p` when it equals `p * n`. In `status`, count the `X`s and `O`s with a generator expression: `sum(row.count("X") for row in board)`.
@@solution
def lines(board):
    n = len(board)
    rows = list(board)
    cols = ["".join(col) for col in zip(*board)]
    down = "".join(board[i][i] for i in range(n))
    up = "".join(board[i][n - 1 - i] for i in range(n))
    return rows + cols + [down, up]

def winner(board):
    n = len(board)
    for line in lines(board):
        for player in ("X", "O"):
            if line == player * n:
                return player
    return None

def status(board):
    w = winner(board)
    if w is not None:
        return f"{w} wins"
    xs = sum(row.count("X") for row in board)
    os = sum(row.count("O") for row in board)
    if xs + os == len(board) ** 2:
        return "Draw"
    return "X to play" if xs == os else "O to play"
:::
