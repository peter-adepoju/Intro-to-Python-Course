## Warm-up

:::predict
print(sorted([10, 9, 100]))
print(sorted(["10", "9", "100"]))
print(sorted(["banana", "Apple", "cherry"]))
:::

The numbers sort by value, but the same digits as **strings** sort letter by letter, so `"100"` comes before `"9"`. And `"Apple"` comes first only because capitals come before lower case. Sorting does exactly what you ask, which isn't always what you mean. Today you'll learn to say what you mean.

## sort, sorted and reverse

A reminder of the two tools:

- `items.sort()` sorts the list **in place** and returns `None`.
- `sorted(items)` returns a **new** sorted list and works on any sequence: lists, strings, ranges, the result of `split`.

Both take `reverse=True` for descending order:

:::example
scores = [72, 95, 64, 88]
print(sorted(scores, reverse=True))
print(sorted("python"))
print("".join(sorted("python")))
:::

## Key functions

A **key function** turns each item into the value that should be compared. Python works out the key once for each item, sorts by the keys, and gives you back the original items in that order.

:::widget sortkey caption="Pick a key, or write your own (x is each item). The table shows the key Python works out for each item. Try a key that makes two items equal, and see which comes first."
{"items": "[\"banana\", \"Fig\", \"apple\", \"Cherry\", \"kiwi\"]"}
:::

You've already used the simple ones:

:::example
words = ["banana", "Fig", "apple", "Cherry", "kiwi"]
print(sorted(words, key=len))
print(sorted(words, key=str.lower))
print(sorted([-5, 3, -1, 4], key=abs))
:::

Any function that takes one item and returns something comparable will do, including a `lambda` or your own `def`:

:::example title="By the last letter"
words = ["banana", "Fig", "apple", "Cherry", "kiwi"]
print(sorted(words, key=lambda w: w[-1]))
:::

### Sorting records

Data often comes as **records**: one item per person or product, each holding several fields. With lists, a record can be a small list, and the key picks a field:

:::example
people = [["Ada", 36, "London"], ["Grace", 85, "New York"], ["Alan", 41, "Manchester"]]
by_age = sorted(people, key=lambda p: p[1])
for name, age, city in by_age:
    print(f"{name:<6}{age:>4}  {city}")
:::

The loop unpacks each record into three names, just as `a, b = 1, 2` unpacks two. (Tomorrow is all about unpacking.)

### A custom order

Some things have an order that isn't alphabetical, like clothes sizes or days of the week. Write the order down as a list, and use each item's **position** in it as the key:

:::example
ORDER = ["XS", "S", "M", "L", "XL"]
stock = ["L", "S", "XL", "M", "S", "XS"]
print(sorted(stock, key=ORDER.index))
:::

`ORDER.index` is a method used as a function: for each size, it gives the size's position in `ORDER`.

## Several keys at once

To sort by one thing, and then by another to break ties, the key can return **a pair of values** in round brackets. Python compares pairs the way it compares words: first items first, and only if those are equal, the second items.

:::example
print((2, "b") < (2, "c"))
print((1, "z") < (2, "a"))
words = ["fig", "apple", "kiwi", "date", "banana", "cherry"]
print(sorted(words, key=lambda w: (len(w), w)))
:::

Words are sorted by length, and words of the same length alphabetically. (These bracketed pairs are **tuples**, tomorrow's topic.)

### Mixing ascending and descending

`reverse=True` reverses the whole order. To sort one key **downwards** and another **upwards**, negate the numeric key:

:::example title="Highest score first; ties in alphabetical order"
results = [["Grace", 88], ["Ada", 93], ["Alan", 88], ["Kemi", 93]]
ranked = sorted(results, key=lambda r: (-r[1], r[0]))
for name, score in ranked:
    print(name, score)
:::

`-r[1]` turns 93 into -93, which sorts before -88, so higher scores come first, while names still sort A to Z.

:::key
A key that returns `(first, second)` sorts by `first`, and by `second` among equals. Negate a number to sort it in the opposite direction.
:::

## Stability

Python's sort is **stable**: items whose keys are equal stay in the order they had before sorting. That gives you a second way to sort by several things. Sort by the **least** important key first, then by the **most** important:

:::example
results = [["Grace", 88], ["Ada", 93], ["Alan", 88], ["Kemi", 93]]
results.sort(key=lambda r: r[0])
results.sort(key=lambda r: r[1], reverse=True)
for name, score in results:
    print(name, score)
:::

The second sort puts the scores in order, and because it's stable, people with equal scores keep the alphabetical order from the first sort. This is exactly what spreadsheets do when you click one column header and then another.

:::tip
A key that returns a pair does the same job in one sort. Use whichever reads more clearly. Sorting several times is handy when the keys go in different directions and can't simply be negated, such as two text fields, one A to Z and the other Z to A.
:::

## Numbers inside text

File names like `photo10.jpg` and `photo9.jpg` sort the "wrong" way as plain strings. A key that pulls out the number fixes it:

:::example
files = ["photo10.jpg", "photo9.jpg", "photo100.jpg", "photo1.jpg"]
print(sorted(files))

def number_in(name):
    digits = ""
    for ch in name:
        if ch.isdigit():
            digits += ch
    return int(digits) if digits else 0

print(sorted(files, key=number_in))
:::

This is called a **natural sort**: the order a person would expect.

def first_number(name):
    digits = ""
    for ch in name:
        if ch.isdigit():
            digits += ch
        elif digits:
            break
    return int(digits) if digits else -1

def natural_sort(names):
    return sorted(names, key=lambda n: (first_number(n), n))

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: ranks with ties"
In a competition, equal scores share a rank, and the next rank skips: scores 95, 90, 90, 85 have ranks 1, 2, 2, 4. This is called **competition ranking**.

Write `rank_table(results)` where each result is `[name, score]`. Return a list of `[rank, name, score]`, sorted by score (highest first) and by name among equal scores, with competition ranks. Then the program reads lines like `Ada 93` with the prompt `> ` until a blank line, and prints the table with the rank right-aligned in 3, a space, the name left-aligned in 10 and the score right-aligned in 4.
@@starter

@@tests
def test_function():
    "rank_table"
    t = rank_table([["Grace", 90], ["Ada", 95], ["Alan", 90], ["Kemi", 85]])
    assert t == [[1, "Ada", 95], [2, "Alan", 90], [2, "Grace", 90], [4, "Kemi", 85]]
    assert rank_table([]) == []
    assert rank_table([["A", 5], ["B", 5], ["C", 5]]) == [[1, "A", 5], [1, "B", 5], [1, "C", 5]]
def test_program():
    "the program"
    want = "> Grace 90\n> Ada 95\n> Alan 90\n> \n  1 Ada         95\n  2 Alan        90\n  2 Grace       90"
    expect_output(want, inputs=["Grace 90", "Ada 95", "Alan 90", ""], echo=True)
@@hint
After sorting, walk through the list with its positions. The rank is the position plus 1, unless the score equals the previous score, in which case it's the previous rank.
@@solution
def rank_table(results):
    ordered = sorted(results, key=lambda r: (-r[1], r[0]))
    table = []
    for i in range(len(ordered)):
        name, score = ordered[i]
        if i > 0 and score == ordered[i - 1][1]:
            rank = table[-1][0]
        else:
            rank = i + 1
        table.append([rank, name, score])
    return table

results = []
while True:
    line = input("> ")
    if line == "":
        break
    name, score = line.split()
    results.append([name, int(score)])
for rank, name, score in rank_table(results):
    print(f"{rank:>3} {name:<10}{score:>4}")
:::
