## Warm-up

:::predict
names = ["Ada", "Grace", "Alan"]
scores = [93, 88, 97]
for i in range(len(names)):
    print(i + 1, names[i], scores[i])
:::

That loop works, but `range(len(names))`, `names[i]` and `scores[i]` are all scaffolding: the loop is really about each **name**, its **number**, and its **score**. Today you'll write it without the scaffolding.

## enumerate: items and their positions

`enumerate(sequence)` gives you each item **together with its position**, as a pair. Unpack the pair in the `for` line:

:::example
names = ["Ada", "Grace", "Alan"]
for i, name in enumerate(names):
    print(i, name)
:::

Positions start at 0. For a numbered list, which people expect to start at 1, give a `start`:

:::example
for n, name in enumerate(["Ada", "Grace", "Alan"], start=1):
    print(f"{n}. {name}")
:::

`enumerate` works on any sequence, strings included:

:::example title="Where are the capitals?"
for i, ch in enumerate("Python Atlas"):
    if ch.isupper():
        print(ch, "at", i)
:::

:::key
`for i, item in enumerate(items):` gives each item with its position. Use it instead of `for i in range(len(items)):` whenever you need both. Note the order: the **position comes first**.
:::

You still use positions directly when you **change** a list in place, or look at a neighbour, but `enumerate` gives you the item as well:

:::example
prices = [100, 250, 80]
for i, p in enumerate(prices):
    prices[i] = p * 2
print(prices)
:::

## zip: several sequences side by side

`zip(a, b)` pairs up the first item of `a` with the first of `b`, the second with the second, and so on:

:::example
names = ["Ada", "Grace", "Alan"]
scores = [93, 88, 97]
for name, score in zip(names, scores):
    print(f"{name:<6}{score:>4}")
:::

It's named after a zip fastener, bringing two sides together tooth by tooth. It works with any number of sequences:

:::example
days = ["Mon", "Tue", "Wed"]
highs = [31, 29, 33]
lows = [24, 23, 25]
for day, hi, lo in zip(days, highs, lows):
    print(day, "range", hi - lo)
:::

### When the lengths differ

`zip` stops as soon as the **shortest** sequence runs out, and says nothing about it:

:::example
print(list(zip([1, 2, 3, 4], ["a", "b"])))
:::

That's handy sometimes, and a silent bug at others, when you expected the lengths to match. In Python 3.10 and later you can write `zip(a, b, strict=True)` to make it raise an error instead. Otherwise, check the lengths yourself when they matter.

:::warn
If two lists should line up but might not, `zip` hides the problem by stopping early. Check `len(a) == len(b)` first, or use `strict=True`.
:::

### Combining enumerate and zip

They combine naturally. The pair from `zip` becomes the item of `enumerate`, so unpack it with brackets:

:::example
names = ["Ada", "Grace", "Alan"]
scores = [93, 88, 97]
for rank, (name, score) in enumerate(zip(names, scores), start=1):
    print(rank, name, score)
:::

## Neighbours, transposing and unzipping

### Neighbours

`zip(items, items[1:])` pairs each item with the next one. It's the neighbour pattern from Week 8, with no indexes at all:

:::example
temps = [21, 23, 22, 25, 30]
for today, tomorrow in zip(temps, temps[1:]):
    print(today, "->", tomorrow, "change", tomorrow - today)
:::

Because `temps[1:]` is one item shorter, `zip` stops at exactly the right place, with no `IndexError` to worry about.

### Transposing with zip(*...)

Remember that a star in a call spreads a list out into separate arguments. `zip(*grid)` passes each **row** as a separate argument, so zip pairs up the first items of every row (column 0), then the second items (column 1), and so on:

:::example
grid = [[1, 2, 3], [4, 5, 6]]
for column in zip(*grid):
    print(column)
transposed = []
for column in zip(*grid):
    transposed.append(list(column))
print(transposed)
:::

The transpose that took nested loops on Day 1 is now one loop.

### Unzipping

The same trick separates a list of pairs back into separate sequences:

:::example
pairs = [("Ada", 93), ("Grace", 88), ("Alan", 97)]
names, scores = zip(*pairs)
print(names)
print(scores)
:::

## Lazy, and used up

Look at what `enumerate` and `zip` give you on their own:

:::example
z = zip([1, 2], ["a", "b"])
print(z)
print(list(z))
print(list(z))
:::

They don't make a list of all the pairs at once. They're **iterators**: objects that produce the next pair only when a loop (or `list`) asks for it. That saves memory when the sequences are long. But an iterator can be used only **once**: after you've gone through it, it's empty. The second `list(z)` gives `[]`.

:::mistake
Don't store a `zip` or `enumerate` and loop over it twice. If you need the pairs again, turn them into a list first (`pairs = list(zip(a, b))`) or call `zip` again.
:::

You'll learn how iterators work, and how to write your own, in Phase 5.

:::exercise id=find_all points=10 title="All the positions"
Write `positions(items, value)` that returns a list of the positions where `value` appears, using `enumerate`.
@@starter

@@tests

def positions(items, value):
    result = []
    for i, item in enumerate(items):
        if item == value:
            result.append(i)

:::exercise id=dot points=10 title="Dot product"
The **dot product** of two lists of numbers of the same length is the sum of the products of their matching items: `[1, 2, 3]` and `[4, 5, 6]` give 1×4 + 2×5 + 3×6 = 32. Write `dot(a, b)` with `zip`. If the lengths differ, return `None`.
@@starter

@@tests
def test_values():
    "several pairs"
    assert dot([1, 2, 3], [4, 5, 6]) == 32
    assert dot([], []) == 0
    assert dot([1, 2], [3]) is None
    assert dot([2.5], [2]) == 5.0
@@solution
def dot(a, b):
    if len(a) != len(b):
        return None
    total = 0
    for x, y in zip(a, b):
        total += x * y
    return total
:::

:::exercise id=changes points=10 title="Biggest rise"
Write `biggest_rise(values)` that returns the largest increase from one value to the next, using `zip(values, values[1:])`. If there are fewer than two values, or no value rises, return 0.
@@starter

@@tests
def test_values():
    "several lists"
    assert biggest_rise([21, 23, 22, 25, 30]) == 5
    assert biggest_rise([5, 4, 3]) == 0
    assert biggest_rise([7]) == 0
    assert biggest_rise([1, 10, 2, 8]) == 9
    assert "zip(" in source
@@solution
def biggest_rise(values):
    best = 0
    for a, b in zip(values, values[1:]):
        if b - a > best:
            best = b - a
    return best
:::

:::exercise id=hamming points=10 title="How different?"
The **Hamming distance** between two strings of the same length is the number of positions where their characters differ. It's used to count errors in transmitted data and mutations in DNA. Write `hamming(a, b)` with `zip`, returning `None` if the lengths differ.
@@starter

@@tests
def test_values():
    "several pairs"
    assert hamming("karolin", "kathrin") == 3
    assert hamming("GATTACA", "GATTACA") == 0
    assert hamming("abc", "ab") is None
    assert hamming("", "") == 0
@@solution
def hamming(a, b):
    if len(a) != len(b):
        return None
    count = 0
    for x, y in zip(a, b):
        if x != y:
            count += 1
    return count
:::

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: a little spreadsheet"
Data often arrives as lines of comma-separated values with a header line. Write `summarise(text)` that takes such text, where every column after the first holds numbers, and returns a report string. For

```
name,maths,english,science
Ada,93,71,88
Grace,88,95,79
Alan,97,62,91
```

it returns:

```
subject   average  best
maths       92.67  Alan
english     76.00  Grace
science     86.00  Alan
```

The subject is left-aligned in 8, the average right-aligned in 9 with 2 places, then two spaces and the name of the student with the highest mark in that subject (the first if tied). Use `zip` to work with the columns.
@@starter

@@tests
def build(text):
    lines = text.strip().splitlines()
    header = lines[0].split(",")
    rows = [l.split(",") for l in lines[1:]]
    names = [r[0] for r in rows]
    out = [f"{'subject':<8}{'average':>9}  best"]
    for j, subject in enumerate(header[1:], start=1):
        col = [float(r[j]) for r in rows]
        best = names[col.index(max(col))]
        out.append(f"{subject:<8}{sum(col) / len(col):>9.2f}  {best}")
    return "\n".join(out)
def test_example():
    "the example"
    t = "name,maths,english,science\nAda,93,71,88\nGrace,88,95,79\nAlan,97,62,91"
    assert summarise(t) == build(t), "Expected:\n" + build(t)
def test_other():
    "another table"
    t = "who,q1,q2\nX,5,5\nY,5,9.5\nZ,1,9.5"
    assert summarise(t) == build(t), "Expected:\n" + build(t)
@@hint
Split the text into lines, the header into subject names, and each other line into a row. `names` is the first item of every row.
@@hint
`zip(*rows)` gives the columns. The first column is the names; pair the others with the subject names using `zip(subjects, columns[1:])`.
@@solution
def summarise(text):
    lines = text.strip().splitlines()
    subjects = lines[0].split(",")[1:]
    rows = []
    for line in lines[1:]:
        rows.append(line.split(","))
    columns = list(zip(*rows))
    names = columns[0]
    report = [f"{'subject':<8}{'average':>9}  best"]
    for subject, column in zip(subjects, columns[1:]):
        marks = []
        for m in column:
            marks.append(float(m))
        best_name = names[marks.index(max(marks))]
        report.append(f"{subject:<8}{sum(marks) / len(marks):>9.2f}  {best_name}")
    return "\n".join(report)
:::
