## Rows and cells

A grid is a list whose items are lists, one per **row**. Writing it out with one row per line shows its shape:

:::example
seats = [
    ["A1", "A2", "A3", "A4"],
    ["B1", "B2", "B3", "B4"],
    ["C1", "C2", "C3", "C4"],
]
print(len(seats), "rows")
print(len(seats[0]), "columns")
print(seats[1])
print(seats[1][2])
:::

`seats[1]` is the whole second row, which is itself a list. `seats[1][2]` takes that row and then its item at position 2. Always **row first, then column**.

Explore the indexes. Click a cell, then choose what to highlight:

:::widget gridviz caption="Each cell shows its value; the row and column numbers are along the edges. Try each view: a row is one inner list, but a column cuts across all of them."
{"rows": 4, "cols": 5, "name": "grid"}
:::

:::key
`grid[r]` is row `r` (an inner list). `grid[r][c]` is the item in row `r`, column `c`. The number of rows is `len(grid)`; the number of columns is `len(grid[0])`.
:::

### Building a grid

You already know the safe way. Each row must be a **separate** list:

:::example
def make_grid(rows, cols, fill=0):
    grid = []
    for _ in range(rows):
        grid.append([fill] * cols)
    return grid

g = make_grid(3, 4)
g[0][0] = 5
print(g)
:::

Grids often come from text: one line per row, with the items separated by spaces:

:::example
text = """1 2 3
4 5 6
7 8 9"""
grid = []
for line in text.splitlines():
    row = []
    for piece in line.split():
        row.append(int(piece))
    grid.append(row)
print(grid)
:::

## Walking through a grid

To visit every cell, use nested loops: the outer one over the rows, the inner one over the items in a row:

:::example title="Every cell, row by row"
grid = [[1, 2, 3], [4, 5, 6]]
total = 0
for row in grid:
    for value in row:
        total += value
print(total)
:::

When you need the positions (to change a cell, or to know where you are), loop over the indexes:

:::example title="Double every cell, in place"
grid = [[1, 2, 3], [4, 5, 6]]
for r in range(len(grid)):
    for c in range(len(grid[r])):
        grid[r][c] *= 2
print(grid)
:::

### Printing a grid neatly

Printing a grid directly shows brackets and commas. To print it as a table, build each row's line and print that:

:::example
grid = [[1, 20, 3], [400, 5, 60]]
for row in grid:
    line = ""
    for value in row:
        line += f"{value:5}"
    print(line)
:::

## Rows, columns and diagonals

A **row** is easy, since it's already a list: `grid[r]`. A **column** is spread across every row, so you collect it:

:::example
grid = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
c = 1
column = []
for row in grid:
    column.append(row[c])
print("Row 0:", grid[0])
print("Column 1:", column)
:::

The **main diagonal** of a square grid runs from top left to bottom right: the cells where the row equals the column. The **other diagonal** runs from top right to bottom left: column `n - 1 - r` in row `r`.

:::example
grid = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
n = len(grid)
main = []
other = []
for i in range(n):
    main.append(grid[i][i])
    other.append(grid[i][n - 1 - i])
print(main, other)
:::

### Transposing

**Transposing** a grid swaps its rows and columns: row 0 becomes column 0. The result has as many rows as the original has columns:

:::example
grid = [[1, 2, 3], [4, 5, 6]]
flipped = []
for c in range(len(grid[0])):
    new_row = []
    for r in range(len(grid)):
        new_row.append(grid[r][c])
    flipped.append(new_row)
print(flipped)
:::

## Neighbours

Many games and simulations need a cell's **neighbours**: the up to 8 cells around it. Loop over the changes in row and column, `dr` and `dc`, each from -1 to 1, skip the cell itself, and skip anything off the edge:

:::example title="Count the X's around a cell"
grid = [
    list("X.X"),
    list(".X."),
    list("XX."),
]

def count_neighbours(grid, r, c, mark="X"):
    count = 0
    for dr in [-1, 0, 1]:
        for dc in [-1, 0, 1]:
            if dr == 0 and dc == 0:
                continue
            nr, nc = r + dr, c + dc
            if 0 <= nr < len(grid) and 0 <= nc < len(grid[0]):
                if grid[nr][nc] == mark:
                    count += 1
    return count

print(count_neighbours(grid, 1, 1))
print(count_neighbours(grid, 0, 0))
:::

:::warn title="Negative indexes don't fail"
Without the bounds check, `grid[-1]` doesn't raise an error: it quietly gives the **last** row. So a cell on the top edge would "see" the bottom row as its neighbour. Always check `0 <= nr < rows` and `0 <= nc < cols` yourself.
:::

:::exercise id=parse_grid points=10 title="Read a grid"

def parse_grid(text):
    grid = []
    for line in text.splitlines():
        row = []
        for piece in line.split():
            row.append(int(piece))
        grid.append(row)
    return grid

:::exercise id=row_sums points=10 title="Row and column totals"
Write `row_totals(grid)` returning a list of the sum of each row, and `column_totals(grid)` returning a list of the sum of each column. All rows have the same length.
@@starter

@@tests

    "row and column totals"

    assert column_totals(g) == [5, 7, 9]

@@solution
def row_totals(grid):
    totals = []
    for row in grid:
        totals.append(sum(row))
    return totals

def column_totals(grid):
    totals = []
    for c in range(len(grid[0])):
        t = 0
        for row in grid:
            t += row[c]
        totals.append(t)
    return totals

@@tests

    result = []

        new_row = []
        for r in range(len(grid)):
            new_row.append(grid[r][c])
        result.append(new_row)
    return result

def winner(board):
    lines = []
    for i in range(3):
        lines.append(board[i])
        lines.append([board[0][i], board[1][i], board[2][i]])
    lines.append([board[0][0], board[1][1], board[2][2]])
    lines.append([board[0][2], board[1][1], board[2][0]])

:::exercise id=neighbours points=15 title="Minesweeper numbers"
In Minesweeper, each empty square shows how many mines touch it. Write `mine_counts(field)` where `field` is a list of strings, like `["*..", "..*", "..."]` (`*` is a mine). Return a new list of strings where every `.` is replaced by the number of mines among its 8 neighbours, and mines stay `*`.
@@starter

@@tests
def test_values():
    "several fields"
    assert mine_counts(["*..", "..*", "..."]) == ["*21", "12*", "011"]
    assert mine_counts(["..."]) == ["000"]
    assert mine_counts(["*"]) == ["*"]
    assert mine_counts(["**", "**"]) == ["**", "**"]
@@solution
def mine_counts(field):
    rows, cols = len(field), len(field[0])
    result = []
    for r in range(rows):
        line = ""
        for c in range(cols):
            if field[r][c] == "*":
                line += "*"
                continue
            count = 0
            for dr in [-1, 0, 1]:
                for dc in [-1, 0, 1]:
                    nr, nc = r + dr, c + dc
                    if (dr != 0 or dc != 0) and 0 <= nr < rows and 0 <= nc < cols and field[nr][nc] == "*":
                        count += 1
            line += str(count)
        result.append(line)
    return result
:::

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: the Game of Life"
In 1970 the mathematician John Conway invented the **Game of Life**: a grid of cells, each alive (`#`) or dead (`.`). Each generation, every cell looks at its 8 neighbours:

- a live cell with 2 or 3 live neighbours survives; otherwise it dies;
- a dead cell with exactly 3 live neighbours comes alive.

All cells change **at the same moment**, so you must build the new grid from the old one, never changing the old one as you go. Cells off the edge count as dead.

Write `step(grid)` that takes a list of strings and returns the next generation as a new list of strings.
@@starter

@@tests
def test_blinker():
    "a blinker flips between two shapes"
    a = [".....", "..#..", "..#..", "..#..", "....."]
    b = [".....", ".....", ".###.", ".....", "....."]
    assert step(a) == b and step(b) == a
def test_block():
    "a block never changes"
    blk = ["....", ".##.", ".##.", "...."]
    assert step(blk) == blk
def test_glider():
    "a glider moves"
    g = [".#....", "..#...", "###...", "......", "......"]
    for _ in range(4):
        g = step(g)
    assert g == ["......", "..#...", "...#..", ".###..", "......"], "After four steps a glider moves one square down and one right."
def test_unchanged():
    "the input is not changed"
    a = ["##", "##"]
    step(a)
    assert a == ["##", "##"]
@@hint
Write a helper `live_neighbours(grid, r, c)`, like `count_neighbours` above. Then build each new row as a string, cell by cell, from the rules.
@@solution
def live_neighbours(grid, r, c):
    count = 0
    for dr in [-1, 0, 1]:
        for dc in [-1, 0, 1]:
            if dr == 0 and dc == 0:
                continue
            nr, nc = r + dr, c + dc
            if 0 <= nr < len(grid) and 0 <= nc < len(grid[0]) and grid[nr][nc] == "#":
                count += 1
    return count

def step(grid):
    new = []
    for r in range(len(grid)):
        row = ""
        for c in range(len(grid[0])):
            n = live_neighbours(grid, r, c)
            alive = grid[r][c] == "#"
            if (alive and n in [2, 3]) or (not alive and n == 3):
                row += "#"
            else:
                row += "."
        new.append(row)
    return new
:::
