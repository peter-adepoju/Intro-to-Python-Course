## Warm-up

:::predict
words = "the quick brown fox".split()
print(words)
print(len(words), words[0], words[-1])
:::

You've been making lists since Week 5: `split` returns one. The square brackets in the output are how Python writes a list. Today you'll learn to make your own and use them properly.

## What a list is

A **list** is an ordered collection of values. You write one with square brackets, the values separated by commas:

:::example
primes = [2, 3, 5, 7, 11]
names = ["Ada", "Grace", "Alan"]
mixed = [42, "hello", 3.14, True]
empty = []
print(primes)
print(len(names), len(empty))
print(type(primes))
:::

A list can hold any kind of value, even a mix (though most useful lists hold one kind). It can be empty. `len` gives the number of items.

The values are called **items** or **elements**. Each one is a separate object, and the list holds a reference to each, like a row of labelled hooks. Press X-ray on this one and look at the objects panel: the list is a row of slots, each with an arrow to its value.

:::example title="X-ray me"
scores = [93, 88, 97]
best = scores[2]
print(best)
:::

### Other ways to make a list

`list()` turns any sequence into a list:

:::example
print(list(range(5)))
print(list(range(10, 0, -3)))
print(list("hello"))
print("2026-10-27".split("-"))
:::

## Indexing, slicing and looping

Everything you learned about indexing and slicing strings works on lists. Positions start at 0; negative positions count from the end; slices stop before the end index:

:::example
planets = ["Mercury", "Venus", "Earth", "Mars", "Jupiter", "Saturn"]
print(planets[0])
print(planets[-1])
print(planets[2:4])
print(planets[:3])
print(planets[::2])
print(planets[::-1])
:::

Play with a list's indexes here. Each box shows its positive and negative index:

:::widget listops caption="Choose one of the reading operations (an index, a slice, len) and run it. A slice gives back a new list; an index gives back one item."
{"start": "[3, 1, 4, 1, 5]", "ops": ["x[0]", "x[-1]", "x[1:3]", "x[::-1]", "len(x)", "x[5]", "4 in x", "x.index(4)", "x.count(1)"]}
:::

:::key
`items[i]` gives one item. `items[a:b]` gives a **new list** of items from position `a` up to, but not including, `b`. Indexing past the end is an `IndexError`; slicing past the end just stops.
:::

### Looping over a list

`for` visits every item in order, exactly as it visits the characters of a string:

:::example
temperatures = [21.5, 23.0, 19.8, 25.1]
for t in temperatures:
    print(f"{t:5.1f} {'#' * round(t - 15)}")
:::

When you need positions too, loop over `range(len(...))`:

:::example
names = ["Ada", "Grace", "Alan"]
for i in range(len(names)):
    print(i + 1, names[i])
:::

### in

`in` asks whether a value is one of the items:

:::example
vowels = ["a", "e", "i", "o", "u"]
print("e" in vowels, "y" in vowels)
print(7 in [1, 3, 5, 7])
:::

## Building a list with append

Usually you don't know a list's items when you write the program. You start with an empty list and add items as you go, with the **method** `.append(value)`, which adds one item to the end:

:::example title="Collect the squares"
squares = []
for n in range(1, 6):
    squares.append(n * n)
print(squares)
:::

Step through it in X-ray: the same list grows by one slot on each pass.

This is the accumulator pattern from Week 3, with a list as the accumulator: start empty, add on each pass, use it after the loop.

:::example title="Read numbers into a list" try="4 8 15 16 23 42"
numbers = []
for piece in input("Numbers: ").split():
    numbers.append(int(piece))
print(numbers)
print("Total:", sum(numbers))
:::

:::example title="Keep only some items"
words = "the cat sat on the warm mat".split()
long_words = []
for w in words:
    if len(w) > 3:
        long_words.append(w)
print(long_words)
:::

:::mistake
`append` changes the list itself and returns `None`. So `numbers = numbers.append(5)` replaces your list with `None`. Just write `numbers.append(5)` on its own line. (Tomorrow you'll see exactly why.)
:::

## Built-in functions on lists

Many of the built-in functions you know work on whole lists:

:::example
marks = [72, 45, 88, 91, 60]
print(len(marks), sum(marks), min(marks), max(marks))
print(sum(marks) / len(marks))
print(sorted(marks))
print(sorted(marks, reverse=True))
print(marks)
:::

`sorted` returns a **new** sorted list and leaves the original alone. It takes the same `key=` you met last week:

:::example
words = ["banana", "Fig", "apple", "Cherry"]
print(sorted(words))
print(sorted(words, key=str.lower))
print(sorted(words, key=len))
:::

### Joining and repeating

`+` joins two lists into a new one, and `*` repeats a list, just as with strings:

:::example
print([1, 2] + [3, 4])
print([0] * 5)
print(["-"] * 3 + ["x"])
:::

`[0] * 5` is a handy way to make a list of five zeros, ready to be filled in.

### Lists and strings together

`split` turns a string into a list, and `join` turns a list of strings back into one string:

:::example
words = "Python lists are flexible".split()
print(" ".join(words))
print("-".join(sorted(words, key=str.lower)))
:::

    best = numbers[0]
    for n in numbers[1:]:
        if n > best:
            best = n
    return best

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: moving average"
Sensor readings are noisy. A **moving average** smooths them: each smoothed value is the average of a window of `k` readings in a row. For readings `[2, 4, 6, 8, 10]` and `k = 3`, the windows are `[2, 4, 6]`, `[4, 6, 8]` and `[6, 8, 10]`, so the moving averages are `[4.0, 6.0, 8.0]`.

Write `moving_average(readings, k)` that returns the list of moving averages, each rounded to 2 places. If there are fewer than `k` readings, return `[]`. Then read readings on one line with the prompt `Readings: ` and a window size with the prompt `Window: `, and print the result.
@@starter

@@tests
def test_function():
    "moving_average"
    assert moving_average([2, 4, 6, 8, 10], 3) == [4.0, 6.0, 8.0]
    assert moving_average([1, 2], 3) == []
    assert moving_average([5, 5, 5], 1) == [5.0, 5.0, 5.0]
    assert moving_average([1, 2, 4], 2) == [1.5, 3.0]
    assert moving_average([1, 1, 2], 3) == [1.33]
def test_program():
    "the program"
    expect_output("Readings: 21 23 22 25 30 28\nWindow: 3\n[22.0, 23.33, 25.67, 27.67]", inputs=["21 23 22 25 30 28", "3"], echo=True)
@@hint
There are `len(readings) - k + 1` windows. Window number `i` is the slice `readings[i:i + k]`, and `sum(...) / k` is its average.
@@solution
def moving_average(readings, k):
    result = []
    for i in range(len(readings) - k + 1):
        window = readings[i:i + k]
        result.append(round(sum(window) / k, 2))
    return result

readings = []
for piece in input("Readings: ").split():
    readings.append(float(piece))
k = int(input("Window: "))
print(moving_average(readings, k))
:::
