:::exercise id=mix_stats points=10 title="Class statistics"
Write `summary(marks)` that returns four values for a non-empty list of marks: the mean (rounded to 1 place), the median, the highest, and how many are at or above the mean. The median of an even-length list is the average of the two middle values. Don't change the caller's list.
@@starter

@@tests
def test_values():
    "several lists"
    data = [72, 45, 88, 91, 60]
    assert tuple(summary(data)) == (71.2, 72, 91, 3)
    assert data == [72, 45, 88, 91, 60], "Don't change the caller's list."
    assert tuple(summary([1, 2, 3, 4])) == (2.5, 2.5, 4, 2)
@@solution
def summary(marks):
    mean = sum(marks) / len(marks)
    ordered = sorted(marks)
    mid = len(ordered) // 2
    if len(ordered) % 2:
        median = ordered[mid]
    else:
        median = (ordered[mid - 1] + ordered[mid]) / 2
    at_or_above = 0
    for m in marks:
        if m >= mean:
            at_or_above += 1
    return round(mean, 1), median, max(marks), at_or_above
:::

def flatten(groups):
    result = []
    for g in groups:
        result.extend(g)
    return result

Write `interleave(a, b)` that returns a new list taking items alternately from `a` and `b`, starting with `a`. When one runs out, the rest of the other follows. `interleave([1, 2, 3], ["x"])` is `[1, "x", 2, 3]`.

@@solution
def interleave(a, b):
    result = []
    for i in range(max(len(a), len(b))):
        if i < len(a):
            result.append(a[i])
        if i < len(b):
            result.append(b[i])
    return result
:::

:::exercise id=mix_stack points=10 title="Reverse Polish"
In **Reverse Polish notation**, operators come after their numbers: `3 4 +` means 3 + 4, and `5 1 2 + 4 * + 3 -` means 5 + (1 + 2) × 4 − 3. It's evaluated with a stack: push numbers; on an operator, pop two numbers, apply it, and push the result. Write `rpn(expression)` for `+`, `-` and `*` with whole numbers, returning the final number.
@@starter

@@tests
def test_values():
    "several expressions"
    assert rpn("3 4 +") == 7
    assert rpn("5 1 2 + 4 * + 3 -") == 14
    assert rpn("2 3 4 * -") == -10
    assert rpn("42") == 42
@@hint
When you pop for an operator, the first value popped is the **right**-hand number: `b = stack.pop()`, then `a = stack.pop()`, then push `a - b`.
@@solution
def rpn(expression):
    stack = []
    for token in expression.split():
        if token in "+-*":
            b = stack.pop()
            a = stack.pop()
            if token == "+":
                stack.append(a + b)
            elif token == "-":
                stack.append(a - b)
            else:
                stack.append(a * b)
        else:
            stack.append(int(token))
    return stack.pop()
:::

## Forge bonus: shuffling fairly

:::exercise id=forge2 points=30 title="Forge bonus: the Fisher-Yates shuffle"
How do you shuffle a list so that every possible order is **equally likely**? Many people's first idea (swap every item with a random position anywhere) is subtly unfair. The correct method, the **Fisher-Yates shuffle**, works backwards:

```
for i from the last position down to 1:
    pick a random j from 0 to i (including i)
    swap the items at i and j
```

1. Write `shuffle(items)` that shuffles the list **in place** this way, using `random.randint(0, i)` for each `j`, and returns `None`.
2. Write `shuffled(items)` that returns a shuffled **copy** and leaves the original alone, by copying and then calling `shuffle`.
3. Write `deal(n_players, n_cards)` that makes a deck `list(range(1, 53))`, shuffles it, and returns a list of `n_players` hands, each a list of `n_cards` cards dealt from the **top** of the deck (the last item), one card to each player in turn.

The checks fix the random numbers, so your shuffle must call `random.randint` exactly as described: once for each `i` from `len(items) - 1` down to 1.
@@starter
import random

@@tests
import random as _r
def ref_shuffle(items):
    for i in range(len(items) - 1, 0, -1):
        j = _r.randint(0, i)
        items[i], items[j] = items[j], items[i]
def test_shuffle():
    "shuffle follows the algorithm exactly"
    for seed in [1, 7, 42]:
        a = list(range(10))
        b = list(range(10))
        _r.seed(seed)
        assert shuffle(a) is None, "shuffle works in place and returns None."
        _r.seed(seed)
        ref_shuffle(b)
        assert a == b, "Use random.randint(0, i) once for each i from the last position down to 1, and swap items i and j."
def test_shuffled():
    "shuffled returns a copy"
    data = list(range(5))
    out = shuffled(data)

    assert sorted(out) == data and out is not data

    _r.seed(3)
    hands = deal(4, 5)
    assert len(hands) == 4 and all(len(h) == 5 for h in hands)
    cards = [c for h in hands for c in h]
    assert len(set(cards)) == 20 and all(1 <= c <= 52 for c in cards)
    _r.seed(3)
    deck = list(range(1, 53))
    ref_shuffle(deck)
    assert hands[0][0] == deck[-1] and hands[1][0] == deck[-2], "Deal from the end of the deck, one card to each player in turn."
@@hint
`for i in range(len(items) - 1, 0, -1):` counts down from the last position to 1.
@@hint
In `deal`, make `hands` a list of `n_players` empty lists (each a separate list!). Then for each round, for each player, `hands[p].append(deck.pop())`.
@@solution
import random

def shuffle(items):
    for i in range(len(items) - 1, 0, -1):
        j = random.randint(0, i)
        items[i], items[j] = items[j], items[i]

def shuffled(items):
    result = items.copy()
    shuffle(result)
    return result

def deal(n_players, n_cards):
    deck = list(range(1, 53))
    shuffle(deck)
    hands = []
    for _ in range(n_players):
        hands.append([])
    for _ in range(n_cards):
        for p in range(n_players):
            hands[p].append(deck.pop())
    return hands
:::

Python's own `random.shuffle` uses exactly this algorithm. Now you know what it does.
