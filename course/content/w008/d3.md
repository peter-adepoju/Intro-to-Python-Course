## Adding items

You know `append`, which adds **one** item at the end. Two more:

:::example
x = [1, 2, 3]
x.append(4)
print(x)
x.extend([5, 6])
print(x)
x.insert(0, 0)
print(x)
x.insert(3, 99)
print(x)
:::

- `extend(other)` adds **every item** of another sequence to the end.
- `insert(i, value)` puts a value **at position** `i`, shifting the rest right.

### append or extend?

The difference catches everyone once:

:::example
a = [1, 2]
a.append([3, 4])
print(a, len(a))
b = [1, 2]
b.extend([3, 4])
print(b, len(b))
:::

`append` adds its argument as **one** item, even if that item is a list, so `a` ends up with a list inside it. `extend` adds the argument's **items** one by one. Use `extend` (or `+=`) to join one list onto another.

## Removing items

:::example
x = ["a", "b", "c", "d", "e"]
last = x.pop()
print(last, x)
first = x.pop(0)
print(first, x)
x.remove("c")
print(x)
x.clear()
print(x)
:::

- `pop()` removes the **last** item and **returns** it. `pop(i)` removes and returns the item at position `i`. Popping from an empty list is an `IndexError`.
- `remove(value)` removes the **first** item equal to `value`. If there isn't one, it's a `ValueError`.
- `clear()` empties the list.

`pop` is the only one of these that gives you back what it removed, which makes it perfect for taking things out of a list one at a time.

:::example error=yes
x = [1, 2, 3]
x.remove(7)
:::

To remove safely, check first:

:::example
x = [1, 2, 3]
if 7 in x:
    x.remove(7)
print(x)
:::

And to remove **every** copy of a value, keep going while one is left:

:::example
x = [1, 0, 2, 0, 0, 3]
while 0 in x:
    x.remove(0)
print(x)
:::

## Finding items

:::example
x = [10, 20, 30, 20, 10]
print(x.index(20))
print(x.index(20, 2))
print(x.count(10))
print(x.count(99))
:::

- `index(value)` gives the position of the **first** match. An optional second argument says where to start looking. If the value isn't there: `ValueError`.
- `count(value)` gives how many items equal `value`, and is 0 when there are none.

`index` on a list is like `.index` on a string. Unlike strings, lists have no `find` that returns -1, so check with `in` first when the value might be missing.

## Ordering: sort and reverse

`x.sort()` sorts the list **in place**. It takes the same `key=` and `reverse=` as `sorted`:

:::example
words = ["banana", "Fig", "apple", "Cherry"]
words.sort()
print(words)
words.sort(key=str.lower)
print(words)
words.sort(key=len, reverse=True)
print(words)
words.reverse()
print(words)
:::

`reverse()` turns the list round in place. (`x[::-1]` gives a reversed **copy**.)

### Changes the list, or returns an answer?

| Changes the list, returns `None` | Leaves the list alone, returns an answer |
|---|---|
| `append`, `extend`, `insert` | `index`, `count` |
| `remove`, `clear` | `len(x)`, `sum(x)`, `min(x)`, `max(x)` |
| `sort`, `reverse` | `sorted(x)`, `x[::-1]`, `x[a:b]`, `x + y` |
| `pop` (also returns the item) | `x.copy()` (a new list with the same items) |

Python's rule: methods that change a list return `None`, so that you can't mistake them for ones that give you something new.

:::mistake title="x = x.sort()"
`x.sort()` returns `None`, so `x = x.sort()` sorts the list and then throws it away, leaving `x` as `None`. Write `x.sort()` on its own, or `x = sorted(x)`.
:::

:::example
x = [3, 1, 2]
x = x.sort()
print(x)
:::

### Speed: the ends are not equal

`append` and `pop()` work at the end of the list and are fast however long the list is. `insert(0, ...)` and `pop(0)` work at the front, so every other item has to shift along one place: on a list of a million items, that's a million moves each time. For a few hundred items you'll never notice. You'll learn faster structures for the front, and why, in Phase 4.

## A list as a stack

A **stack** is a pile: you put things on top, and take them off the top, last in, first out. A list does this perfectly with `append` (push) and `pop` (pop):

:::example title="Undo"
history = []
text = ""
for word in ["Hello", " world", "!!!"]:
    history.append(text)
    text += word
    print("Typed:", repr(text))
text = history.pop()
print("Undo: ", repr(text))
text = history.pop()
print("Undo: ", repr(text))
:::

Every undo button, the back button in a browser, and the way Python itself keeps track of function calls (the call stack from Week 6) work like this. Stacks will come back many times.

:::exercise id=todo points=15 title="A to-do list"
Write a to-do list manager. It reads commands with the prompt `> ` until `quit`:

- `add TASK` adds the task at the end;
- `first TASK` adds the task at the front;
- `done` removes and prints the **first** task as `Done: TASK`, or prints `Nothing to do`;
- `drop TASK` removes that task if it's in the list, or prints `No such task`;
- `list` prints the tasks numbered from 1, or `Empty`.

The task is everything after the first space.
@@starter
tasks = []

@@tests
def test_session():
    "a session"
    ins = ["add buy rice", "add call Ada", "first wake up", "list", "done", "drop call Ada", "drop fly", "list", "done", "done", "list", "quit"]
    want = ("> add buy rice\n> add call Ada\n> first wake up\n> list\n1. wake up\n2. buy rice\n3. call Ada\n"
            "> done\nDone: wake up\n> drop call Ada\n> drop fly\nNo such task\n> list\n1. buy rice\n"
            "> done\nDone: buy rice\n> done\nNothing to do\n> list\nEmpty\n> quit")
    expect_output(want, inputs=ins, echo=True)
@@hint
`command.split(" ", 1)` splits off the first word: `"add buy rice"` becomes `["add", "buy rice"]`.
@@solution
tasks = []
while True:
    line = input("> ")
    if line == "quit":
        break
    parts = line.split(" ", 1)
    cmd = parts[0]
    task = parts[1] if len(parts) > 1 else ""
    if cmd == "add":
        tasks.append(task)
    elif cmd == "first":
        tasks.insert(0, task)
    elif cmd == "done":
        if tasks:
            print("Done:", tasks.pop(0))
        else:
            print("Nothing to do")
    elif cmd == "drop":
        if task in tasks:
            tasks.remove(task)
        else:
            print("No such task")
    elif cmd == "list":
        if tasks:
            for i in range(len(tasks)):
                print(f"{i + 1}. {tasks[i]}")
        else:
            print("Empty")
:::

:::exercise id=remove_all points=10 title="Remove every copy"
Write `remove_all(items, value)` that removes every item equal to `value` from the list, in place, and returns how many were removed.
@@starter

@@tests
def test_values():
    "several calls"
    a = [1, 0, 2, 0, 0, 3]
    assert remove_all(a, 0) == 3 and a == [1, 2, 3]
    b = [1, 2]
    assert remove_all(b, 9) == 0 and b == [1, 2]
    c = ["x", "x"]
    assert remove_all(c, "x") == 2 and c == []
@@solution
def remove_all(items, value):
    removed = 0
    while value in items:
        items.remove(value)
        removed += 1
    return removed

:::exercise id=all_positions points=10 title="Every position"
Write `positions(items, value)` that returns a list of every index where `value` appears, using `index` with its start argument (not a loop over every position). `positions([5, 1, 5, 5], 5)` is `[0, 2, 3]`.
@@starter

@@tests
def test_values():
    "several calls"
    assert positions([5, 1, 5, 5], 5) == [0, 2, 3]
    assert positions([1, 2, 3], 9) == []
    assert positions(["a"], "a") == [0]
    assert ".index(" in source
@@hint
Start looking at 0. While the value is still in the rest of the list (`value in items[start:]`), find it with `items.index(value, start)`, record it, and start again just after it.
@@solution
def positions(items, value):
    result = []
    start = 0
    while value in items[start:]:
        i = items.index(value, start)
        result.append(i)
        start = i + 1
    return result
:::

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: matching brackets"
Code editors check that brackets match: every `(`, `[` and `{` must be closed by the right kind, in the right order. `{[()]}` is fine; `([)]` is not.

Write `check_brackets(text)` that returns `"OK"` if the brackets in `text` match (other characters are ignored), or a message:

- `Unexpected X at N` if a closing bracket `X` at position `N` doesn't match the most recent open bracket (or there isn't one);
- `Unclosed X at N` if an opening bracket `X` at position `N` is never closed (report the **last** one still open).

Use a list as a stack of the open brackets and their positions.
@@starter

@@tests
def test_ok():
    "matching text"
    for t in ["", "abc", "{[()]}", "f(a[1], {b: 2})", "(()())"]:
        assert check_brackets(t) == "OK", f"{t!r} matches."
def test_unexpected():
    "a wrong closing bracket"
    assert check_brackets("([)]") == "Unexpected ) at 2"
    assert check_brackets("a)") == "Unexpected ) at 1"
    assert check_brackets("{]") == "Unexpected ] at 1"
def test_unclosed():
    "an opening bracket never closed"
    assert check_brackets("(a[b]") == "Unclosed ( at 0"
    assert check_brackets("{{}") == "Unclosed { at 0"
    assert check_brackets("([") == "Unclosed [ at 1"
@@hint
When you see an opening bracket, push it and its position (as a pair: `stack.append((ch, i))`). When you see a closing one, the stack must not be empty, and the top's bracket must be its partner.
@@hint
`"([{".index(open_ch) == ")]}".index(close_ch)` tells you whether two brackets are partners. At the end, anything left on the stack was never closed: report the top one.
@@solution
def check_brackets(text):
    stack = []
    for i in range(len(text)):
        ch = text[i]
        if ch in "([{":
            stack.append((ch, i))
        elif ch in ")]}":
            if not stack or "([{".index(stack[-1][0]) != ")]}".index(ch):
                return f"Unexpected {ch} at {i}"
            stack.pop()
    if stack:
        ch, i = stack[-1]
        return f"Unclosed {ch} at {i}"
    return "OK"
:::
