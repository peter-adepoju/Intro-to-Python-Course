## Warm-up

:::predict
marks = [72, 45, 88, 51]
passed = []
for m in marks:
    if m >= 50:
        passed.append(m)
print(passed, len(passed), sum(passed))
:::

The filter pattern, but this time the result is a list you can keep: count it, sum it, print it, pass it on.

## Filter and transform

**Filter** keeps the items that pass a test. **Transform** (also called **map**) changes every item. Both build a **new** list and leave the original alone:

:::example
words = ["apple", "Fig", "banana", "Kiwi", "cherry"]
long_ones = []
for w in words:
    if len(w) > 4:
        long_ones.append(w)
shouted = []
for w in words:
    shouted.append(w.upper())
print(long_ones)
print(shouted)
print(words)
:::

They combine naturally: filter, then transform.

:::example
temps = [21.5, -3.0, 19.8, -1.2, 25.1]
above_zero_f = []
for t in temps:
    if t > 0:
        above_zero_f.append(round(t * 9 / 5 + 32, 1))
print(above_zero_f)
:::

:::key
Filter and transform build a new list: start with `result = []`, loop over the original, and `result.append(...)`. This is also the safe way to "remove" items: keep the ones you want.
:::

(Next week you'll meet **list comprehensions**, a one-line way to write exactly these two patterns.)

## Built-ins that replace loops

Several patterns are so common that Python has a function for them:

| Pattern | Built-in |
|---|---|
| accumulate a sum | `sum(items)` |
| best so far | `max(items)`, `min(items)`, with `key=` if needed |
| count | `items.count(value)`, or `len` of a filtered list |
| any of | `any(...)` |
| all of | `all(...)` |

`any` and `all` take a list of `True`/`False` values:

:::example
marks = [72, 45, 88, 51]
checks = []
for m in marks:
    checks.append(m >= 50)
print(checks)
print("Anyone passed:", any(checks))
print("Everyone passed:", all(checks))
:::

`any([])` is `False` (nothing passed) and `all([])` is `True` (nothing failed). Next week's comprehensions will let you write `all(m >= 50 for m in marks)` in one line.

:::tip
Use the built-in when there is one: it's shorter, it's been tested by millions of people, and it's usually faster. Write the loop yourself when you need something the built-in doesn't give you, like the **position** of the best item.
:::

## Positions, neighbours, running totals

### Where is the best?

`max` gives the best **value**. For its **position**, keep the position in the loop, or use `index`:

:::example
scores = [72, 95, 64, 95, 80]
best_at = 0
for i in range(1, len(scores)):
    if scores[i] > scores[best_at]:
        best_at = i
print("Best:", scores[best_at], "at", best_at)
print("Also:", scores.index(max(scores)))
:::

### Neighbours

Comparing each item with the next uses positions up to `len - 1`, just as with strings:

:::example title="Daily changes"
prices = [100, 104, 101, 108, 108]
changes = []
for i in range(len(prices) - 1):
    changes.append(prices[i + 1] - prices[i])
print(changes)
:::

### Two lists in step

When two lists line up (item `i` of one goes with item `i` of the other), loop over the positions:

:::example
names = ["Ada", "Grace", "Alan"]
scores = [93, 88, 97]
for i in range(len(names)):
    print(f"{names[i]:<6}{scores[i]:>4}")
:::

(Next week, `zip` pairs them up for you.)

### Running totals

A running total kept as a list gives you the total **so far** at every step, which is useful for bank balances, cumulative rainfall, and much more:

:::example
deposits = [100, -30, 250, -80]
running = []
total = 0
for d in deposits:
    total += d
    running.append(total)
print(running)
:::

## New patterns

### No duplicates, order kept

Keep an item only if it isn't already in the result:

:::example
visits = ["Lagos", "Accra", "Lagos", "Nairobi", "Accra"]
unique = []
for city in visits:
    if city not in unique:
        unique.append(city)
print(unique)
:::

### Chunks

Split a list into groups of `n` with a slice in steps of `n`:

:::example
items = list(range(1, 11))
chunks = []
for start in range(0, len(items), 3):
    chunks.append(items[start:start + 3])
print(chunks)
:::

The result is a list of lists. Next week is all about those.

### Merging two sorted lists

Given two lists that are each already sorted, you can combine them into one sorted list in a single pass, without sorting again. Keep a position in each list. At every step, take the smaller of the two front items, and move that list's position on. When one list runs out, add the rest of the other:

:::example title="Merge"
a = [1, 4, 9, 12]
b = [2, 3, 10]
i = j = 0
merged = []
while i < len(a) and j < len(b):
    if a[i] <= b[j]:
        merged.append(a[i])
        i += 1
    else:
        merged.append(b[j])
        j += 1
merged.extend(a[i:])
merged.extend(b[j:])
print(merged)
:::

Trace it in X-ray, watching `i` and `j`. This **two-pointer** idea is the heart of **merge sort**, one of the fastest sorting algorithms, which you'll build in Phase 2.

:::exercise id=second_largest points=15 title="Second largest"
Write `second_largest(values)` that returns the second-largest **different** value in the list, without sorting. `second_largest([5, 9, 9, 7])` is 7. If there isn't one (fewer than two different values), return `None`.
@@starter

@@tests
def test_values():
    "several lists"
    assert second_largest([5, 9, 9, 7]) == 7
    assert second_largest([1, 2]) == 1
    assert second_largest([4, 4]) is None
    assert second_largest([]) is None
    assert second_largest([-1, -5, -3]) == -3
    assert "sort" not in source
@@hint
Keep two records, `first` and `second`, both starting at `None`. For each value: if it beats `first`, the old `first` becomes `second`; otherwise, if it's different from `first` and beats `second`, it becomes `second`.
@@solution
def second_largest(values):
    first = second = None
    for v in values:
        if first is None or v > first:
            if first is not None:
                second = first
            first = v
        elif v != first and (second is None or v > second):
            second = v
    return second
:::

:::exercise id=merge points=15 title="Merge two sorted lists"
Write `merge(a, b)` that takes two lists, each already sorted, and returns one sorted list with all their items, in a single pass (don't call `sort` or `sorted`).
@@starter

@@tests
def test_values():
    "several pairs"
    assert merge([1, 4, 9], [2, 3, 10, 11]) == [1, 2, 3, 4, 9, 10, 11]
    assert merge([], [1, 2]) == [1, 2]
    assert merge([1, 2], []) == [1, 2]
    assert merge([1, 1], [1]) == [1, 1, 1]
    assert merge(["ant", "cat"], ["bee"]) == ["ant", "bee", "cat"]
    assert "sort" not in source
@@solution
def merge(a, b):
    i = j = 0
    result = []
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            result.append(a[i])
            i += 1
        else:
            result.append(b[j])
            j += 1
    result.extend(a[i:])
    result.extend(b[j:])
    return result
:::

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: the longest rising streak"
Write `longest_rise(values)` that returns the longest run of values where each one is **bigger** than the one before, as a list. If there's a tie, return the first. An empty list gives `[]`, and a single value is a run of one.

`longest_rise([5, 1, 2, 3, 2, 4, 6, 8, 1])` is `[2, 4, 6, 8]`.
@@starter

@@tests
def test_values():
    "several lists"
    assert longest_rise([5, 1, 2, 3, 2, 4, 6, 8, 1]) == [2, 4, 6, 8]
    assert longest_rise([]) == []
    assert longest_rise([7]) == [7]
    assert longest_rise([3, 3, 3]) == [3]
    assert longest_rise([1, 2, 1, 2]) == [1, 2]
    assert longest_rise([9, 8, 1, 2, 3]) == [1, 2, 3]
@@hint
Remember where the current run **started**. When an item isn't bigger than the one before, the run ends: compare its length with the best so far, and start a new run at this item.
@@hint
Don't forget the run that's still going when the loop ends. Then return a slice.
@@solution
def longest_rise(values):
    if not values:
        return []
    best_start, best_len = 0, 1
    start = 0
    for i in range(1, len(values) + 1):
        if i == len(values) or values[i] <= values[i - 1]:
            if i - start > best_len:
                best_start, best_len = start, i - start
            start = i
    return values[best_start:best_start + best_len]
:::
