## Warm-up

:::predict
from datetime import date

start = date(2026, 2, 27)
print(date(2026, 3, 1) - start)
print(date(2028, 3, 1) - date(2028, 2, 27))
:::

2026 isn't a leap year, so from 27 February to 1 March is 2 days; in 2028 it is a leap year, and it's 3. `date` knows the calendar, so you never have to.

## Dates, times and datetimes

The `datetime` module has a few types:

| Type | Holds | Made with |
|---|---|---|
| `date` | a calendar day | `date(2026, 10, 31)` |
| `time` | a time of day | `time(14, 30)` or `time(9, 5, 30)` |
| `datetime` | a day and a time together | `datetime(2026, 10, 31, 14, 30)` |
| `timedelta` | a length of time | `timedelta(days=3, hours=4)` |

The module and one of its types share the name `datetime`, which confuses everyone at first. The usual style is to import the types you need: `from datetime import date, datetime, timedelta`. Then `datetime` means the type.

:::example
from datetime import date, time, datetime

d = date(2026, 10, 31)
print(d, d.year, d.month, d.day)
print(d.weekday(), d.isoweekday(), d.strftime("%A"))     # Monday is 0 (or 1 for isoweekday)

t = time(14, 30)
print(t, t.hour, t.minute)

dt = datetime(2026, 10, 31, 14, 30, 15)
print(dt, dt.date(), dt.time())
print(datetime.combine(d, t))
:::

**Now:** `date.today()` and `datetime.now()` give the current date and time on the computer running the code (in the browser, yours). Their values change every time, so the examples below mostly use fixed dates.

:::example
from datetime import date, datetime

print(date.today())
print(datetime.now().strftime("%H:%M"))
:::

Dates **validate** themselves: `date(2026, 2, 30)` raises `ValueError: day is out of range for month`. And dates are **immutable**: to change one, make a new one with `replace`:

:::example
from datetime import date

d = date(2026, 10, 31)
print(d.replace(year=2027), d.replace(day=1))
try:
    date(2026, 2, 30)
except ValueError as e:
    print("ValueError:", e)
:::

## Arithmetic with timedelta

A `timedelta` is a duration. Add one to a date to move forward; subtract two dates to get the one between them:

:::example
from datetime import date, datetime, timedelta

today = date(2026, 10, 31)
print(today + timedelta(days=30))
print(today - timedelta(weeks=2))

gap = date(2027, 2, 5) - today
print(gap, gap.days, type(gap).__name__)

meeting = datetime(2026, 10, 31, 9, 45)
print(meeting + timedelta(hours=2, minutes=30))
print((datetime(2026, 11, 1, 6, 0) - meeting).total_seconds() / 3600, "hours")
:::

- `date - date` and `datetime - datetime` give a `timedelta`. Use `.days`, or `.total_seconds()` for the whole length in seconds.
- `timedelta` takes `weeks`, `days`, `hours`, `minutes`, `seconds` (and smaller); internally it stores only days, seconds and microseconds.
- There's no `timedelta(months=1)`, because months differ in length. To move by months, change the month number yourself (and decide what "one month after 31 January" should mean).

Dates **compare** and **sort** in time order, as you'd hope:

:::example
from datetime import date

deadlines = [date(2026, 12, 1), date(2026, 11, 15), date(2027, 1, 10)]
print(min(deadlines), sorted(deadlines)[-1])
print(date(2026, 11, 15) < date(2026, 12, 1))
:::

## Text to dates and back

**Dates to text.** `isoformat()` gives the international standard form, `YYYY-MM-DD` (and `T` before the time for a datetime). For any other layout, `strftime` (string **f**ormat time) takes a pattern of codes:

| Code | Means | Example |
|---|---|---|
| `%d` | day, two digits | `05` |
| `%m` | month, two digits | `03` |
| `%Y` | year, four digits | `2026` |
| `%y` | year, two digits | `26` |
| `%B` / `%b` | month name / short name | `October` / `Oct` |
| `%A` / `%a` | weekday / short weekday | `Saturday` / `Sat` |
| `%H:%M` | hours and minutes, 24-hour clock | `14:30` |
| `%I:%M %p` | 12-hour clock with AM/PM | `02:30 PM` |
| `%j` | day of the year | `304` |

:::example
from datetime import date, datetime

d = date(2026, 10, 31)
print(d.isoformat())
print(d.strftime("%d/%m/%Y"), d.strftime("%A %d %B %Y"))
print(datetime(2026, 10, 31, 14, 30).strftime("%I:%M %p on %a"))
print(f"{d:%d %b %Y}")            # f-strings accept the same codes after a colon
:::

**Text to dates.** `date.fromisoformat("2026-10-31")` reads the ISO form. For any other layout, `datetime.strptime(text, pattern)` (string **p**arse time) reads it with the same codes, and raises `ValueError` if the text doesn't match:

:::example
from datetime import date, datetime

print(date.fromisoformat("2026-10-31"))
d = datetime.strptime("31/10/2026", "%d/%m/%Y").date()
print(d, d.strftime("%A"))
print(datetime.strptime("5 March 2027 18:05", "%d %B %Y %H:%M"))
try:
    datetime.strptime("2026-10-31", "%d/%m/%Y")
except ValueError as e:
    print("ValueError:", e)
:::

:::mistake
`"03/04/2026"` is 3 April in Britain and 4 March in the United States. Never guess: know which layout your data uses, and say so in your code with an explicit pattern. Store and exchange dates in ISO form (`2026-04-03`), which has only one meaning and sorts correctly as text.
:::

## Common calculations

:::example
from datetime import date

def age_on(born, on):
    """Whole years old on the date `on`."""
    years = on.year - born.year
    if (on.month, on.day) < (born.month, born.day):    # birthday not reached yet this year
        years -= 1
    return years

def days_until_birthday(born, today):
    nxt = born.replace(year=today.year)
    if nxt < today:
        nxt = born.replace(year=today.year + 1)
    return (nxt - today).days

born = date(2000, 11, 3)
today = date(2026, 10, 31)
print(age_on(born, today), days_until_birthday(born, today))
:::

Comparing `(month, day)` tuples is a neat way to ask "has the birthday happened yet this year?". (Someone born on 29 February needs special care in `replace`, since most years have no 29 February. The challenge deals with it.)

The `calendar` module helps with whole months and years:

:::example
import calendar

print(calendar.isleap(2028), calendar.monthrange(2026, 2))   # (weekday of the 1st, days in month)
print(calendar.month(2026, 10))
:::

## Testable code with dates

A function that calls `date.today()` inside it gives a different answer every day, which makes it impossible to check properly. Pass "today" **in** as an argument, with the real today as the default:

```
def is_overdue(due, today=None):
    today = today or date.today()
    return today > due
```

Your program calls `is_overdue(due)`, and your tests call `is_overdue(due, date(2026, 10, 31))` and always get the same answer. Every exercise today is written that way.

:::key
`date`, `time`, `datetime` for moments; `timedelta` for lengths of time; subtract two dates to get the days between. `strftime` turns dates into text and `strptime` reads them back, with codes like `%d/%m/%Y`. Use ISO `YYYY-MM-DD` for storing dates, and pass "today" into functions so they can be tested.
:::

:::exercise id=shifts points=15 title="Working hours"
A timesheet lists shifts as `("2026-10-31 08:45", "2026-10-31 17:15")` pairs of start and end, written `YYYY-MM-DD HH:MM`. Some shifts run past midnight. Write `hours(shift)` returning the length in hours (a float), and `weekly_total(shifts)` returning the total hours rounded to 2 decimal places. Use `strptime`.
@@starter
from datetime import datetime

@@tests
def test_values():
    "several"
    s1 = ("2026-10-31 08:45", "2026-10-31 17:15")
    s2 = ("2026-11-01 22:00", "2026-11-02 06:30")
    assert hours(s1) == 8.5 and hours(s2) == 8.5
    assert weekly_total([s1, s2, ("2026-11-03 09:00", "2026-11-03 09:20")]) == 17.33
    assert weekly_total([]) == 0
@@solution
from datetime import datetime

FORMAT = "%Y-%m-%d %H:%M"

def hours(shift):
    start, end = (datetime.strptime(t, FORMAT) for t in shift)
    return (end - start).total_seconds() / 3600

def weekly_total(shifts):
    return round(sum(hours(s) for s in shifts), 2)
:::

:::exercise id=overdue points=15 title="Library loans"
Loans are `(title, borrowed_iso)` pairs, and books are due back 21 days after borrowing. Write `due_date(borrowed_iso)` returning the due `date`, and `overdue(loans, today)` returning a list of `(title, days_late)` for books past their due date, most overdue first, ties by title. A book due **on** `today` isn't late.
@@starter
from datetime import date, timedelta

@@tests
def test_values():
    "several"
    from datetime import date
    assert due_date("2026-10-01") == date(2026, 10, 22)
    loans = [("Dune", "2026-10-01"), ("Emma", "2026-10-10"), ("Kindred", "2026-09-30"), ("Dawn", "2026-10-01")]
    assert overdue(loans, date(2026, 10, 31)) == [("Kindred", 10), ("Dawn", 9), ("Dune", 9)]
    assert overdue(loans, date(2026, 10, 21)) == []
    assert overdue(loans, date(2026, 10, 22)) == [("Kindred", 1)]
@@solution
from datetime import date, timedelta

LOAN_DAYS = 21

def due_date(borrowed_iso):
    return date.fromisoformat(borrowed_iso) + timedelta(days=LOAN_DAYS)

def overdue(loans, today):
    late = [(title, (today - due_date(b)).days) for title, b in loans if today > due_date(b)]
    return sorted(late, key=lambda p: (-p[1], p[0]))
:::

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: months are awkward"
Write:

- `add_months(d, n)`: the date n months after `d` (n may be negative). If the day doesn't exist in the new month, use the **last** day of that month: 31 January plus 1 month is 28 February (29 in a leap year). Use `calendar.monthrange`.
- `birthday_in(born, year)`: the birthday in a given year, treating 29 February as 28 February in years that aren't leap years.
- `monthly_schedule(start, count)`: a list of `count` payment dates, one month apart, each worked out from `start` (not from the previous payment, so a start on the 31st returns to the 31st whenever the month allows).
@@starter
import calendar
from datetime import date

@@tests
def test_values():
    "several"
    from datetime import date
    assert add_months(date(2026, 1, 31), 1) == date(2026, 2, 28)
    assert add_months(date(2028, 1, 31), 1) == date(2028, 2, 29)
    assert add_months(date(2026, 10, 31), 2) == date(2026, 12, 31)
    assert add_months(date(2026, 10, 31), 3) == date(2027, 1, 31)
    assert add_months(date(2026, 3, 31), -1) == date(2026, 2, 28)
    assert add_months(date(2026, 1, 15), -13) == date(2024, 12, 15)
    assert birthday_in(date(2004, 2, 29), 2026) == date(2026, 2, 28) and birthday_in(date(2004, 2, 29), 2028) == date(2028, 2, 29)
    assert monthly_schedule(date(2026, 1, 31), 4) == [date(2026, 1, 31), date(2026, 2, 28), date(2026, 3, 31), date(2026, 4, 30)]
@@hint
Count months from year 0: `total = d.year * 12 + (d.month - 1) + n`, then `year, month = divmod(total, 12)` and `month += 1`. The last day of that month is `calendar.monthrange(year, month)[1]`.
@@solution
import calendar
from datetime import date

def add_months(d, n):
    total = d.year * 12 + (d.month - 1) + n
    year, month = divmod(total, 12)
    month += 1
    last = calendar.monthrange(year, month)[1]
    return date(year, month, min(d.day, last))

def birthday_in(born, year):
    last = calendar.monthrange(year, born.month)[1]
    return date(year, born.month, min(born.day, last))

def monthly_schedule(start, count):
    return [add_months(start, k) for k in range(count)]
:::
