:::exercise id=mix_week points=10 title="Which weekday?"
Write `busiest_weekday(dates)` that takes a list of ISO date strings and returns the name of the weekday (like `"Monday"`) on which most of them fall, the earliest in the week if tied. Use `datetime` and `Counter`.
@@starter
from collections import Counter
from datetime import date

@@tests
def test_values():
    "several"
    d = ["2026-10-31", "2026-11-07", "2026-11-02", "2026-11-14", "2026-11-09"]
    assert busiest_weekday(d) == "Saturday"
    assert busiest_weekday(["2026-11-02", "2026-11-01"]) == "Monday"
@@solution
from collections import Counter
from datetime import date

NAMES = ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday"]

def busiest_weekday(dates):
    counts = Counter(date.fromisoformat(d).weekday() for d in dates)
    best = max(counts.values())
    return NAMES[min(w for w, c in counts.items() if c == best)]
:::

from collections import defaultdict
import statistics

RESULTS = [("9A", "Ada", 71), ("9B", "Ben", 64), ("9A", "Cy", 88), ("9B", "Dee", 70), ("9A", "Eve", 59), ("9C", "Fin", 90)]

def class_medians(results):
    marks = defaultdict(list)
    for cls, student, mark in results:
        marks[cls].append(mark)
    return {cls: statistics.median(ms) for cls, ms in marks.items()}

:::exercise id=mix_draw points=10 title="A fair draw"
Write `draw(names, k, seed)` that picks k different winners from `names` with `random.Random(seed).sample`, and returns them sorted. The same seed must always give the same winners, and `k` larger than the number of names should give everyone.
@@starter
import random

@@tests
def test_values():
    "several"
    names = ["Ada", "Ben", "Cy", "Dee", "Eve", "Fin"]
    a = draw(names, 3, 1)
    assert a == draw(names, 3, 1) and len(a) == 3 and len(set(a)) == 3 and a == sorted(a)
    assert draw(names, 10, 2) == sorted(names) and draw([], 2, 3) == []
@@solution
import random

def draw(names, k, seed):
    rng = random.Random(seed)
    return sorted(rng.sample(names, min(k, len(names))))

## Forge: a spending tracker

Spending is recorded as lines of text, one purchase per line: the date, the category, the amount in pounds, and a note.

```
2026-10-02,food,12.40,market
2026-10-02,transport,3.10,bus
2026-10-05,food,7.85,lunch
2026-10-14,bills,45.00,phone
2026-10-20,food,23.10,market
2026-11-01,transport,3.10,bus
2026-11-03,fun,15.00,cinema
2026-11-04,food,9.60,lunch
```

You'll build it as a package called `spend`, with one job per module.

:::exercise id=forge points=50 title="Forge: a spending tracker"
Write `build()` that creates the package with the starter's `write_file` helper:

1. `spend/records.py`: a namedtuple `Purchase` with fields `day` (a `date`), `category`, `amount` (a float) and `note`, and `parse(text)` returning a list of `Purchase`s (skip blank lines).
2. `spend/totals.py` (no printing): `by_category(purchases)` returning a `Counter` of totals per category, each rounded to 2 decimal places; `by_month(purchases)` returning a plain dict from `"YYYY-MM"` to the total, rounded to 2 places; `biggest(purchases, k)` returning the k largest purchases, largest first.
3. `spend/summary.py`: `summary(text)` returning a string report (exact layout below), using the other modules through **relative** imports and `statistics.mean` for the average purchase.
4. `spend/__init__.py`: makes `summary` importable as `from spend import summary`.

For the sample data, `summary` returns exactly:

```
8 purchases, 119.15 in total, 14.89 on average
food: 52.95
bills: 45.0
fun: 15.0
transport: 6.2
2026-10: 91.45
2026-11: 27.7
Biggest: bills 45.0 (phone)
```

Categories are listed by total, highest first (ties alphabetically); months in order.
@@starter
import os

def write_file(name, text):
    """Write text to a file, making its folder first if needed."""
    os.makedirs(os.path.dirname(name) or ".", exist_ok=True)
    with open(name, "w") as f:
        f.write(text)

def build():
    write_file("spend/__init__.py", """___""")
    write_file("spend/records.py", """___""")
    write_file("spend/totals.py", """___""")
    write_file("spend/summary.py", """___""")
@@tests

2026-10-02,transport,3.10,bus
2026-10-05,food,7.85,lunch
2026-10-14,bills,45.00,phone

@@hint
`records.py` needs `from collections import namedtuple` and `from datetime import date`; parse each line with `line.split(",")` and `date.fromisoformat`.
@@hint
`by_category`: add up in a `Counter`, then round each total. `by_month`: the month key is `p.day.strftime("%Y-%m")`. `biggest`: `sorted(purchases, key=lambda p: p.amount, reverse=True)[:k]`.

@@solution
import os

def write_file(name, text):
    """Write text to a file, making its folder first if needed."""
    os.makedirs(os.path.dirname(name) or ".", exist_ok=True)
    with open(name, "w") as f:
        f.write(text)

def build():
    write_file("spend/__init__.py", '''"""A small spending tracker."""
from .summary import summary
''')
    write_file("spend/records.py", '''"""Reading purchases from text."""
from collections import namedtuple
from datetime import date

Purchase = namedtuple("Purchase", ["day", "category", "amount", "note"])

def parse(text):
    purchases = []
    for line in text.splitlines():
        if line.strip():
            day, category, amount, note = line.strip().split(",")
            purchases.append(Purchase(date.fromisoformat(day), category, float(amount), note))
    return purchases
''')
    write_file("spend/totals.py", '''"""Totals and rankings. No printing here."""
from collections import Counter, defaultdict

def by_category(purchases):
    totals = Counter()
    for p in purchases:
        totals[p.category] += p.amount
    for c in totals:
        totals[c] = round(totals[c], 2)
    return totals

def by_month(purchases):
    totals = defaultdict(float)
    for p in purchases:
        totals[p.day.strftime("%Y-%m")] += p.amount
    return {m: round(t, 2) for m, t in totals.items()}

def biggest(purchases, k):
    return sorted(purchases, key=lambda p: p.amount, reverse=True)[:k]
''')
    write_file("spend/summary.py", '''"""The text report."""
import statistics
from .records import parse
from .totals import by_category, by_month, biggest

def summary(text):
    ps = parse(text)
    total = round(sum(p.amount for p in ps), 2)
    average = round(statistics.mean(p.amount for p in ps), 2)
    lines = [f"{len(ps)} purchases, {total} in total, {average} on average"]
    cats = by_category(ps)
    for c in sorted(cats, key=lambda c: (-cats[c], c)):
        lines.append(f"{c}: {cats[c]}")
    months = by_month(ps)
    for m in sorted(months):
        lines.append(f"{m}: {months[m]}")
    top = biggest(ps, 1)[0]
    lines.append(f"Biggest: {top.category} {top.amount} ({top.note})")
    return "\\n".join(lines)
''')
:::

:::think title="One job per module"
Look at what each module knows about. `records` knows the text format and nothing about totals. `totals` knows how to add things up and nothing about text or printing. `summary` knows the report's layout and nothing about the file format. If the data moved from text lines to a spreadsheet, only `records` would change; if the report needed a new section, only `summary`. That independence is the whole point of splitting a program up, and it's what makes each part easy to test on its own.
:::

## Forge bonus: a bank queue

A bank has one cashier. Customers arrive at random times; each takes a random amount of time to serve. How long do people wait on average, and how long does the queue get? Questions like these, about queues at shops, phone lines, hospital clinics and computer servers, are often answered by **simulation**.

:::exercise id=forge2 points=30 title="Forge bonus: a bank queue"
Simulate the bank minute by minute for `minutes` minutes, with `rng = random.Random(seed)`:

- each minute, a new customer arrives with probability `arrive` (`rng.random() < arrive`); a customer is represented by the minute they arrived, and joins the back of a `deque`;
- the cashier serves one customer at a time; when free and the queue isn't empty, they take the customer at the front, whose waiting time is the current minute minus their arrival minute, and who then takes `rng.randint(1, max_service)` minutes to serve;
- in each minute, first handle the arrival, then let the cashier pick up the next customer if free, then let one minute of service pass.

Write `simulate(minutes, arrive, max_service, seed)` returning a dictionary with `"served"` (how many were picked up by the cashier), `"average_wait"` (mean wait of those served, to 2 decimal places, 0 if none), `"longest_queue"` (the most people waiting at once, measured after each minute's arrival) and `"still_waiting"` (the queue length at the end).
@@starter
import random
from collections import deque
import statistics

@@tests
def test_values():
    "repeatable and sensible"
    a = simulate(480, 0.2, 6, 1)
    assert a == simulate(480, 0.2, 6, 1)
    assert set(a) == {"served", "average_wait", "longest_queue", "still_waiting"}
    quiet = simulate(480, 0.05, 3, 2)
    busy = simulate(480, 0.4, 6, 2)
    assert quiet["average_wait"] < 2 and busy["average_wait"] > 30
    assert busy["longest_queue"] > quiet["longest_queue"]
    assert simulate(60, 0.0, 5, 3) == {"served": 0, "average_wait": 0, "longest_queue": 0, "still_waiting": 0}
def test_exact():
    "exact for a known seed"
    assert simulate(100, 0.3, 4, 7) == {'served': 31, 'average_wait': 2.87, 'longest_queue': 5, 'still_waiting': 3}
@@hint
Keep `busy_until` (the minute the cashier becomes free, starting at 0) and a list of waits. Each minute `t`: maybe append `t` to the queue; record `len(queue)` for the longest; if `t >= busy_until` and the queue isn't empty, pop the front, record `t - arrived`, and set `busy_until = t + rng.randint(1, max_service)`.
@@solution
import random
from collections import deque
import statistics

def simulate(minutes, arrive, max_service, seed):
    rng = random.Random(seed)
    queue = deque()
    waits = []
    longest = 0
    busy_until = 0
    for t in range(minutes):
        if rng.random() < arrive:
            queue.append(t)
        longest = max(longest, len(queue))
        if t >= busy_until and queue:
            arrived = queue.popleft()
            waits.append(t - arrived)
            busy_until = t + rng.randint(1, max_service)
    return {
        "served": len(waits),
        "average_wait": round(statistics.mean(waits), 2) if waits else 0,
        "longest_queue": longest,
        "still_waiting": len(queue),
    }
:::
