:::exercise id=mix_stats points=10 title="Statistics of anything"
Write `stats(*numbers, places=2)` that returns three values: the smallest, the largest and the mean rounded to `places`. `places` must be keyword-only (it already is, after `*numbers`). If no numbers are given, return `None, None, None`.
@@starter

@@tests
def test_values():
    "several calls"
    assert tuple(stats(4, 8, 15, 16, 23, 42)) == (4, 42, 18.0)
    assert tuple(stats(1, 2, places=0)) == (1, 2, 2.0)
    assert tuple(stats(1, 1, 2, places=3)) == (1, 2, 1.333)
    assert tuple(stats()) == (None, None, None)
@@solution
def stats(*numbers, places=2):
    if len(numbers) == 0:
        return None, None, None
    return min(numbers), max(numbers), round(sum(numbers) / len(numbers), places)

## Forge: the password rule kit

About an hour. Websites have password rules, and they keep changing them. Instead of one long function full of `if`s, you'll make each rule a **function**, and build a checker that applies any rules it's given.

A **rule** is a function that takes a password and returns an empty string if the password is fine, or a short message saying what's wrong.

:::exercise id=forge points=50 title="Forge: the password rule kit"
Write these, each with a docstring:

1. `min_length(n)` returns a rule that complains `At least N characters` (with the number) when the password is shorter than `n`.
2. `needs(test, what)` returns a rule that complains `Needs WHAT` when **no** character of the password passes `test`. For example `needs(str.isdigit, "a digit")` complains `Needs a digit`.
3. `no_spaces(password)` is itself a rule: it complains `No spaces allowed` when the password contains a space.
4. `check(password, *rules)` applies every rule in order and returns all the complaints joined with `"; "`, or `"OK"` if there are none.
5. `test_check()` tests `check` with at least four asserts, including one that expects `"OK"` and one that expects two complaints at once.

Finally, the main program builds this rule set and checks the password typed after the prompt `Password: `:

```python
rules = (min_length(8), needs(str.isupper, "a capital letter"), needs(str.isdigit, "a digit"), no_spaces)
```

```
Password: hello world
Needs a capital letter; Needs a digit; No spaces allowed
```

(`hello world` has 11 characters, so the length rule is happy.) Use `check(password, *rules)` to pass the rules in.
@@starter
def min_length(n):
    """Return a rule that complains if a password is shorter than n."""
    ___

def needs(test, what):
    """Return a rule that complains if no character passes test."""
    ___

def no_spaces(password):
    """Complain if the password contains a space."""
    ___

def check(password, *rules):
    """Return every complaint from rules, joined by '; ', or 'OK'."""
    ___

def test_check():
    pass

@@tests
def test_rules():
    "each rule"
    r = min_length(8)
    assert r("short") == "At least 8 characters" and r("longenough") == ""
    d = needs(str.isdigit, "a digit")
    assert d("abc") == "Needs a digit" and d("ab3") == ""
    assert no_spaces("a b") == "No spaces allowed" and no_spaces("ab") == ""
def test_check_fn():
    "check"
    assert check("abc") == "OK", "With no rules, every password is OK."
    assert check("Abcdefg1", min_length(8), needs(str.isdigit, "a digit")) == "OK"
    assert check("abc", min_length(5), needs(str.isupper, "a capital")) == "At least 5 characters; Needs a capital"
def test_your_tests():
    "your test has four asserts and passes"
    start = source.find("def test_check")
    body = source[start:].split("\ndef ")[0]
    assert body.count("assert") >= 4, "Write at least four asserts in test_check."
    test_check()
def test_program():
    "the main program"
    expect_output("Password: hello world\nNeeds a capital letter; Needs a digit; No spaces allowed", inputs=["hello world"], echo=True)
    expect_output("Password: Str0ngPass\nOK", inputs=["Str0ngPass"], echo=True)
    expect_output("Password: Ab1\nAt least 8 characters", inputs=["Ab1"], echo=True)
@@hint
`min_length` and `needs` are factories, like `make_multiplier`: define a function inside, using `n` (or `test` and `what`), and return it.
@@hint
`check` loops over `rules`, calls each one with the password, and collects the non-empty messages into a string.
@@solution
def min_length(n):
    """Return a rule that complains if a password is shorter than n."""
    def rule(password):
        return f"At least {n} characters" if len(password) < n else ""
    return rule

def needs(test, what):
    """Return a rule that complains if no character passes test."""
    def rule(password):
        for ch in password:
            if test(ch):
                return ""
        return f"Needs {what}"
    return rule

def no_spaces(password):
    """Complain if the password contains a space."""
    return "No spaces allowed" if " " in password else ""

def check(password, *rules):
    """Return every complaint from rules, joined by '; ', or 'OK'."""
    complaints = ""
    for rule in rules:
        message = rule(password)
        if message:
            complaints = message if complaints == "" else complaints + "; " + message
    return complaints if complaints else "OK"

def test_check():
    assert check("anything") == "OK"
    assert check("Abcdefg1", min_length(8)) == "OK"
    assert check("ab", min_length(3)) == "At least 3 characters"
    assert check("ab", min_length(3), needs(str.isdigit, "a digit")) == "At least 3 characters; Needs a digit"

rules = (min_length(8), needs(str.isupper, "a capital letter"), needs(str.isdigit, "a digit"), no_spaces)
password = input("Password: ")
print(check(password, *rules))
:::

:::think title="Why rules as functions?"
Suppose the website adds a rule tomorrow: "needs a symbol". With one big function, you'd edit its middle and hope nothing else breaks. With rules as functions, you write `needs(lambda c: not c.isalnum(), "a symbol")` and add it to the tuple. Nothing else changes, and `test_check` still guards the checker. This idea of building behaviour out of small interchangeable functions is used all over professional software.
:::

## Forge bonus: encode, decode, round trip

:::exercise id=forge2 points=30 title="Forge bonus: round trip"
In Week 4 you wrote run-length **encoding**: `aaabcc` becomes `a3b1c2`. Now write both directions, and test them against each other.

1. `encode(text)` returns the run-length encoding. Text may contain any characters except digits.
2. `decode(code)` turns an encoding back into the text. A count may have several digits: `x12` means twelve `x`s.
3. `test_round_trip()` checks that `decode(encode(s)) == s` for at least six different strings, including the empty string, a single character, and a run longer than 9.

A **round-trip test** checks two functions that undo each other at the same time: if either is wrong, the round trip almost always fails.
@@starter
def encode(text):
    """Return the run-length encoding of text."""
    ___

def decode(code):
    """Return the text that the run-length code stands for."""
    ___

def test_round_trip():
    pass

@@tests
def test_encode():
    "encode"
    assert encode("aaabcc") == "a3b1c2"
    assert encode("") == ""
    assert encode("x" * 12) == "x12"
def test_decode():
    "decode"
    assert decode("a3b1c2") == "aaabcc"
    assert decode("x12y1") == "x" * 12 + "y"
    assert decode("") == ""
def test_your_round_trip():
    "your round-trip test"
    start = source.find("def test_round_trip")
    body = source[start:].split("\ndef ")[0]
    assert body.count("assert") >= 1 and (body.count('"') + body.count("'")) >= 12, "Check at least six strings."
    test_round_trip()
def test_catches():
    "your round trip catches a broken decode"
    g = test_round_trip.__globals__
    good = g["decode"]
    def bad(code):
        out, i = "", 0
        while i < len(code):
            out += code[i] * int(code[i + 1])
            i += 2
        return out
    g["decode"] = bad
    try:
        try:
            test_round_trip()
        except (AssertionError, ValueError, IndexError):
            return
        assert False, "Your round trip passed a decode that only reads one-digit counts. Include a run longer than 9."
    finally:
        g["decode"] = good
@@hint
`decode` walks through the code: take a character, then collect every digit after it into a number string, then add that many of the character.
@@solution
def encode(text):
    """Return the run-length encoding of text."""
    if text == "":
        return ""
    out = ""
    current = text[0]
    count = 1
    for ch in text[1:]:
        if ch == current:
            count += 1
        else:
            out += current + str(count)
            current = ch
            count = 1
    return out + current + str(count)

def decode(code):
    """Return the text that the run-length code stands for."""
    out = ""
    i = 0
    while i < len(code):
        ch = code[i]
        i += 1
        digits = ""
        while i < len(code) and code[i].isdigit():
            digits += code[i]
            i += 1
        out += ch * int(digits)
    return out

def test_round_trip():
    for s in ["", "a", "aaabcc", "abc", "z" * 25 + "y", "hello  world!!"]:
        assert decode(encode(s)) == s, f"round trip failed for {s!r}"
:::
