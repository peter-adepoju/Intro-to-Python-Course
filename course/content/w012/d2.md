## Warm-up

:::predict
def f(items):
    items.append(1)
    items = [9]
    return items

a = [0]
b = f(a)
print(a, b)
:::

If you got that right first time, you understand the most important idea of Weeks 8 to 10: a function receives the **same** list, so changing it in place is visible outside, but rebinding the parameter to a new list isn't. If not, keep this one on your list.

## Strings

Strings are immutable, so every method returns a **new** string. `split` and `join` move between text and lists. f-strings format values.

:::predict
s = "  Hello, World  "
t = s.strip().lower().replace("world", "there")
print(repr(s), repr(t))
:::

:::predict
print("a-b-c".split("-"), "-".join(["x", "y"]), "a b  c".split())
:::

:::predict
word = "level"
print(word == word[::-1], word.count("l"), word.find("z"), "ve" in word)
:::

:::key
`s.upper()` doesn't change `s`; you must keep the result. `split()` with no argument splits on any run of whitespace and ignores the ends; `split(" ")` splits on every single space.
:::

## Functions

A function packages steps behind a name. Parameters receive arguments; `return` sends a value back (and a function without it returns `None`); names assigned inside are **local**.

:::predict
def greet(name, greeting="Hello", *, punct="!"):
    return f"{greeting}, {name}{punct}"

print(greet("Ada"), greet("Bo", "Hi"), greet("Cy", punct="?"))
:::

:::predict
def total(*nums, **opts):
    t = sum(nums)
    return round(t, opts.get("places", 0))

print(total(1.25, 2.5), total(1.25, 2.5, places=1))
:::

:::predict
count = 0
def bump():
    count = 1
    return count

print(bump(), count)
:::

:::predict
def apply(f, values):
    return [f(v) for v in values]

print(apply(len, ["a", "bcd"]), apply(lambda x: x * 2, [1, 2]))
:::

:::key
Return values, don't print them, so the caller can use the result. Default values are worked out **once**, when the function is defined: never use a mutable default like `[]`; use `None` and create the list inside.
:::

## Lists, tuples and comprehensions

Lists are mutable sequences; methods like `append`, `sort` and `reverse` change the list and return `None`. Assignment makes **aliases**, not copies. Tuples are immutable, and unpacking pulls values out. Comprehensions build lists in one line.

:::predict
x = [3, 1, 2]
y = x
z = sorted(x)
x.sort()
print(x, y, z, y is x, z is x)
:::

:::predict
grid = [[0] * 2] * 2
grid[0][0] = 1
print(grid)
:::

:::predict
first, *rest = "abcd"
pairs = list(zip("ab", [1, 2, 3]))
print(first, rest, pairs)
:::

:::predict
nums = [4, -1, 7, 0, -3]
print([n * 2 for n in nums if n > 0], [n if n > 0 else 0 for n in nums])
:::

:::predict
words = ["pear", "Fig", "apple"]
print(sorted(words), sorted(words, key=str.lower), sorted(words, key=len, reverse=True))
:::

:::key
`items.sort()` returns `None`; `sorted(items)` returns a new list. `[[0] * 2] * 2` repeats **one** inner list; use `[[0] * 2 for _ in range(2)]`. A filter `if` goes at the **end** of a comprehension; a choice `a if c else b` goes at the **start**.
:::

## Dictionaries and sets

Dictionaries map keys to values, with fast lookup; keys must be hashable. Sets hold unique items, with fast membership and set operations.

:::predict
d = {"a": 1}
d["b"] = d.get("b", 0) + 2
d["a"] += 10
print(d, "a" in d, 11 in d)
:::

:::predict
from collections import Counter
c = Counter("hello world")
print(c["l"], c.most_common(1), c["z"])
:::

:::predict
groups = {}
for w in ["ant", "bee", "ape", "cat", "bat"]:
    groups.setdefault(w[0], []).append(w)
print(groups)
:::

:::predict
a = {1, 2, 3, 4}
b = {3, 4, 5}
print(sorted(a & b), sorted(a | b), sorted(a - b), sorted(a ^ b))
:::

:::key
The four patterns: **counting** (`d[k] = d.get(k, 0) + 1`), **grouping** (`d.setdefault(k, []).append(x)`), **totals**, and **index** (key to record). A set answers "is it in here?" in one step; a list has to search.
:::

## Files and errors

Open files with `with`; read with `read`, `readline`, `readlines` or a `for` loop; write with mode `"w"` (replaces) or `"a"` (adds). Catch specific exceptions; raise your own with clear messages.

:::files
=== data.txt
Ada 93
Bo x
Cy 78
:::

:::predict
total = 0
bad = []
with open("data.txt") as f:
    for line in f:
        name, mark = line.split()
        try:
            total += int(mark)
        except ValueError:
            bad.append(name)
print(total, bad)
:::

:::predict
def check(n):
    if n < 0:
        raise ValueError("negative")
    return n

results = []
for n in [2, -1, 3]:
    try:
        results.append(check(n))
    except ValueError as e:
        results.append(str(e))
print(results)
:::

:::key
Keep `try` blocks small, catch the exception you expect, and never hide errors with `except Exception`. A function that can't do its job should `raise`, not return a special value.
:::

## The classic mistakes, part two

| Mistake | What happens | The fix |
|---|---|---|
| `items = items.sort()` | `items` becomes `None` | `items.sort()` alone, or `items = sorted(items)` |
| `def f(x, seen=[]):` | the list is shared between calls | `seen=None`, then `if seen is None: seen = []` |
| `copy = original` | an alias, not a copy | `original.copy()`, or `copy.deepcopy` for nested data |
| removing from a list while looping over it | items are skipped | loop over a copy, or build a new list |
| `counts[word] += 1` on a new word | `KeyError` | `counts.get(word, 0) + 1`, or `Counter` |
| `{}` for an empty set | it's a dictionary | `set()` |
| opening a file with `"w"` to update it | it's emptied before you read it | read everything first, then write |
| `except:` around everything | real bugs are hidden | catch the specific exception |

:::exercise id=initials points=10 title="Initials"
Write `initials(name)` that returns the initials of a full name in capitals with dots, ignoring extra spaces: `"  ada  lovelace "` gives `"A.L."`. Hyphenated parts count separately: `"Jean-Luc Picard"` gives `"J.L.P."`.
@@starter

@@tests
def test_values():
    "several"
    assert initials("  ada  lovelace ") == "A.L."
    assert initials("Jean-Luc Picard") == "J.L.P."
    assert initials("Plato") == "P."
    assert initials("") == ""
@@solution
def initials(name):
    parts = name.replace("-", " ").split()
    return "".join(p[0].upper() + "." for p in parts)

:::exercise id=stats points=10 title="Several results"
Write `stats(values)` that returns a tuple `(smallest, largest, mean, median)`, the mean rounded to 2 places. The median is the middle value of the sorted list, or the mean of the two middle values. Don't change the list you're given. Raise a `ValueError` for an empty list.
@@starter

@@tests
def test_values():
    "several lists"
    v = [7, 1, 4, 10]
    assert stats(v) == (1, 10, 5.5, 5.5)
    assert v == [7, 1, 4, 10], "stats changed the list"
    assert stats([3, 9, 1]) == (1, 9, 4.33, 3)
    try:
        stats([])
    except ValueError:
        pass
    else:
        raise AssertionError("an empty list should raise a ValueError")
@@solution
def stats(values):
    if not values:
        raise ValueError("no values")
    s = sorted(values)
    n = len(s)
    mid = n // 2
    median = s[mid] if n % 2 else (s[mid - 1] + s[mid]) / 2
    return s[0], s[-1], round(sum(s) / n, 2), median
:::

:::exercise id=dedupe points=10 title="Unique, in order"
Write `unique(items)` that returns a new list of the items with repeats removed, keeping the first appearance of each, using a set for the check.
@@starter

@@tests
def test_values():
    "several"
    assert unique([3, 1, 3, 2, 1]) == [3, 1, 2]
    assert unique("banana") == ["b", "a", "n"]
    assert unique([]) == []
    assert "set(" in source
@@solution
def unique(items):
    seen = set()
    result = []
    for x in items:
        if x not in seen:
            seen.add(x)
            result.append(x)
    return result

:::exercise id=transpose points=10 title="Rows to columns"
Write `columns(rows)` that takes a list of equal-length rows and returns a dictionary from each value in the first row (the header) to the list of values below it in that column.
@@starter

@@tests
def test_values():
    "a table"
    rows = [["name", "mark"], ["Ada", 93], ["Bo", 41]]
    assert columns(rows) == {"name": ["Ada", "Bo"], "mark": [93, 41]}
    assert columns([["a", "b"]]) == {"a": [], "b": []}
@@solution
def columns(rows):
    header, *data = rows
    return {h: [row[i] for row in data] for i, h in enumerate(header)}

:::exercise id=vowel_rank points=10 title="Most vowels"
Write `by_vowels(words)` that returns the words sorted by how many vowels they have, most first, then alphabetically.
@@starter

@@tests
def test_values():
    "several"
    assert by_vowels(["sky", "audio", "tree", "bee", "queue"]) == ["audio", "queue", "bee", "tree", "sky"]
@@solution
def vowels(word):
    return sum(1 for ch in word.lower() if ch in "aeiou")

def by_vowels(words):
    return sorted(words, key=lambda w: (-vowels(w), w))

:::exercise id=inventory points=15 title="Stock from a file"
`stock.txt` has lines like `rice 12`, possibly with blank lines and bad lines. Write `load_stock(name)` that returns a dictionary from item to total quantity (an item can appear on several lines) and a list of the line numbers that couldn't be read, as a tuple. If the file doesn't exist, return `({}, [])`.
@@starter
@@files
=== stock.txt
rice 12
beans 5

rice three
garri 20
beans 2
oil
@@tests
def test_values():
    "the file"
    assert load_stock("stock.txt") == ({"rice": 12, "beans": 7, "garri": 20}, [4, 7])
    assert load_stock("none.txt") == ({}, [])
@@solution
def load_stock(name):
    stock, bad = {}, []
    try:
        with open(name) as f:
            lines = f.read().splitlines()
    except FileNotFoundError:
        return {}, []
    for n, line in enumerate(lines, start=1):
        if not line.strip():
            continue
        parts = line.split()
        try:
            item, qty = parts
            qty = int(qty)
        except ValueError:
            bad.append(n)
            continue
        stock[item] = stock.get(item, 0) + qty
    return stock, bad
:::

:::exercise id=compose points=10 title="Functions as values"
Write `pipeline(*funcs)` that returns a new function which passes its argument through each of `funcs` in order. `pipeline(str.strip, str.lower, len)("  Hi ")` is `2`.
@@starter

@@tests
def test_values():
    "several pipelines"
    assert pipeline(str.strip, str.lower, len)("  Hi ") == 2
    assert pipeline()(5) == 5
    double = lambda x: x * 2
    assert pipeline(double, double, str)(3) == "12"
@@solution
def pipeline(*funcs):
    def run(value):
        for f in funcs:
            value = f(value)
        return value
    return run

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: a tiny search engine"
Build a small search index over some documents. Write:

- `tokens(text)`: the words of `text` in lower case, where a word is a run of letters or digits (everything else separates words).
- `build_index(docs)`: takes a dictionary from document name to text, and returns a dictionary from each word to the **set** of document names containing it.
- `search(index, query)`: returns the sorted list of documents containing **every** word of the query. An empty query gives `[]`.
- `rank(docs, query)`: returns the matching documents (as `search` finds them) sorted by how many times the query words appear in them in total, most first, then by name.
@@starter

@@tests
DOCS = {
    "a.txt": "Python is fun. Python is popular!",
    "b.txt": "Snakes: the python is a large snake.",
    "c.txt": "Fun with numbers, and more fun.",
}
def test_tokens():
    "tokens"
    assert tokens("Snakes: the python, 2 large!") == ["snakes", "the", "python", "2", "large"]
    assert tokens("") == []
def test_index():
    "build_index"
    idx = build_index(DOCS)
    assert idx["python"] == {"a.txt", "b.txt"}
    assert idx["fun"] == {"a.txt", "c.txt"}
    assert idx["snake"] == {"b.txt"}
def test_search():
    "search"
    idx = build_index(DOCS)
    assert search(idx, "Python IS") == ["a.txt", "b.txt"]
    assert search(idx, "fun python") == ["a.txt"]
    assert search(idx, "missing") == []
    assert search(idx, "") == []
def test_rank():
    "rank"
    assert rank(DOCS, "python") == ["a.txt", "b.txt"]
    assert rank(DOCS, "fun") == ["c.txt", "a.txt"]
@@hint
For `tokens`, build words character by character: add a letter or digit (`ch.isalnum()`) to the current word; anything else ends it. Or replace every non-alphanumeric character with a space and split.
@@hint
For `search`, start with the set for the first word (or an empty set if it's not in the index) and intersect it with the set for each other word.
@@solution
def tokens(text):
    cleaned = "".join(ch.lower() if ch.isalnum() else " " for ch in text)
    return cleaned.split()

def build_index(docs):
    index = {}
    for name, text in docs.items():
        for word in tokens(text):
            index.setdefault(word, set()).add(name)
    return index

def search(index, query):
    words = tokens(query)
    if not words:
        return []
    found = set(index.get(words[0], set()))
    for w in words[1:]:
        found &= index.get(w, set())
    return sorted(found)

def rank(docs, query):
    words = tokens(query)
    matches = search(build_index(docs), query)
    def score(name):
        doc_words = tokens(docs[name])
        return sum(doc_words.count(w) for w in words)
    return sorted(matches, key=lambda name: (-score(name), name))
:::
