## Values have types

A **value** is a single piece of data: `42`, `3.14`, `"hello"`. Every value has a **type**, which tells Python what kind of thing it is and what you can do with it. Remember the eight switches from yesterday: the same bits can be a number or a letter. The type decides.

Today's four basic types:

| Type | Name | Examples | What it's for |
|---|---|---|---|
| `int` | integer | `7`, `0`, `-12`, `1_000_000` | whole numbers |
| `float` | floating-point number | `3.14`, `-0.5`, `2.0`, `1e3` | numbers with a decimal point |
| `str` | string | `"hi"`, `'42'`, `""` | text |
| `bool` | Boolean | `True`, `False` | yes/no, on/off |

Try sorting these values into their types. Then ask Python to check. Some are traps — look closely at quotes and decimal points.

:::widget typesorter caption="Twelve values, four types. Some are traps: look closely at quotes and decimal points."
{}
:::

The rule that catches most people: **anything in quotes is a string**, even if it looks like a number. `"42"` is text made of the characters `4` and `2`. And `2.0` is a float, not an int, because it has a decimal point.

### Asking Python: type()

The function `type()` tells you the type of any value.

:::example
print(type(42))
print(type(3.14))
print(type("42"))
print(type(True))
:::

`<class 'int'>` is Python's way of saying "the type int". (Types are called *classes* in Python; you'll make your own in Phase 3.)

Use the inspector below to look at any value. Try `2 ** 100`: a gigantic number. Python's ints can be as big as your memory allows.

:::widget typeinspect caption="Type any value or calculation. Python reports its type, how it shows it, and how many bytes of memory it takes."
{}
:::

### Writing numbers

- Long numbers can use underscores to make them readable: `1_000_000` is one million. The underscores are ignored.
- `1e3` means 1 × 10³ = `1000.0` (a float). `2.5e-3` is `0.0025`. This is *scientific notation*.
- Don't write commas inside numbers: `1,000` isn't one thousand in Python — it's two values, `1` and `0`, separated by a comma.

:::predict
print(1_000_000)
print(1e3)
print(1,000)
:::

## The arithmetic operators

Python has seven arithmetic operators. Drag the sliders below and watch all seven results update at once.

:::widget operators caption="All seven operators on the same two numbers. Try a = 17, b = 5, then a = -17. Try b = 0."
{"a": 17, "b": 5}
:::

| Operator | Meaning | Example | Result |
|---|---|---|---|
| `+` | add | `7 + 2` | `9` |
| `-` | subtract | `7 - 2` | `5` |
| `*` | multiply | `7 * 2` | `14` |
| `/` | divide | `7 / 2` | `3.5` |
| `//` | floor divide (divide and round down) | `7 // 2` | `3` |
| `%` | remainder ("modulo") | `7 % 2` | `1` |
| `**` | power | `7 ** 2` | `49` |

`//` and `%` are a pair: `7 // 2` is how many whole 2s fit into 7 (three), and `7 % 2` is what's left over (one). On Day 4 you'll explore them properly — they're more useful than they look.

:::example
print(17 / 5)
print(17 // 5)
print(17 % 5)
print(2 ** 10)
:::

### int or float?

Python follows simple rules for the type of the answer:

1. `/` **always** gives a float, even when the division is exact: `6 / 3` is `2.0`.
2. If **either** side is a float, the answer is a float: `2 + 1.0` is `3.0`.
3. Otherwise (`int` with `int`, using `+ - * // % **`) the answer is an int.

:::predict
print(6 / 3)
print(6 // 3)
print(2 * 3.0)
print(2 ** 3)
:::

:::key
`/` means "divide exactly, give me a float". `//` means "how many whole times does it fit". Choose deliberately.
:::

### Errors with arithmetic

Dividing by zero has no answer, so Python raises an error.

:::example error=yes
print(10 / 0)
:::

And arithmetic between a number and text doesn't work (we'll come back to this on Day 4):

:::example error=yes
print("10" + 5)
:::

## Order of operations

What is `2 + 3 * 4`? It depends on which you do first. Python follows fixed rules, the same ones you learnt in school, often remembered as **BODMAS** or **PEMDAS**:

1. **Brackets** first: `( )`
2. **Powers**: `**`
3. **Multiplying and dividing**: `* / // %` (left to right)
4. **Adding and subtracting**: `+ -` (left to right)

Don't just trust the rule: watch Python apply it. Press **Next step** to see exactly which part Python works out next. Then choose another example from the list, or type your own.

:::stepper caption="Python evaluates an expression one small step at a time. The yellow part is always what it works out next."
2 + 3 * 4
(2 + 3) * 4
2 + 3 * 4 ** 2
10 - 4 - 3
100 / 10 / 5
2 ** 3 ** 2
(1 + 2) * (3 + 4) - 5
7 + 10 // 3 % 2
:::

Two surprises worth looking at in the stepper:

- `10 - 4 - 3` is worked from **left to right**: `(10 - 4) - 3` = 3, not `10 - (4 - 3)` = 9.
- `2 ** 3 ** 2` is worked from **right to left**: `2 ** (3 ** 2)` = `2 ** 9` = 512. Powers are the exception.

And one more trap:

:::predict
print(-3 ** 2)
print((-3) ** 2)
:::

`**` is done before the minus sign, so `-3 ** 2` is `-(3 ** 2)` = `-9`. When in doubt, **add brackets**. Brackets never hurt, and they make your intention clear to the next person who reads your code.

:::tip
Professional programmers add brackets even when they're not strictly needed, if it makes an expression easier to read. `(price * quantity) + delivery` is clearer than relying on everyone remembering the rules.
:::

## Python as a calculator

You now have a calculator more powerful than any you can buy. Here are some everyday problems.

:::example title="Shopping"
# 3 loaves at 1200 naira, 2 cartons of milk at 950
print("Total:", 3 * 1200 + 2 * 950)
:::

:::example title="Converting temperature"
# Celsius to Fahrenheit: F = C × 9/5 + 32
print("30 °C is", 30 * 9 / 5 + 32, "°F")
:::

:::example title="Minutes and hours"
# 135 minutes is how many hours and minutes?
print(135 // 60, "hours and", 135 % 60, "minutes")
:::

That last one is a pattern you'll use again and again: `//` to count whole units, `%` for what's left over.

## Quiz

:::quiz id=quiz
- q: What is the type of `"3.5"`?
  options: ["int", "float", "str", "bool"]
  answer: 2
  explain: "It's in quotes, so it's a string."
- q: What does this print?
  type: output
  code: |
    print(9 / 3)

  type: text
  answer: "14"
  explain: "Multiplication first: 3 * 4 is 12, then 2 + 12."
- q: What is the value of `2 ** 3 ** 2`?
  options: ["64", "512", "36", "18"]
  answer: 1
  explain: "Powers go right to left: 3 ** 2 is 9, then 2 ** 9 is 512."
- q: What is the type of `4 + 1.0`?
  options: ["int", "float", "str"]
  answer: 1
  explain: "If either side is a float, the answer is a float: 5.0."

  type: output
  code: |
    print(-2 ** 2)
  answer: "-4"
  explain: "** happens before the minus sign: -(2 ** 2)."
- q: What is `1e2`?
  options: ["The int 100", "The float 100.0", "The string '1e2'", "An error"]
  answer: 1
  explain: "Scientific notation always makes a float."
- q: Which expression gives the number of whole weeks in 50 days?
  options: ["`50 / 7`", "`50 // 7`", "`50 % 7`", "`50 ** 7`"]

## Daily challenge

:::exercise id=challenge points=20 title="Challenge: the time machine"
A film lasts 10 000 seconds. Print its length in the form below, calculating every number from `10000` with `//` and `%`:

```
2 hours
46 minutes
40 seconds
```

Then, on a fourth line, prove your answer is right: print the total seconds rebuilt from your three numbers (it should print `10000`).
@@starter
# 1 hour = 3600 seconds
@@tests
def test_output():
    "prints the breakdown and the check"
    expect_output("2 hours\n46 minutes\n40 seconds\n10000")
def test_calc():
    "everything is calculated from 10000"
    assert "46" not in source and "40" not in source, "Calculate 46 and 40 with // and %, don't type them."
@@hint
Minutes: first take the remainder after removing the hours (`10000 % 3600`), then divide that by 60.
@@solution
print(10000 // 3600, "hours")
print(10000 % 3600 // 60, "minutes")
print(10000 % 60, "seconds")
print(10000 // 3600 * 3600 + 10000 % 3600 // 60 * 60 + 10000 % 60)
:::
