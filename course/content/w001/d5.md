## Warm-up

:::predict
n = 7
print(n // 2, n % 2, round(n / 2))
print("7" * 2)
:::

The last line is a preview: `*` works on strings too. Let's find out why.

## A string is a sequence of characters

A **string** (`str`) is a sequence of characters in a particular order. Each character sits at a numbered position, called its **index**. Python starts counting at **0**.

:::widget strruler caption="Each character has two addresses: its position from the left (blue, starting at 0) and from the right (purple, starting at -1). Change the string and the index."
{"text": "Python", "mode": "index"}
:::

Spaces and punctuation are characters too: `"Hi there!"` has 9 characters.

## Writing strings

### Quotes

Single and double quotes make exactly the same kind of string. Choosing one lets you put the other inside without trouble:

:::example
print("It's sunny.")
print('She said "hello".')
:::

**Triple quotes** (`"""` or `'''`) let a string run over several lines:

:::example
poem = """Roses are red,
Python is too,
it reads like English
and works well for you."""
print(poem)
:::

### Escape sequences

Some characters are hard to type inside a string: a new line, a tab, or the same quote you used to open the string. A backslash `\` starts an **escape sequence**: the backslash and the character after it together stand for one special character.

| You type | You get |
|---|---|
| `\n` | a new line |
| `\t` | a tab |
| `\\` | one backslash |
| `\'` | a single quote |
| `\"` | a double quote |

Type a string literal below and look inside it. Notice that `\n` takes two keystrokes but is stored as **one** character.

:::widget escapes caption="Every character inside a string, including invisible ones. Escapes are highlighted. Try the Windows path and the raw string r'...'."
{}
:::

:::predict
print("one\ttwo\nthree")
:::

A **raw string**, written with an `r` before the quote, switches escapes off. It's handy for Windows paths and, later, regular expressions (Week 23): `r"C:\new\table"` keeps its backslashes.

:::mistake
`print("C:\new folder")` prints `C:` and then a line break, then `ew folder`, because `\n` became a new line. Use `"C:\\new folder"` or `r"C:\new folder"`.
:::

## Length, joining and repeating

`len(s)` gives the number of characters:

:::example
print(len("Python"))
print(len("Hi there!"))
print(len(""))
:::

`""` is the **empty string**: a string with no characters at all. It's still a string.

`+` joins two strings (this is called **concatenation**), and `*` repeats a string a whole number of times:

:::stepper caption="Strings follow the same order of operations: * before +."
"ab" + "cd" * 2
("ab" + "cd") * 2
"=" * 10
"Hip " * 2 + "hooray!"
:::

:::example
first = "Ada"
last = "Lovelace"
full = first + " " + last
print(full)
print("-" * len(full))
:::

The second line draws a line exactly as long as the name. Change the name and the line still fits.

## Indexing: one character

`s[i]` gives the character at index `i`. Remember: the first is at index 0, so the last is at `len(s) - 1`.

:::example
word = "Python"
print(word[0])
print(word[1])
print(word[5])
:::

Counting from the right uses **negative** indices: `-1` is the last character, `-2` the one before.

:::example
word = "Python"
print(word[-1])
print(word[-2])
print(word[len(word) - 1])
:::

Asking for an index that doesn't exist raises `IndexError`:

:::example error=yes
word = "Python"
print(word[6])
:::

:::key
For a string of length n, valid indices are 0 to n − 1, and −1 to −n. The last character is always `s[-1]` — no need to work out the length.
:::

## Slicing: cutting out pieces

A **slice** `s[start:stop]` gives a new string from index `start` up to **but not including** `stop`. Use the ruler: set start and stop, and watch which boxes light up.

:::widget strruler caption="Set start, stop and step. The highlighted boxes are the slice; small numbers show the order they're taken in. Try the preset buttons, including the ones with negative steps."
{"text": "Python", "mode": "slice"}
:::

Why "up to but not including"? Because then `stop - start` is exactly the length of the slice, and `s[:k] + s[k:]` is always the whole string. You'll come to like it.

:::example
word = "Python"
print(word[0:2])
print(word[2:6])
print(word[:2] + word[2:])
:::

Leave out `start` to begin at the start; leave out `stop` to go to the end:

:::predict
s = "Hello, world"
print(s[:5])
print(s[7:])
print(s[-5:])
:::

### The step

A third number, the **step**, says how far to jump: `s[::2]` takes every second character. A **negative step** walks backwards, so `s[::-1]` is the whole string reversed.

:::predict
s = "abcdefgh"
print(s[::2])
print(s[1::2])
print(s[::-1])
:::

### Slices are forgiving

An index out of range is an error, but a slice that goes too far is simply cut short. A slice can even be empty:

:::example
s = "cat"
print(s[1:100])
print(s[5:10])
print(len(s[5:10]))
:::

## Strings can't be changed

Strings are **immutable**: once made, a string object never changes. You can't replace a character inside one:

:::example error=yes
name = "Jython"
name[0] = "P"
:::

Instead, build a **new** string and point the name at it:

:::example
name = "Jython"
name = "P" + name[1:]
print(name)
:::

X-ray that and watch: a new object `'Python'` appears and the label `name` moves to it. Strings in Python always work this way — every "change" makes a new string. You'll see why that's a good thing in Week 8.

## Quiz

:::quiz id=quiz
- q: What does `len("a b")` give?
  type: text
  answer: "3"
  explain: "The space is a character too."
- q: What does this print?
  type: output
  code: |
    s = "Lagos"
    print(s[1], s[-1])
  answer: "a s"
  explain: "Index 1 is the second character; -1 is the last."
- q: What does this print?
  type: output
  code: |
    s = "abcdef"
    print(s[1:4])
  answer: "bcd"
  explain: "From index 1 up to, but not including, index 4."
- q: What is `"ha" * 3`?
  options: ['`"ha3"`', '`"hahaha"`', "An error", '`"ha ha ha"`']
  answer: 1
  explain: "* repeats a string; no spaces are added."
- q: What is `"python"[::-1]`?
  type: text
  answer: ["nohtyp", "'nohtyp'"]
  explain: "A step of -1 walks backwards through the whole string."
- q: "`s = \"cat\"`. What does `s[3]` do?"
  options: ['Gives `""`', 'Gives `"t"`', "Raises IndexError", 'Gives `"c"`']
  answer: 2
  explain: "Indices are 0, 1, 2. 3 is past the end."
- q: "`s = \"cat\"`. What does `s[1:10]` give?"
  options: ['`"at"`', "IndexError", '`"cat"`', '`""`']
  answer: 0
  explain: "Slices that go too far are cut short without an error."
- q: How many characters are in `"a\nb"`?
  options: ["2", "3", "4"]
  answer: 1
  explain: "\\n is typed with two keys but stored as one newline character."
- q: What happens with `s = "hat"` then `s[0] = "c"`?
  options: ["s becomes 'cat'", "TypeError: strings can't be changed", "A new string 'cat' is made"]
  answer: 1
  explain: "Strings are immutable. Build a new one: s = 'c' + s[1:]."
- q: For any string `s` and whole number `k`, which is always equal to `s`?
  options: ["`s[:k] + s[k+1:]`", "`s[:k] + s[k:]`", "`s[k:] + s[:k]`"]
  answer: 1
  explain: "Because stop is excluded, the two slices meet exactly at k."
:::

## Daily challenge

:::exercise id=challenge points=20 title="Challenge: palindrome parts"
A palindrome reads the same backwards. `word = "racecar"`. Without typing any letters of the word again:

1. Print the word reversed.
2. Print the first half of the word (up to but not including the middle letter): `rac`.
3. Print the middle letter: `e`.
4. Print the second half after the middle letter: `car`.
5. Print the first half followed by the middle letter followed by the *reversed first half*. For a palindrome this rebuilds the word: `racecar`.

The checks also try your program on another odd-length palindrome.
@@starter
word = "racecar"

@@tests
def test_output():
    "prints the five lines"
    expect_output("racecar\nrac\ne\ncar\nracecar")
def test_no_letters():
    "doesn't type the letters"
    assert source.count("race") == 1 and "\"rac\"" not in source and "'rac'" not in source, "Build everything from word with slices."
def test_other_word():
    "works for another palindrome"
    got = norm(run_with({'"racecar"': '"rotator"'}))
    assert got == "rotator\nrot\na\ntor\nrotator", "With word = 'rotator' your program printed:\n" + got
@@hint
`mid = len(word) // 2`. The first half is `word[:mid]`, the middle is `word[mid]`, the second half `word[mid + 1:]`.
@@solution
word = "racecar"
mid = len(word) // 2
print(word[::-1])
print(word[:mid])
print(word[mid])
print(word[mid + 1:])
print(word[:mid] + word[mid] + word[:mid][::-1])
:::
