## Warm-up

:::predict
stock = {"rice": 12, "beans": 5}
print(stock.get("yam", 0))
stock["yam"] = stock.get("yam", 0) + 4
for item, n in stock.items():
    print(item, n)
:::

`get` with a default, and `items` with unpacking: you'll use both constantly. Today adds the methods that make other common jobs one line.

## Removing and filling in

### pop

`d.pop(key)` removes an entry and **returns its value**. Like `del`, it raises `KeyError` if the key isn't there, unless you give a default:

:::example
basket = {"apple": 3, "pear": 2}
n = basket.pop("apple")
print(n, basket)
print(basket.pop("plum", 0), basket)
:::

`d.popitem()` removes and returns the **last** entry added, as a `(key, value)` tuple. It's handy for using a dictionary like a stack.

`d.clear()` removes everything.

### setdefault

`d.setdefault(key, default)` returns the value for `key` if it's there. If it isn't, it **adds** `key` with the value `default` first, then returns that:

:::example
groups = {}
groups.setdefault("A", []).append("Ada")
groups.setdefault("B", []).append("Bo")
groups.setdefault("A", []).append("Alan")
print(groups)
:::

That line reads "get the list for this key, making an empty one if there isn't one yet, and append to it". You'll use it on Day 3 for grouping.

:::key
`get(key, default)` **reads** without changing the dictionary. `setdefault(key, default)` **adds** the default when the key is missing. `pop(key, default)` **removes** the key if it's there.
:::

## Merging

`a.update(b)` copies every entry of `b` into `a`, changing `a` in place. Where both have the same key, **`b`'s value wins**:

:::example
settings = {"theme": "light", "size": 14}
mine = {"theme": "dark", "sound": False}
settings.update(mine)
print(settings)
:::

From Python 3.9, `a | b` makes a **new** merged dictionary and leaves both alone, and `a |= b` is the same as `a.update(b)`. Again, the right-hand side wins:

:::example
defaults = {"theme": "light", "size": 14}
mine = {"size": 18}
print(defaults | mine)
print(mine | defaults)
print(defaults)
:::

This is the usual way to combine **defaults** with someone's own choices: start with the defaults, merge their choices over the top.

## Building dictionaries

### dict and zip

`dict` turns a sequence of pairs into a dictionary. With `zip`, that's two lists into one dictionary:

:::example
names = ["Ada", "Grace", "Alan"]
marks = [93, 88, 97]
print(dict(zip(names, marks)))
print(dict([("x", 1), ("y", 2)]))
:::

`dict` can also take keyword arguments, when the keys are simple words: `dict(name="Ada", year=1815)`.

### Dictionary comprehensions

A **dictionary comprehension** is a list comprehension with `key: value` in front and curly brackets around it:

:::example
squares = {n: n * n for n in range(1, 6)}
print(squares)
words = ["tea", "biscuits", "jam"]
print({w: len(w) for w in words})
:::

You can filter, and transform an existing dictionary through `items()`:

:::example
prices = {"tea": 150, "coffee": 900, "bread": 950, "egg": 120}
cheap = {item: p for item, p in prices.items() if p < 500}
with_vat = {item: round(p * 1.075, 2) for item, p in prices.items()}
print(cheap)
print(with_vat)
:::

### fromkeys, and its trap

`dict.fromkeys(keys, value)` gives every key the **same** value. That's fine for numbers and strings:

:::example
print(dict.fromkeys(["a", "b", "c"], 0))
:::

But "the same value" means the same **object**. With a list, every key shares one list, the same trap as `[[0] * 3] * 2` for grids:

:::example
groups = dict.fromkeys(["A", "B"], [])
groups["A"].append("Ada")
print(groups)
:::

:::mistake
Never use `dict.fromkeys` with a mutable value such as `[]`. Use a comprehension, which makes a new list for each key: `{k: [] for k in keys}`.
:::

## Sorting and inverting

A dictionary keeps the order its entries were added; it has no `sort` method. To go through it in another order, sort its **items**:

:::example
marks = {"Grace": 88, "Ada": 93, "Alan": 97, "Bo": 41}
for name, mark in sorted(marks.items()):
    print(name, mark)
print()
for name, mark in sorted(marks.items(), key=lambda kv: kv[1], reverse=True):
    print(name, mark)
:::

The first sorts by key (tuples compare by their first item). The second sorts by value, highest first: each item `kv` is a `(key, value)` tuple, so `kv[1]` is the value.

`dict(sorted(...))` turns the sorted pairs back into a dictionary in that order, if you need one.

To find the key with the largest value, `max(marks, key=marks.get)` reads: of the keys, the one whose `marks.get(key)` is largest.

:::example
marks = {"Grace": 88, "Ada": 93, "Alan": 97, "Bo": 41}
print(max(marks, key=marks.get), min(marks, key=marks.get))
:::

### Inverting

**Inverting** a dictionary swaps keys and values, so you can look up in the other direction:

:::example
code = {"NG": "Nigeria", "GH": "Ghana"}
name_to_code = {v: k for k, v in code.items()}
print(name_to_code["Ghana"])
:::

That only works cleanly when the values are all different and hashable. If two keys share a value, the later one silently wins. You'll handle that properly with grouping tomorrow.

## Views and copies

`keys()`, `values()` and `items()` don't make copies. They return **views**: live windows onto the dictionary that change when it does:

:::example
d = {"a": 1}
ks = d.keys()
d["b"] = 2
print(ks)
print(list(ks))
:::

Views support `len`, `in` and looping. `keys()` and `items()` also support set operations, which you'll meet on Day 5. Wrap a view in `list(...)` when you need a fixed snapshot, or need to index it.

Assignment never copies a dictionary, exactly as with lists:

:::example
a = {"x": 1}
b = a
c = a.copy()
b["y"] = 2
print(a)
print(c)
:::

`d.copy()` (or `dict(d)`) is a **shallow** copy: a new dictionary holding the same values. If the values are lists, both dictionaries share those lists, just like a shallow copy of a list of lists.

@@solution
def invert(d):
    result = {}
    for k, v in d.items():
        result.setdefault(v, k)
    return result

:::exercise id=take points=10 title="Take from the basket"
Write `take(basket, item, n)` that removes `n` of `item` from the basket in place and returns how many were actually taken. You can't take more than there are; if the count reaches 0, remove the item entirely. A missing item gives 0.
@@starter

@@tests
def test_values():
    "several calls"
    b = {"apple": 3, "pear": 2}
    assert take(b, "apple", 2) == 2 and b == {"apple": 1, "pear": 2}
    assert take(b, "pear", 5) == 2 and b == {"apple": 1}
    assert take(b, "plum", 1) == 0 and b == {"apple": 1}
@@solution
def take(basket, item, n):
    have = basket.get(item, 0)
    taken = min(have, n)
    if have - taken > 0:
        basket[item] = have - taken
    else:
        basket.pop(item, None)
    return taken
:::

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: a shopping list from recipes"
A recipe is a dictionary from ingredient to amount in grams. Write:

- `scale(recipe, factor)` returns a new recipe with every amount multiplied by `factor` and rounded to whole grams.
- `combine(recipes)` takes a list of recipes and returns one dictionary of total amounts.
- `shopping_list(recipes, pantry)` returns what you still need to buy: the combined amounts minus what's in the `pantry` dictionary, leaving out anything you already have enough of. Return it as a list of lines `ingredient: amount g`, sorted by amount, largest first (ties alphabetically).

```
rice = {"rice": 400, "tomato": 300, "pepper": 50, "oil": 60}
stew = {"tomato": 500, "pepper": 100, "onion": 150, "oil": 80}
pantry = {"oil": 500, "rice": 100, "pepper": 30}
shopping_list([rice, scale(stew, 0.5)], pantry)
->  ["tomato: 550 g", "rice: 300 g", "onion: 75 g", "pepper: 70 g"]
```
@@starter

@@tests
rice = {"rice": 400, "tomato": 300, "pepper": 50, "oil": 60}
stew = {"tomato": 500, "pepper": 100, "onion": 150, "oil": 80}
def test_scale():
    "scale"
    assert scale(stew, 0.5) == {"tomato": 250, "pepper": 50, "onion": 75, "oil": 40}
    assert stew["tomato"] == 500, "scale changed the recipe"
    assert scale({"salt": 3}, 1.5) == {"salt": 4} or scale({"salt": 3}, 1.5) == {"salt": 5}
def test_combine():
    "combine"
    assert combine([rice, stew]) == {"rice": 400, "tomato": 800, "pepper": 150, "oil": 140, "onion": 150}
    assert combine([]) == {}
    assert rice == {"rice": 400, "tomato": 300, "pepper": 50, "oil": 60}, "combine changed a recipe"
def test_list():
    "shopping_list"
    pantry = {"oil": 500, "rice": 100, "pepper": 30}
    assert shopping_list([rice, scale(stew, 0.5)], pantry) == ["tomato: 550 g", "rice: 300 g", "onion: 75 g", "pepper: 70 g"]
    assert shopping_list([rice], {"rice": 400, "tomato": 300, "pepper": 50, "oil": 60}) == []
    assert shopping_list([{"b": 10, "a": 10}], {}) == ["a: 10 g", "b: 10 g"]
@@hint
In `combine`, start with `total = {}` and, for every amount in every recipe, `total[item] = total.get(item, 0) + amount`.
@@hint
In `shopping_list`, work out `need = combined amount - pantry.get(item, 0)` for each item and keep those above 0. Sort the `(item, need)` pairs with `key=lambda kv: (-kv[1], kv[0])`.
@@solution
def scale(recipe, factor):
    return {item: round(g * factor) for item, g in recipe.items()}

def combine(recipes):
    total = {}
    for recipe in recipes:
        for item, grams in recipe.items():
            total[item] = total.get(item, 0) + grams
    return total

def shopping_list(recipes, pantry):
    need = {}
    for item, grams in combine(recipes).items():
        short = grams - pantry.get(item, 0)
        if short > 0:
            need[item] = short
    pairs = sorted(need.items(), key=lambda kv: (-kv[1], kv[0]))
    return [f"{item}: {grams} g" for item, grams in pairs]
:::
