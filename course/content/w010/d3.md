## Counting

The **counting pattern** keeps one entry per distinct item, holding how many times it has been seen:

```
counts = {}
for item in items:
    counts[item] = counts.get(item, 0) + 1
```

`counts.get(item, 0)` is the count so far, or 0 for an item seen for the first time. Step through it and watch the dictionary grow:

:::widget tracetable caption="One row per line run. Watch counts: a new key appears the first time a letter is seen, and its count goes up each time after."
{"code": "counts = {}\nfor ch in \"banana\":\n    counts[ch] = counts.get(ch, 0) + 1\nprint(counts)"}
:::

Anything hashable can be counted: words, letters, numbers, tuples.

:::example title="Word frequencies"
text = "the cat sat on the mat the end"
counts = {}
for word in text.split():
    counts[word] = counts.get(word, 0) + 1
print(counts)
print(counts["the"])
:::

### The most common

Sort the entries by count, highest first:

:::example
counts = {"the": 3, "cat": 1, "sat": 1, "mat": 2}
ranked = sorted(counts.items(), key=lambda kv: kv[1], reverse=True)
print(ranked[:2])
print(max(counts, key=counts.get))
:::

### A text histogram

Counts are easy to draw as bars:

:::example
rolls = [3, 6, 2, 6, 6, 1, 3, 5, 6, 2]
counts = {}
for r in rolls:
    counts[r] = counts.get(r, 0) + 1
for face in range(1, 7):
    n = counts.get(face, 0)
    print(face, "#" * n, n)
:::

Notice `range(1, 7)` and `get(face, 0)`: looping over every possible face, not just the ones that came up, so a face that never appeared still gets a line.

:::key
**Counting:** `counts[x] = counts.get(x, 0) + 1`. Use it whenever a problem says "how many of each", "how often", or "the most common".
:::

## Grouping

The **grouping pattern** collects items into lists, one list per key:

```
groups = {}
for item in items:
    key = the property to group by
    groups.setdefault(key, []).append(item)
```

:::example title="Words by first letter"
words = ["apple", "bean", "avocado", "cherry", "banana", "apricot"]
groups = {}
for w in words:
    groups.setdefault(w[0], []).append(w)
print(groups)
print(groups["a"])
:::

The key can be anything you can work out from the item: its length, its first letter, whether it passed, which band a number falls in.

:::example title="Students by grade"
marks = {"Ada": 93, "Bo": 41, "Cy": 78, "Di": 55, "Ed": 71}
by_grade = {}
for name, m in marks.items():
    grade = "A" if m >= 70 else "B" if m >= 50 else "F"
    by_grade.setdefault(grade, []).append(name)
print(by_grade)
:::

### Anagrams

A classic use: two words are **anagrams** if they use the same letters, so `"".join(sorted(word))` is the same for both. Group by that:

:::example
words = ["listen", "silent", "enlist", "google", "inlets", "banana"]
groups = {}
for w in words:
    groups.setdefault("".join(sorted(w)), []).append(w)
for key, group in groups.items():
    if len(group) > 1:
        print(group)
:::

:::key
**Grouping:** `groups.setdefault(key, []).append(item)`. Use it whenever a problem says "for each X, list the Ys" or "group by".
:::

## Totals and indexes

### Totals per group

The **totals** pattern is counting with an amount instead of 1:

:::example
sales = [("Lagos", 500), ("Abuja", 300), ("Lagos", 200), ("Kano", 150), ("Abuja", 50)]
totals = {}
for city, amount in sales:
    totals[city] = totals.get(city, 0) + amount
print(totals)
:::

To find an **average** per group, keep the totals and the counts (or group the amounts into lists and average each list).

### Indexing records

When each record has a **unique** field, such as an ID or a username, a dictionary from that field to the record lets you find any record at once:

:::example
books = [
    ("978-0", "Things Fall Apart", 1958),
    ("978-1", "Half of a Yellow Sun", 2006),
    ("978-2", "The Famished Road", 1991),
]
by_isbn = {}
for book in books:
    by_isbn[book[0]] = book
print(by_isbn["978-2"])
print(by_isbn["978-1"][1])
:::

This is exactly what last week's league table needed: a dictionary from team name to that team's row.

## Counter and defaultdict

These patterns are so common that Python's standard library has tools for them, in the `collections` module.

### Counter

`Counter` counts everything in a sequence in one go. It's a dictionary, with extras:

:::example
from collections import Counter
counts = Counter("mississippi")
print(counts)
print(counts["s"], counts["z"])
print(counts.most_common(2))
:::

Two things to notice. A missing key gives **0**, not a `KeyError`. And `most_common(n)` gives the top `n` as `(item, count)` pairs.

`from collections import Counter` brings in just the name `Counter`, so you can write `Counter(...)` instead of `collections.Counter(...)`. You'll learn more about imports in Phase 2.

### defaultdict

`defaultdict` is a dictionary that makes a value for a missing key automatically. You tell it **how** to make one by giving it a function to call: `list` makes `[]`, `int` makes `0`.

:::example
from collections import defaultdict
groups = defaultdict(list)
for w in ["apple", "bean", "avocado", "banana"]:
    groups[w[0]].append(w)
print(dict(groups))
totals = defaultdict(int)
for city, amount in [("Lagos", 500), ("Kano", 150), ("Lagos", 200)]:
    totals[city] += amount
print(dict(totals))
:::

`groups[w[0]].append(w)` works even the first time, because the missing key gets a fresh empty list. Note `list`, not `list()`: you hand over the function, and `defaultdict` calls it when it needs a new value.

:::warn
With a `defaultdict`, even **reading** a missing key adds it. `if groups["z"]:` quietly creates `groups["z"] = []`. Use `in` to check whether a key is there.
:::

:::tip
Learn the hand-written patterns first; they work everywhere and show what's going on. Then use `Counter` and `defaultdict` in your own code: they're clearer, and other programmers expect them. In the exercises today, some ask for one and some for the other.
:::

## Choosing a pattern

| The problem says… | Pattern | Result |
|---|---|---|
| how many of each, how often, most common | counting | key → count |
| for each X, the list of Ys; group by | grouping | key → list |
| total (or average) for each X | totals | key → number |
| find the record for an ID or name | index | key → record |

:::exercise id=letters points=10 title="Letter frequencies"
Write `letter_counts(text)` that counts the letters in `text`, ignoring case and anything that isn't a letter, using the counting pattern by hand (no `Counter`).
@@starter

@@tests
def test_values():
    "several texts"
    assert letter_counts("Aa b!") == {"a": 2, "b": 1}
    assert letter_counts("") == {}
    assert letter_counts("Hello, World") == {"h": 1, "e": 1, "l": 3, "o": 2, "w": 1, "r": 1, "d": 1}

@@solution
def letter_counts(text):
    counts = {}
    for ch in text.lower():
        if ch.isalpha():
            counts[ch] = counts.get(ch, 0) + 1
    return counts

:::exercise id=mode points=10 title="The mode"
The **mode** of a list is its most common value. Write `mode(values)` that returns it; if several values are equally common, return the one that appears first in the list. Return `None` for an empty list.
@@starter

@@tests
def test_values():
    "several lists"
    assert mode([3, 1, 3, 2, 1, 3]) == 3
    assert mode([5, 7, 7, 5]) == 5
    assert mode(["x"]) == "x"
    assert mode([]) is None
@@hint
Count first. Then go through the original list and return the first value whose count equals the largest count.
@@solution
def mode(values):
    if not values:
        return None
    counts = {}
    for v in values:
        counts[v] = counts.get(v, 0) + 1
    best = max(counts.values())
    for v in values:
        if counts[v] == best:
            return v
:::

:::exercise id=by_length points=10 title="Words by length"

def by_length(text):
    groups = {}
    for w in text.split():
        groups.setdefault(len(w), []).append(w)

:::exercise id=averages points=15 title="Average per class"

@@starter

@@tests

def class_averages(records):
    marks = {}
    for name, cls, mark in records:
        marks.setdefault(cls, []).append(mark)
    return {cls: round(sum(ms) / len(ms), 1) for cls, ms in marks.items()}

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: a web server log"
A web server writes one line per request: `ip method path status`. Write `analyse(log)` that takes the whole log as text and returns a report string with:

1. `Requests: N`
2. `Unique visitors: N` (different IPs)
3. `Errors: N` (status 400 or above)
4. `Top pages:` then the 3 most requested paths, one per line as `  path  N`, with the path left-aligned in the width of the longest of those three paths. Ties keep the order the paths were first seen.
5. `Busiest visitor: ip (N requests)`

For example:

```
10.0.0.1 GET /home 200
10.0.0.2 GET /about 200
10.0.0.1 GET /home 200
10.0.0.3 POST /login 401
10.0.0.1 GET /shop 200
10.0.0.2 GET /home 200
```

gives:

```
Requests: 6
Unique visitors: 3
Errors: 1
Top pages:
  /home   3
  /about  1
  /login  1
Busiest visitor: 10.0.0.1 (3 requests)
```

Blank lines in the log should be ignored. You may assume there's at least one request.
@@starter
from collections import Counter

@@tests
from collections import Counter as _C
def ref(log):
    rows = [l.split() for l in log.splitlines() if l.strip()]
    ips = _C(r[0] for r in rows)
    pages = _C(r[2] for r in rows).most_common(3)
    w = max(len(p) for p, _ in pages)
    out = [f"Requests: {len(rows)}", f"Unique visitors: {len(ips)}", f"Errors: {sum(1 for r in rows if int(r[3]) >= 400)}", "Top pages:"]
    out += [f"  {p:<{w}}  {n}" for p, n in pages]
    ip, n = ips.most_common(1)[0]
    out.append(f"Busiest visitor: {ip} ({n} requests)")
    return "\n".join(out)
LOG = "10.0.0.1 GET /home 200\n10.0.0.2 GET /about 200\n10.0.0.1 GET /home 200\n10.0.0.3 POST /login 401\n10.0.0.1 GET /shop 200\n10.0.0.2 GET /home 200\n"
def test_example():
    "the example"
    assert analyse(LOG) == ref(LOG), "Expected:\n" + ref(LOG)
def test_other():
    "another log"
    log = "\n1.1.1.1 GET /a 500\n2.2.2.2 GET /products/list 404\n2.2.2.2 GET /a 200\n\n"
    assert analyse(log) == ref(log), "Expected:\n" + ref(log)
@@hint
Split the text into lines, skip blank ones, and split each line into its four parts. Make one `Counter` of IPs and one of paths.
@@hint
`len(ip_counts)` is the number of different visitors. For the error count, compare `int(status) >= 400`.
@@solution
from collections import Counter

def analyse(log):
    requests = []
    for line in log.splitlines():
        if line.strip():
            requests.append(line.split())
    ips = Counter(r[0] for r in requests)
    pages = Counter(r[2] for r in requests).most_common(3)
    errors = sum(1 for r in requests if int(r[3]) >= 400)
    width = max(len(path) for path, n in pages)
    lines = [f"Requests: {len(requests)}", f"Unique visitors: {len(ips)}", f"Errors: {errors}", "Top pages:"]
    for path, n in pages:
        lines.append(f"  {path:<{width}}  {n}")
    ip, n = ips.most_common(1)[0]
    lines.append(f"Busiest visitor: {ip} ({n} requests)")
    return "\n".join(lines)
:::
