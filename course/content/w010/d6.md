## Mixed review

:::exercise id=mix_merge points=10 title="Add up two counts"
Write `add_counts(a, b)` that takes two dictionaries of counts and returns a new one with the counts for each key added together. Don't change `a` or `b`.
@@starter

@@tests
def test_values():
    "several pairs"
    a, b = {"x": 2, "y": 1}, {"y": 3, "z": 4}
    assert add_counts(a, b) == {"x": 2, "y": 4, "z": 4}
    assert a == {"x": 2, "y": 1} and b == {"y": 3, "z": 4}
    assert add_counts({}, {}) == {}
@@solution
def add_counts(a, b):
    total = dict(a)
    for k, n in b.items():
        total[k] = total.get(k, 0) + n
    return total
:::

:::exercise id=mix_owners points=10 title="Who owns what"
`owner` maps each item to the person who owns it. Write `belongings(owner)` that returns a dictionary from each person to the sorted list of their items.
@@starter

@@tests
def test_values():
    "several"
    assert belongings({"pen": "Ada", "cup": "Bo", "book": "Ada"}) == {"Ada": ["book", "pen"], "Bo": ["cup"]}
    assert belongings({}) == {}
@@solution
def belongings(owner):
    result = {}
    for item, person in owner.items():
        result.setdefault(person, []).append(item)
    return {person: sorted(items) for person, items in result.items()}
:::

:::exercise id=mix_tags points=10 title="Tag cloud"
Each post is a dictionary with a `"tags"` list. Write `tag_report(posts)` that returns a tuple: the set of all tags used, and the tag used on the most posts (the first seen if tied). Return `(set(), None)` for no posts.
@@starter

@@tests
def test_values():
    "several"
    posts = [{"title": "a", "tags": ["py", "web"]}, {"title": "b", "tags": ["py"]}, {"title": "c", "tags": ["data", "web", "py"]}]
    assert tag_report(posts) == ({"py", "web", "data"}, "py")
    assert tag_report([]) == (set(), None)
@@solution
from collections import Counter

def tag_report(posts):
    counts = Counter(tag for post in posts for tag in post["tags"])
    if not counts:
        return set(), None
    return set(counts), counts.most_common(1)[0][0]
:::

:::exercise id=mix_lookup points=10 title="Anagram finder"
Write `anagrams_of(word, words)` that returns, sorted, the words in the list that are anagrams of `word` (the same letters in a different order; not the word itself). Ignore case.
@@starter

@@tests
def test_values():
    "several"
    ws = ["enlist", "google", "inlets", "banana", "Silent", "listen"]
    assert anagrams_of("listen", ws) == ["Silent", "enlist", "inlets"]
    assert anagrams_of("cat", ws) == []
@@solution
def anagrams_of(word, words):
    key = sorted(word.lower())
    return sorted(w for w in words if sorted(w.lower()) == key and w.lower() != word.lower())

## Forge: the library

:::exercise id=forge points=50 title="Forge: the library"
Build the core of a library system. The whole library is one dictionary:

```
library = {
    "books": {},    # isbn -> {"title": ..., "author": ..., "copies": ...}
    "loans": {},    # member name -> set of isbns they have borrowed
}
```

A member may have at most **3** books at once, and never two copies of the same book. A book's **available** copies are its copies minus the number of members who have borrowed it. Write:

- `new_library()` returns an empty library like the one above.
- `add_book(library, isbn, title, author, copies)` adds a book, or adds `copies` more to a book that's already there.
- `borrow(library, member, isbn)` returns one of these messages, changing the library only for `OK`, checked in this order: `No such book`, `Already borrowed`, `Limit reached`, `None available`, `OK`.
- `give_back(library, member, isbn)` returns `OK` (and records the return) or `Not borrowed`. A member with nothing left on loan is removed from `loans`.
- `available(library, isbn)` returns the number of copies on the shelf.
- `report(library)` returns one line per book, sorted by title: `Title by Author: 1 of 2 available`, joined with `"\n"`.
- `process(library, command)` carries out one command and returns its message: `borrow NAME ISBN`, `return NAME ISBN`, `report`, or `who ISBN`, which returns the borrowers' names sorted and joined with `", "`, or `nobody`. Anything else returns `Unknown command`. Member names are one word.
- The main program makes a library, adds the two books below, then reads commands with the prompt `> ` until `quit`, printing each message.

```
add_book(lib, "111", "Things Fall Apart", "Chinua Achebe", 2)
add_book(lib, "222", "Americanah", "Chimamanda Ngozi Adichie", 1)
```

For example:

```
> borrow Ada 222
OK
> borrow Bo 222
None available
> who 222
Ada
> report
Americanah by Chimamanda Ngozi Adichie: 0 of 1 available
Things Fall Apart by Chinua Achebe: 2 of 2 available
> quit
```
@@starter
LIMIT = 3

def new_library():
    ___

@@tests
def fresh():
    lib = new_library()
    add_book(lib, "111", "Things Fall Apart", "Chinua Achebe", 2)
    add_book(lib, "222", "Americanah", "Chimamanda Ngozi Adichie", 1)
    return lib
def test_new():
    "new_library and add_book"
    lib = new_library()
    assert lib == {"books": {}, "loans": {}}
    assert new_library() is not lib and new_library()["books"] is not lib["books"], "each library needs its own dictionaries"
    add_book(lib, "9", "T", "A", 1)
    add_book(lib, "9", "T", "A", 2)
    assert lib["books"]["9"] == {"title": "T", "author": "A", "copies": 3}
def test_borrow():
    "borrow"
    lib = fresh()
    assert borrow(lib, "Ada", "999") == "No such book"
    assert borrow(lib, "Ada", "222") == "OK"
    assert lib["loans"] == {"Ada": {"222"}}
    assert borrow(lib, "Ada", "222") == "Already borrowed"
    assert borrow(lib, "Bo", "222") == "None available"
    assert available(lib, "222") == 0 and available(lib, "111") == 2
    for i in range(3):
        add_book(lib, f"x{i}", f"X{i}", "Z", 1)
    assert borrow(lib, "Ada", "x0") == "OK" and borrow(lib, "Ada", "x1") == "OK"
    assert borrow(lib, "Ada", "x2") == "Limit reached"
    assert borrow(lib, "Ada", "999") == "No such book"
def test_return():
    "give_back"
    lib = fresh()
    borrow(lib, "Ada", "111")
    assert give_back(lib, "Ada", "222") == "Not borrowed"
    assert give_back(lib, "Bo", "111") == "Not borrowed"
    assert give_back(lib, "Ada", "111") == "OK"
    assert lib["loans"] == {}, "a member with no loans should be removed"
    assert available(lib, "111") == 2
def test_report():
    "report"
    lib = fresh()
    borrow(lib, "Ada", "111")
    assert report(lib) == "Americanah by Chimamanda Ngozi Adichie: 1 of 1 available\nThings Fall Apart by Chinua Achebe: 1 of 2 available"
def test_process():
    "process"
    lib = fresh()
    assert process(lib, "borrow Cy 111") == "OK"
    assert process(lib, "borrow Ada 111") == "OK"
    assert process(lib, "who 111") == "Ada, Cy"
    assert process(lib, "who 222") == "nobody"
    assert process(lib, "return Cy 111") == "OK"
    assert process(lib, "dance") == "Unknown command"
    assert process(lib, "report").startswith("Americanah")
def test_program():
    "the whole program"
    cmds = ["borrow Ada 222", "borrow Bo 222", "who 222", "report", "quit"]
    want = "> borrow Ada 222\nOK\n> borrow Bo 222\nNone available\n> who 222\nAda\n> report\nAmericanah by Chimamanda Ngozi Adichie: 0 of 1 available\nThings Fall Apart by Chinua Achebe: 2 of 2 available\n> quit"
    expect_output(want, inputs=cmds, echo=True)
@@hint
`new_library` must build new dictionaries every time it's called: `return {"books": {}, "loans": {}}`. In `add_book`, use `in` to check whether the ISBN is already a key.
@@hint
`available` is `copies - sum(1 for isbns in library["loans"].values() if isbn in isbns)`. In `borrow`, the member's current set is `library["loans"].get(member, set())`.
@@hint
In `process`, `parts = command.split()`. Check `parts[0]` and `len(parts)` to decide which function to call.
@@solution
LIMIT = 3

def new_library():
    return {"books": {}, "loans": {}}

def add_book(library, isbn, title, author, copies):
    books = library["books"]
    if isbn in books:
        books[isbn]["copies"] += copies
    else:
        books[isbn] = {"title": title, "author": author, "copies": copies}

def available(library, isbn):
    out = sum(1 for isbns in library["loans"].values() if isbn in isbns)
    return library["books"][isbn]["copies"] - out

def borrow(library, member, isbn):
    if isbn not in library["books"]:
        return "No such book"
    mine = library["loans"].get(member, set())
    if isbn in mine:
        return "Already borrowed"
    if len(mine) >= LIMIT:
        return "Limit reached"
    if available(library, isbn) == 0:
        return "None available"
    library["loans"].setdefault(member, set()).add(isbn)
    return "OK"

def give_back(library, member, isbn):
    mine = library["loans"].get(member, set())
    if isbn not in mine:
        return "Not borrowed"
    mine.remove(isbn)
    if not mine:
        del library["loans"][member]
    return "OK"

def report(library):
    books = library["books"]
    lines = []
    for isbn in sorted(books, key=lambda i: books[i]["title"]):
        b = books[isbn]
        lines.append(f"{b['title']} by {b['author']}: {available(library, isbn)} of {b['copies']} available")
    return "\n".join(lines)

def who(library, isbn):
    names = sorted(m for m, isbns in library["loans"].items() if isbn in isbns)
    return ", ".join(names) if names else "nobody"

def process(library, command):
    parts = command.split()
    if len(parts) == 3 and parts[0] == "borrow":
        return borrow(library, parts[1], parts[2])
    if len(parts) == 3 and parts[0] == "return":
        return give_back(library, parts[1], parts[2])
    if parts == ["report"]:
        return report(library)
    if len(parts) == 2 and parts[0] == "who":
        return who(library, parts[1])
    return "Unknown command"

lib = new_library()
add_book(lib, "111", "Things Fall Apart", "Chinua Achebe", 2)
add_book(lib, "222", "Americanah", "Chimamanda Ngozi Adichie", 1)
command = input("> ")
while command != "quit":
    print(process(lib, command))
    command = input("> ")
:::

:::think title="One fact, one place"
Notice that the library never stores how many copies are **available**. It works that out from `copies` and `loans` whenever it's asked. If it stored the number as well, every borrow and return would have to update two things, and one day a bug would update only one of them. Storing each fact in exactly one place, and working everything else out from it, is one of the most useful rules in data design. Real databases are built around it.
:::

## Forge bonus: a spelling corrector

This bonus is based on a famous short essay by Peter Norvig, "How to Write a Spelling Corrector". The idea: most typing mistakes are one small **edit** away from the word that was meant, and among the real words one edit away, the most likely is the most common one.

:::exercise id=forge2 points=30 title="Forge bonus: a spelling corrector"
An **edit** of a word is one of:

- a **delete**: remove one letter (`"speling"` → `"seling"`);
- a **swap**: swap two neighbouring letters (`"teh"` → `"the"`);
- a **replace**: change one letter to another letter `a` to `z`;
- an **insert**: add one letter `a` to `z` anywhere, including at the ends.

Write:

1. `edits(word)` returns the **set** of every word one edit away (the word itself may be included, through a replace with the same letter, which is fine).
2. `train(text)` returns a `Counter` of the words in the text, in lower case, counting only runs of letters (treat every non-letter as a space).
3. `correct(word, counts)` returns, in lower case: the word itself if it's known (in `counts`); otherwise the most common known word one edit away; otherwise the word unchanged. If known words tie, return the alphabetically first.

Use comprehensions to build the edits. The split points are `[(word[:i], word[i:]) for i in range(len(word) + 1)]`.
@@starter
from collections import Counter
LETTERS = "abcdefghijklmnopqrstuvwxyz"

@@tests
TEXT = "The cat sat on the mat. The dog sat on the log, and the cat spelled spelling! Then the cat and dog ate."
def test_edits():
    "edits"
    e = edits("ab")
    assert isinstance(e, set)
    assert {"a", "b", "ba", "cb", "ac", "zab", "abz", "axb"} <= e
    assert len(edits("speling")) == 390, "speling has 390 different words one edit away"
    assert "spelling" in edits("speling") and "the" in edits("teh") and "cat" in edits("cst")
def test_train():
    "train"
    c = train(TEXT)
    assert c["the"] == 6 and c["cat"] == 3 and c["spelling"] == 1
    assert "mat." not in c and "" not in c
def test_correct():
    "correct"
    c = train(TEXT)
    assert correct("speling", c) == "spelling"
    assert correct("teh", c) == "the"
    assert correct("cst", c) == "cat"
    assert correct("Dog", c) == "dog"
    assert correct("xylophone", c) == "xylophone"
    assert correct("sa", c) == "sat"
@@hint
With `splits` as given: deletes are `L + R[1:]` for each split with a non-empty `R`; swaps are `L + R[1] + R[0] + R[2:]` when `len(R) > 1`; replaces are `L + c + R[1:]` for every letter `c`; inserts are `L + c + R` for every letter.
@@hint
For `train`, turn every character that isn't a letter into a space with a comprehension, join, lower, and split. For `correct`, `known = [w for w in edits(word) if w in counts]`, then pick with `min(known, key=lambda w: (-counts[w], w))`.
@@solution
from collections import Counter
LETTERS = "abcdefghijklmnopqrstuvwxyz"

def edits(word):
    splits = [(word[:i], word[i:]) for i in range(len(word) + 1)]
    deletes = {L + R[1:] for L, R in splits if R}
    swaps = {L + R[1] + R[0] + R[2:] for L, R in splits if len(R) > 1}
    replaces = {L + c + R[1:] for L, R in splits if R for c in LETTERS}
    inserts = {L + c + R for L, R in splits for c in LETTERS}
    return deletes | swaps | replaces | inserts

def train(text):
    cleaned = "".join(ch if ch.isalpha() else " " for ch in text)
    return Counter(cleaned.lower().split())

def correct(word, counts):
    word = word.lower()
    if word in counts:
        return word
    known = [w for w in edits(word) if w in counts]
    if not known:
        return word
    return min(known, key=lambda w: (-counts[w], w))
:::

Train it on a whole book and it corrects most single typos. Norvig's full version also looks two edits away, and you could add that now: the edits of every edit.
