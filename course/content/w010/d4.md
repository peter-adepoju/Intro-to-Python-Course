## Warm-up

:::predict
student = {"name": "Ada", "marks": [93, 88, 71]}
print(student["marks"][1])
print(len(student["marks"]))
student["marks"].append(64)
print(student)
:::

`student["marks"]` is a list, so you can index it, take its length, and append to it, like any other list. That one idea is all of today: each pair of square brackets takes you one level deeper.

## Shapes of data

There are three common shapes, and choosing the right one makes the rest of the program simpler.

**A list of dictionaries**: many records of the same kind, in order. Each dictionary has the same keys. This is the shape of a table, a spreadsheet, or rows from a database.

:::example
students = [
    {"name": "Ada", "city": "Lagos", "mark": 93},
    {"name": "Bo", "city": "Accra", "mark": 41},
    {"name": "Cy", "city": "Lagos", "mark": 78},
]
print(students[1]["city"])
print([s["name"] for s in students if s["mark"] >= 50])
:::

**A dictionary of lists**: a list of things for each key. It's what the grouping pattern produces.

:::example
by_city = {"Lagos": ["Ada", "Cy"], "Accra": ["Bo"]}
print(by_city["Lagos"])
print(len(by_city["Lagos"]))
:::

**A dictionary of dictionaries**: a record for each key, found at once by that key. It's what the index pattern produces.

:::example
students = {
    "ada_l": {"name": "Ada", "city": "Lagos", "mark": 93},
    "bo99": {"name": "Bo", "city": "Accra", "mark": 41},
}
print(students["bo99"]["mark"])
:::

:::key
Ask what you'll look things up **by**. If you go through records in order, a **list of dictionaries**. If you look up a group by a name, a **dictionary of lists**. If you look up one record by a unique key, a **dictionary of dictionaries**.
:::

## Reaching in

Read a chain of square brackets from left to right, one step at a time. Each step gives a new value, and the next bracket applies to that value:

:::example
school = {
    "name": "Python Atlas",
    "classes": [
        {"code": "3A", "students": ["Ada", "Bo"]},
        {"code": "3B", "students": ["Cy"]},
    ],
}
print(school["classes"])
print(school["classes"][0])
print(school["classes"][0]["students"])
print(school["classes"][0]["students"][1])
:::

`school["classes"]` is a list; `[0]` is its first item, a dictionary; `["students"]` is a list in that; `[1]` is its second name.

### When a level might be missing

Any step can fail: a key may be missing, a list may be too short. Use `get` at the levels where something may legitimately be missing, with a default of the right **type**, so the next step still works:

:::example
user = {"name": "Ada", "settings": {"theme": "dark"}}
guest = {"name": "Guest"}
for u in [user, guest]:
    theme = u.get("settings", {}).get("theme", "light")
    print(u["name"], theme)
:::

`u.get("settings", {})` gives an empty dictionary when there are no settings, and `.get("theme", "light")` on an empty dictionary gives `"light"`.

:::tip
When a long chain of brackets fails, split it up and print each step. The error tells you the **key** or **index** that failed; the printed steps tell you what was actually there.
:::

## Looping and building

### Looping through levels

Each level of nesting is usually one loop:

:::example
classes = {
    "3A": [{"name": "Ada", "mark": 93}, {"name": "Bo", "mark": 41}],
    "3B": [{"name": "Cy", "mark": 78}],
}
for code, students in classes.items():
    print(code)
    for s in students:
        print(f"  {s['name']:<4}{s['mark']:>4}")
:::

Notice `s['name']` inside the f-string: the quotes inside must differ from the f-string's own quotes (until Python 3.12 allowed the same quotes).

### Summarising

Comprehensions and generator expressions work well on nested data:

:::example
classes = {
    "3A": [{"name": "Ada", "mark": 93}, {"name": "Bo", "mark": 41}],
    "3B": [{"name": "Cy", "mark": 78}, {"name": "Di", "mark": 66}],
}
averages = {code: sum(s["mark"] for s in ss) / len(ss) for code, ss in classes.items()}
print(averages)
everyone = [s for ss in classes.values() for s in ss]
best = max(everyone, key=lambda s: s["mark"])
print(best["name"])
:::

### Building from flat records

Data often arrives flat, one record per line, and you build the nested shape you need:

:::example
rows = [("3A", "Ada", 93), ("3B", "Cy", 78), ("3A", "Bo", 41)]
classes = {}
for code, name, mark in rows:
    classes.setdefault(code, []).append({"name": name, "mark": mark})
print(classes)
:::

### Changing nested data

Changing an inner value changes it in place, wherever it's reached from:

:::example
inventory = {"rice": {"price": 8500, "stock": 12}, "beans": {"price": 3200, "stock": 0}}
inventory["rice"]["stock"] -= 2
inventory["beans"]["price"] = 3500
inventory["garri"] = {"price": 2000, "stock": 30}
for item, info in inventory.items():
    print(item, info)
:::

## Copies

You saw in Week 8 that `.copy()` is shallow: the new outer container holds the **same** inner objects. With nested data that matters:

:::example
import copy
original = {"name": "Ada", "marks": [93, 88]}
shallow = original.copy()
deep = copy.deepcopy(original)
shallow["marks"].append(10)
deep["marks"].append(99)
print(original)
print(deep)
:::

Changing the shallow copy's list changed the original's list, because they're the same list. `copy.deepcopy` copies every level, so the deep copy is completely separate.

:::key
To change nested data without touching the original, use `copy.deepcopy`. A shallow `.copy()` is enough only when you'll replace whole values, not change them inside.
:::

## JSON

**JSON** (JavaScript Object Notation) is a text format for nested data. It looks almost exactly like Python's lists and dictionaries, and it's how most websites and apps send data to each other. The `json` module converts both ways:

:::example
import json
data = {"name": "Ada", "marks": [93, 88], "passed": True, "tutor": None}
text = json.dumps(data)
print(text)
print(type(text))
back = json.loads(text)
print(back["marks"][0])
:::

`json.dumps` ("dump to string") turns data into JSON text; `json.loads` ("load from string") turns JSON text back into data. Notice the small differences in the text: JSON writes `true`, `false` and `null` where Python has `True`, `False` and `None`, and always uses double quotes.

`indent` makes the text readable, which is the easiest way to look at a big nested structure:

:::example
import json
data = {"school": "Python Atlas", "classes": [{"code": "3A", "size": 2}, {"code": "3B", "size": 1}]}
print(json.dumps(data, indent=2))
:::

:::warn
JSON keys are always strings. A dictionary with number or tuple keys doesn't come back the same: `json.loads(json.dumps({1: "a"}))` gives `{"1": "a"}`, and tuple keys can't be saved at all. Tuples as values come back as lists.
:::

Next week you'll save JSON to files, so your programs can remember things between runs.

:::exercise id=regroup points=15 title="Books by author"
Write `by_author(books)` that turns the list of book dictionaries into a dictionary from author to a list of `(year, title)` tuples, each list sorted by year.
@@starter

@@tests
def test_values():
    "several books"
    books = [
        {"title": "Purple Hibiscus", "author": "Adichie", "year": 2003},
        {"title": "Things Fall Apart", "author": "Achebe", "year": 1958},
        {"title": "Americanah", "author": "Adichie", "year": 2013},
        {"title": "Half of a Yellow Sun", "author": "Adichie", "year": 2006},
    ]
    assert by_author(books) == {
        "Adichie": [(2003, "Purple Hibiscus"), (2006, "Half of a Yellow Sun"), (2013, "Americanah")],

    }
    assert by_author([]) == {}
@@solution
def by_author(books):
    result = {}
    for b in books:
        result.setdefault(b["author"], []).append((b["year"], b["title"]))
    for author in result:
        result[author].sort()
    return result
:::

:::exercise id=sell points=10 title="Make a sale"
`inventory` maps items to dictionaries with `price` and `stock`. Write `sell(inventory, item, qty)` that, if there's enough stock, reduces the stock in place and returns the cost (`price * qty`); otherwise it changes nothing and returns 0. An unknown item also gives 0.
@@starter

@@tests
def test_values():
    "several sales"
    inv = {"rice": {"price": 8500, "stock": 3}}
    assert sell(inv, "rice", 2) == 17000 and inv["rice"]["stock"] == 1
    assert sell(inv, "rice", 2) == 0 and inv["rice"]["stock"] == 1
    assert sell(inv, "yam", 1) == 0
@@solution
def sell(inventory, item, qty):
    info = inventory.get(item)
    if info is None or info["stock"] < qty:
        return 0
    info["stock"] -= qty
    return info["price"] * qty

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: flatten and unflatten"
Settings files and spreadsheets often store nested data as flat keys joined with dots: `{"user.name": "Ada", "user.theme.dark": True}` stands for `{"user": {"name": "Ada", "theme": {"dark": True}}}`.

Write `flatten(data)` that turns nested dictionaries into a flat dictionary with dotted keys (values that aren't dictionaries, including lists, are kept as they are), and `unflatten(flat)` that does the reverse. Keys are strings without dots, and an empty inner dictionary can be left out when flattening.

```
flatten({"a": 1, "b": {"c": 2, "d": {"e": 3}}})  ->  {"a": 1, "b.c": 2, "b.d.e": 3}
```
@@starter

@@tests
def test_flatten():
    "flatten"
    assert flatten({"a": 1, "b": {"c": 2, "d": {"e": 3}}}) == {"a": 1, "b.c": 2, "b.d.e": 3}
    assert flatten({"x": [1, {"y": 2}]}) == {"x": [1, {"y": 2}]}
    assert flatten({}) == {}
def test_unflatten():
    "unflatten"
    assert unflatten({"a": 1, "b.c": 2, "b.d.e": 3}) == {"a": 1, "b": {"c": 2, "d": {"e": 3}}}
    assert unflatten({}) == {}
def test_round_trip():
    "there and back"
    d = {"user": {"name": "Ada", "theme": {"dark": True, "size": 14}}, "version": 3}
    assert unflatten(flatten(d)) == d
@@hint
Flattening one level at a time works with a list of things still to do. Start with `todo = [("", data)]`. Take one `(prefix, d)` off; for each key and value, the new key is `prefix + key` (with a dot in between if there's a prefix). If the value is a dictionary, put `(new_key, value)` on `todo`; otherwise store it in the result.
@@hint
For `unflatten`, split each key on dots. Walk down from the top with `node = node.setdefault(part, {})` for every part except the last, then set `node[last] = value`.
@@solution
def flatten(data):
    result = {}
    todo = [("", data)]
    while todo:
        prefix, d = todo.pop(0)
        for key, value in d.items():
            full = f"{prefix}.{key}" if prefix else key
            if isinstance(value, dict):
                todo.append((full, value))
            else:
                result[full] = value
    return result

def unflatten(flat):
    result = {}
    for key, value in flat.items():
        *path, last = key.split(".")
        node = result
        for part in path:
            node = node.setdefault(part, {})
        node[last] = value
    return result
:::
