## Warm-up

:::predict
n = 1
while n <= 5:
    print(n * n, end=" ")
    n += 1
:::

A counting `while` loop: start at 1, keep going while `n <= 5`, add 1 each time. That's three parts in three places. `range` puts all three in one spot.

## range: a sequence of numbers

`range(5)` is a sequence of the numbers 0, 1, 2, 3, 4. A `for` loop walks through it just as it walks through a string:

:::example
for n in range(5):
    print(n)
:::

Five numbers, starting at 0 and stopping **before** 5. That's the most important fact about `range`: **the stop value is never included**.

### Three forms

| You write | You get | Read as |
|---|---|---|
| `range(stop)` | 0, 1, ..., stop − 1 | "stop numbers, from 0" |
| `range(start, stop)` | start, ..., stop − 1 | "from start, up to but not including stop" |
| `range(start, stop, step)` | start, start + step, ... | "from start, in steps of step, before stop" |

Explore them. Try each preset, then make your own:

:::widget rangeviz caption="The yellow dot is the start; the red ring is stop, which is never included. Try a negative step, and a range that comes out empty."
{"start": 0, "stop": 10, "step": 1}
:::

:::predict
for n in range(3, 8):
    print(n, end=" ")
print()
for n in range(0, 20, 5):
    print(n, end=" ")
print()
for n in range(10, 0, -2):
    print(n, end=" ")
:::

### Why stop isn't included

It seems odd at first, but it makes everyday sums tidy:

- `range(n)` has exactly `n` numbers. `range(a, b)` has exactly `b - a`.
- `range(len(s))` gives exactly the valid positions of a string `s`, from 0 to `len(s) - 1`.
- Two ranges join without overlap: `range(0, 5)` then `range(5, 10)` covers 0 to 9 with nothing repeated.

It matches slicing, too: `s[2:5]` stops before position 5, just as `range(2, 5)` stops before 5.

:::key
To count from 1 to `n` **inclusive**, write `range(1, n + 1)`.
:::

### Counting down

A negative step counts backwards. Now the range stops **before going below** the stop value:

:::example title="Countdown"
for n in range(10, 0, -1):
    print(n, end=" ")
print("Lift off!")
:::

To count down to 0 inclusive, the stop must be -1: `range(10, -1, -1)`.

### Empty ranges

If the start is already at or past the stop, the range is empty and the loop body never runs:

:::example
for n in range(5, 5):
    print("never")
for n in range(10, 0):
    print("never either: counting up from 10 never reaches 0")
print("done")
:::

### Looking inside a range

A range doesn't store its numbers; it works each one out when the loop asks for it. That's why `range(1000000000)` costs almost nothing. To see the numbers, turn the range into a list (you'll meet lists properly in Week 8):

:::example
print(list(range(4)))
print(list(range(2, 12, 3)))
print(len(range(0, 100, 7)))
print(50 in range(0, 100, 5))
:::

## Counting loops with for

Every counting `while` loop from last week can be a `for` loop. Here's the sum from Week 3, Day 2:

:::example title="Sum of 1 to 100"
total = 0
for n in range(1, 101):
    total += n
print(total)
:::

And factorial:

:::example title="10 factorial"
product = 1
for k in range(2, 11):
    product *= k
print(product)
:::

### Repeat n times

When you just want to repeat something and don't need the counter, call it `_`. It's an ordinary name, but it tells readers "I'm not going to use this":

:::example title="Three cheers"
for _ in range(3):
    print("Hip hip hooray!")
:::

## Positions: range(len(s))

A `for` loop over a string gives you each character, but not its position. When you need the position, loop over the **positions** instead, and look up each character:

:::example title="Characters and their positions"
word = "range"
for i in range(len(word)):
    print(i, word[i])
:::

`range(len(word))` is `range(5)`: exactly the indexes 0 to 4. This is the pattern to use when the position matters:

:::example title="Where are the vowels?" try=education
word = input("Word: ")
for i in range(len(word)):
    if word[i] in "aeiou":
        print(word[i], "at position", i)
:::

:::example title="Every other character"
text = "abcdefghij"
result = ""
for i in range(0, len(text), 2):
    result += text[i]
print(result)
:::

:::tip
Use `for ch in s` when you only need the characters. Use `for i in range(len(s))` when you need positions. (In Week 9 you'll meet `enumerate`, which gives you both at once.)
:::

## Neighbours, and staying inside the string

Some jobs compare each character with the **next** one: finding double letters, or checking whether letters are in alphabetical order. Then `s[i + 1]` must exist, so the last `i` has to be `len(s) - 2`:

:::example title="Double letters" try=bookkeeper
word = input("Word: ")
for i in range(len(word) - 1):
    if word[i] == word[i + 1]:
        print("Double", word[i], "at position", i)
:::

With `range(len(word))` instead, the last pass would look at `word[len(word)]`, one past the end:

:::example error=yes title="One too far"
word = "book"
for i in range(len(word)):
    if word[i] == word[i + 1]:
        print("double", word[i])
:::

:::mistake
`IndexError: string index out of range` inside a loop almost always means the loop went one step too far. Check the stop value of your `range`, and every `[i + 1]` or `[i - 1]`.
:::

## Quiz

:::quiz id=quiz
- q: What does `list(range(3))` give?
  type: text
  answer: ["[0, 1, 2]", "[0,1,2]"]
  explain: "Three numbers from 0; 3 is not included."
- q: How many numbers are in `range(5, 15)`?
  type: text
  answer: ["10", "ten"]
  explain: "stop - start."
- q: Which range gives 1, 2, ..., 10?
  options: ["`range(10)`", "`range(1, 10)`", "`range(1, 11)`", "`range(0, 11)`"]
  answer: 2
  explain: "Stop must be one past the last number you want."
- q: What does this print?
  type: output
  code: |
    for n in range(10, 0, -3):
        print(n, end=" ")
  answer: "10 7 4 1 "
  explain: "Down in threes, stopping before 0."
- q: How many times does the body run?
  code: |
    for i in range(4, 2):
        print(i)
  type: text
  answer: ["0", "zero", "none"]
  explain: "Counting up from 4 can't reach 2."

  explain: "Exactly the valid positions."

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: run-length encoding"
**Run-length encoding** shrinks text with lots of repeats by writing each run of the same character as the character and how many times it repeats: `aaabccdddd` becomes `a3b1c2d4`. It was used to compress early fax and image files.

Ask for some text with the prompt `Text: ` and print its run-length encoding. Empty text prints an empty line.
@@starter

@@tests
def test_basic():
    "aaabccdddd"
    expect_output("Text: aaabccdddd\na3b1c2d4", inputs=["aaabccdddd"], echo=True)
def test_single():
    "one character"
    expect_output("Text: z\nz1", inputs=["z"], echo=True)
def test_no_runs():
    "no repeats"
    expect_output("Text: abc\na1b1c1", inputs=["abc"], echo=True)
def test_spaces():
    "spaces count too"
    expect_output("Text: aa  bb\na2 2b2", inputs=["aa  bb"], echo=True)
def test_empty():
    "empty text"
    expect_output("Text: ", inputs=[""], echo=True)
@@hint
Keep the current run's character and its length. Loop over positions from 1: if `text[i]` matches the current character, the run grows; otherwise write out the finished run and start a new one.
@@hint
Don't forget the last run: it's still waiting when the loop ends.
@@solution
text = input("Text: ")
result = ""
if text:
    current = text[0]
    count = 1
    for i in range(1, len(text)):
        if text[i] == current:
            count += 1
        else:
            result += current + str(count)
            current = text[i]
            count = 1
    result += current + str(count)
print(result)
:::
