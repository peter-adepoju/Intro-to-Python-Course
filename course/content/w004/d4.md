## Warm-up

:::predict
total = 0
best = ""
for ch in "loop":
    total += ord(ch)
    if ch > best:
        best = ch
print(total, best)
:::

That loop does two jobs at once: it **accumulates** a total and keeps the **best so far**. Both are patterns you've already used. Today they get names, along with eight more.

## Why name patterns?

When you read "count the words that start with a capital", you could stare at a blank screen. Or you could think: *count* (a counter that goes up), and *filter* (only some items). Two patterns you know, joined together. Naming patterns turns a new problem into a combination of old ones.

Each pattern below has three parts: what you set up **before** the loop, what you do **inside**, and what you have **after**.

## 1. Accumulate

Combine every item into one result.

:::example
total = 0                        # before: the neutral value
for ch in "2468":
    total += int(ch)             # inside: combine
print(total)                     # after: the answer
:::

Start with 0 for sums, 1 for products, `""` for strings.

## 2. Count

Count the items that pass a test. It's accumulate, adding 1 at a time.

:::example
count = 0
for ch in "Hello World":
    if ch.isupper():
        count += 1
print(count)
:::

## 3. Filter

Keep only the items that pass a test, building a new result.

:::example
kept = ""
for ch in "h3ll0 w0rld":
    if ch.isalpha():
        kept += ch
print(kept)
:::

## 4. Transform

Change **every** item, building a new result. No test, or a test that chooses between two changes.

:::example
result = ""
for ch in "hello":
    result += ch.upper() + " "
print(result)
:::

## 5. Find first

Stop at the first item that passes a test. Afterwards, you need to know whether one was found.

:::example
for i in range(len("listen")):
    if "listen"[i] in "aeiou":
        print("First vowel at", i)
        break
else:
    print("No vowels")
:::

## 6. All of

Is **every** item OK? Start by assuming yes, and look for one that isn't. One failure is enough to decide, so you can `break`.

:::example title="Are all the characters letters?"
text = "Python"
all_letters = True
for ch in text:
    if not ch.isalpha():
        all_letters = False
        break
print(all_letters)
:::

## 7. Any of

Is **at least one** item OK? Start by assuming no, and look for one that is. One success is enough to decide.

:::example title="Is there at least one digit?"
text = "pass1word"
has_digit = False
for ch in text:
    if ch.isdigit():
        has_digit = True
        break
print(has_digit)
:::

:::key
**All of** starts `True` and looks for a failure. **Any of** starts `False` and looks for a success. Neither ever sets the flag back the other way inside the loop.
:::

:::mistake title="The flag that flips back"
A common bug in an all-of check is an `else` that sets the flag back to `True`. Then only the **last** item decides the answer:

```python
ok = True
for ch in "ab3d":
    if ch.isalpha():
        ok = True      # wrong: this undoes an earlier failure
    else:
        ok = False
```

Here `ok` ends up `True` because the last character, `d`, is a letter, even though `3` isn't.
:::

## 8. Best so far

Find the largest or smallest. Start with the **first** item, and replace the record whenever it's beaten. Often you also want **where** the best was, so keep its position too:

:::example title="The latest letter in the alphabet, and its position"
word = "algorithm"
best = word[0]
best_at = 0
for i in range(1, len(word)):
    if word[i] > best:
        best = word[i]
        best_at = i
print(best, "at position", best_at)
:::

Should a tie replace the record? With `>`, the **first** of several equal bests is kept. With `>=`, the **last** one is. Decide on purpose.

## 9. Running total

Print (or keep) the total **so far** at every step, not just the final one. Bank statements and scoreboards do this.

:::example title="A running balance" try=500,-200,1000,-450,
balance = 0
while True:
    text = input("Amount (blank to stop): ")
    if text == "":
        break
    balance += int(text)
    print("Balance now:", balance)
:::

## 10. Compare with the previous

Each item is compared with the one **before** it: is it bigger, the same, part of a run? Keep the previous item in a variable, and update it at the **end** of each pass.

:::example title="How many times does the temperature rise?" try=12,15,15,14,18,21,
rises = 0
prev = int(input("Reading: "))
while True:
    text = input("Reading (blank to stop): ")
    if text == "":
        break
    t = int(text)
    if t > prev:
        rises += 1
    prev = t
print("Rises:", rises)
:::

When the items are in a string, you can use positions instead, comparing `s[i]` with `s[i - 1]` for `i` from 1, as you did yesterday with neighbours.

## Choosing and combining

Here are some problems and the patterns they need:

| Problem | Patterns |
|---|---|
| Average of the readings | accumulate + count |
| Is this word a valid code (only capitals and digits)? | all of |
| Where is the first space? | find first |
| How long is the longest run of the same letter? | compare with previous + best so far |
| Remove the vowels and count what's removed | filter + count |
| Does the password contain a symbol? | any of |

Several patterns can share **one** loop. Each keeps its own variables, set up before the loop:

:::example title="Three patterns, one loop"
text = "The Quick Brown fox"
capitals = 0
no_spaces = ""
longest_word = 0
current = 0
for ch in text:
    if ch.isupper():
        capitals += 1
    if ch != " ":
        no_spaces += ch
        current += 1
        if current > longest_word:
            longest_word = current
    else:
        current = 0
print(capitals, no_spaces, longest_word)
:::

:::tip
Before writing a loop, say the pattern names out loud. Then write the **before** lines for each one first. Most loop bugs are a missing or misplaced "before" line.
:::

:::exercise id=all_caps points=10 title="Shouting?"
Ask for a message with the prompt `Message: `. It's shouting if every letter in it is a capital (ignore non-letters) and it has at least one letter. Print `Shouting: True` or `Shouting: False`.
@@starter

@@tests
def test_yes():
    "shouting"

    "no letters"

:::exercise id=longest_run points=15 title="Longest run"
Ask for a string with the prompt `Text: ` and print `Longest run: ` and the length of the longest run of one character repeated. `aabbbbcc` has a longest run of 4. Empty text has a longest run of 0.
@@starter

@@tests
def test_cases():
    "several strings"
    for s, n in [("aabbbbcc", 4), ("abc", 1), ("zzzzz", 5), ("", 0), ("aabbaaa", 3), ("mississippi", 2)]:
        expect_output(f"Text: {s}\nLongest run: {n}", inputs=[s], echo=True)
@@hint
Compare with previous (is this character the same as the last one?) and best so far (is this run the longest yet?).
@@solution
text = input("Text: ")

current = 0
prev = ""
for ch in text:
    if ch == prev:
        current += 1
    else:
        current = 1
    if current > longest:
        longest = current
    prev = ch
print("Longest run:", longest)
:::

## Quiz

:::quiz id=quiz
- q: What value does an all-of flag start with?
  options: ["True", "False", "0", "None"]
  answer: 0
  explain: "Assume everything passes, and look for one failure."
- q: What value does an any-of flag start with?
  options: ["True", "False"]
  answer: 1
  explain: "Assume nothing passes, and look for one success."
- q: Which pattern answers "how many words start with a capital"?
  options: ["filter", "count", "transform", "best so far"]
  answer: 1
  explain: "A counter that goes up when the test passes."
- q: What does this print?

    s = ""
    for ch in "abc":
        s += ch.upper()
    print(s)

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: the best trade"
Read a share's price on each day with the prompt `Price: ` (whole numbers) until a blank line. You may buy once and then sell once on a **later** day. Print `Best profit: ` and the largest profit possible, or `Best profit: 0` if prices only fall (then you just don't trade).

For prices `7, 1, 5, 3, 6, 4`, buying at 1 and selling at 6 gives 5.

Use **one** loop, with no loop inside it.
@@starter

@@tests
def run_prices(ps):
    p = "Price: "
    return "".join(f"{p}{x}\n" for x in ps) + f"{p}\n"
def test_example():
    "the example"
    expect_output(run_prices([7, 1, 5, 3, 6, 4]) + "Best profit: 5", inputs=["7", "1", "5", "3", "6", "4", ""], echo=True)
def test_falling():
    "prices only fall"
    expect_output(run_prices([9, 7, 4, 1]) + "Best profit: 0", inputs=["9", "7", "4", "1", ""], echo=True)
def test_late_low():
    "the lowest price comes after the best profit"
    expect_output(run_prices([2, 10, 1, 5]) + "Best profit: 8", inputs=["2", "10", "1", "5", ""], echo=True)
def test_one():
    "a single day"
    expect_output(run_prices([5]) + "Best profit: 0", inputs=["5", ""], echo=True)
def test_empty():
    "no days"
    expect_output("Price: \nBest profit: 0", inputs=[""], echo=True)
@@hint
Two best-so-far records: the **lowest price seen so far** (the best day to have bought), and the **best profit so far**.
@@hint
For each new price: the best profit from selling today is `price - lowest`. Check it against the record, then update `lowest`.
@@solution
best = 0
lowest = 0
seen_any = False
while True:
    text = input("Price: ")
    if text == "":
        break
    price = int(text)
    if not seen_any or price < lowest:
        lowest = price
        seen_any = True
    if price - lowest > best:
        best = price - lowest
print("Best profit:", best)
:::
