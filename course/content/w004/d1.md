## Warm-up

:::predict
word = "loop"
i = 0
while i < len(word):
    print(word[i].upper(), end="")
    i += 1
:::

Four lines of machinery to visit four letters: set up `i`, check it, use it, move it on. Get any of them wrong and you have an off-by-one bug or an infinite loop. Today that machinery disappears.

## The for loop

:::example title="The same job with for"
word = "loop"
for letter in word:
    print(letter.upper(), end="")
:::

Read it aloud: "**for** each **letter in word**, print it in capitals". Python does all the work:

1. It takes the first character of `word` and makes the name `letter` point at it.
2. It runs the body.
3. It moves `letter` on to the next character and runs the body again.
4. When there are no characters left, the loop ends.

There's no condition to write and no counter to update, so there's nothing to get wrong. Press X-ray and step through: watch `letter` point at `'l'`, then `'o'`, then `'o'`, then `'p'`.

:::key
`for name in sequence:` runs the body once for each item in the sequence, with `name` pointing at that item. A string is a sequence of characters.
:::

The body can be as long as you like and can contain anything, just like a `while` body:

:::example title="One line per letter" try=Ada
name = input("Name: ")
for ch in name:
    print(ch, "is character number", ord(ch))
:::

The name after `for` is up to you. `ch`, `c`, `letter` and `char` are all common for characters. Choose one that says what it holds.

## The loop variable

The **loop variable** is an ordinary name. Each pass, Python points it at the next item. It's a label, exactly like the ones from Week 1, Day 3.

That explains something that surprises people:

:::example title="Changing the loop variable changes nothing else"
word = "cat"
for ch in word:
    ch = ch.upper()
    print(ch, end=" ")
print()
print(word)
:::

`ch = ch.upper()` moves the label `ch` to a new string. The string `word` is untouched (and strings can't be changed anyway). To get a changed string, **build a new one**, as you did with accumulators last week.

After the loop, the loop variable still points at the last item:

:::example
for ch in "xyz":
    pass
print(ch)
:::

(`pass` means "do nothing". Python needs at least one statement in a block, and `pass` is the statement that does nothing.)

:::mistake
If the string is empty, the body never runs and the loop variable is never created. Using it after the loop then raises a `NameError`. Don't rely on the loop variable after a loop unless you know the sequence wasn't empty.
:::

## Last week's patterns, with for

Every accumulator pattern from Week 3 works with `for`, and gets shorter.

### Counting

:::example title="Count one letter" try=mississippi
word = input("Word: ")
count = 0
for ch in word:
    if ch == "s":
        count += 1
print(count)
:::

### Counting by kind

Strings have methods that answer questions about a character: `.isalpha()` (a letter?), `.isdigit()` (a digit?), `.isupper()`, `.islower()` and `.isspace()` (a space, tab or new line?).

:::example title="What's in this text?" try="Room 101 is on Floor 3!"
text = input("Text: ")
letters = digits = spaces = other = 0
for ch in text:
    if ch.isalpha():
        letters += 1
    elif ch.isdigit():
        digits += 1
    elif ch.isspace():
        spaces += 1
    else:
        other += 1
print(f"{letters} letters, {digits} digits, {spaces} spaces, {other} other")
:::

`letters = digits = spaces = other = 0` points all four names at 0 in one line.

### Filtering: keep only some characters

:::example title="Remove the vowels" try=programming
word = input("Word: ")
result = ""
for ch in word:
    if ch.lower() not in "aeiou":
        result += ch
print(result)
:::

### Transforming: change every character

:::example title="Double every letter"
result = ""
for ch in "hello":
    result += ch * 2
print(result)
:::

### Reversing

:::example title="Reverse, by putting each character in front"
backwards = ""
for ch in "stressed":
    backwards = ch + backwards
print(backwards)
:::

Compare these with last week's `while` versions. Each one has lost three lines: the counter, the condition on it, and its update.

## break, continue and else

They all work in `for` loops, exactly as in `while` loops:

:::example title="Stop at the first digit"
for ch in "pass1word":
    if ch.isdigit():
        print("First digit:", ch)
        break
else:
    print("No digits")
:::

:::example title="Skip the spaces"
for ch in "a b c":
    if ch == " ":
        continue
    print(ch, end="")
:::

The `else` on a `for` loop runs if the loop reached the end of the sequence without a `break`, which is perfect for searches.

## for or while?

| Use `for` when... | Use `while` when... |
|---|---|
| you're going through every item of a sequence | you don't know in advance how many passes you need |
| you know the loop must finish | the loop waits for something: valid input, a sentinel, a condition |
| | you need to move through a sequence in an unusual way |

A `for` loop over a string can't run forever, because the string has an end. That alone makes it the safer choice whenever it fits. Searching for the first prime, reading until the user types `done` and Euclid's algorithm are still `while` jobs.

:::tip
If you catch yourself writing `i = 0` and `while i < len(...)`, stop and ask whether a `for` loop would do.
:::

You may be wondering how to get the **position** of each character too. That's tomorrow, with `range`.

## Quiz

:::quiz id=quiz
- q: How many times does the body run?
  code: |
    for ch in "hello":
        print(ch)
  type: text
  answer: ["5", "five"]
  explain: "Once per character."
- q: What does this print?
  type: output
  code: |
    for ch in "abc":
        print(ch * 2, end=" ")
  answer: "aa bb cc "
  explain: "Each character, doubled."
- q: What is word after this runs?
  code: |
    word = "hi"
    for ch in word:
        ch = "X"
  options: ['"hi"', '"XX"', '"X"', "an error"]
  answer: 0
  explain: "Changing the loop variable only moves that label."
- q: What does this print?
  type: output
  code: |
    total = 0
    for ch in "2024":
        total += int(ch)
    print(total)
  answer: "8"
  explain: "2 + 0 + 2 + 4."
- q: Can a for loop over a string run forever?
  options: ["Yes", "No"]
  answer: 1
  explain: "The string has an end."
- q: What does `"7".isdigit()` give, and `"x".isalpha()`?
  options: ["True, True", "True, False", "False, True", "False, False"]
  answer: 0
  explain: "Both are true."
- q: What does this print?
  type: output
  code: |
    for ch in "code":
        if ch == "d":
            break
        print(ch, end="")
  answer: "co"
  explain: "It stops at d before printing it."
- q: When does the else of a for loop run?
  options: ["When the sequence is empty only", "When the loop finished without break", "Always", "When break ran"]
  answer: 1
  explain: "Same as for while."
- q: Which job is a while job, not a for job?
  options: ["Count the vowels in a word", "Reverse a string", "Keep asking until the user types a valid age", "Remove the spaces from a sentence"]
  answer: 2
  explain: "You don't know in advance how many passes it needs."
- q: What does `pass` do?
  options: ["Skips to the next pass", "Leaves the loop", "Nothing", "Ends the program"]
  answer: 2
  explain: "It fills a block that must contain a statement."
:::

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: password strength"
Ask for a password with the prompt `Password: ` and check it against five rules, printing one line for each rule it **breaks**:

- `At least 8 characters`
- `Needs a capital letter`
- `Needs a lower-case letter`
- `Needs a digit`
- `Needs a symbol` (a symbol is any character that is not a letter, a digit or a space)

If it breaks no rules, print `Strong password`. Otherwise finish with `Score: ` and the number of rules it passes, out of 5, like `Score: 3/5`. Use one `for` loop over the password.
@@starter

@@tests
def test_strong():
    "strong"
    expect_output("Password: Tr1cky!Pass\nStrong password", inputs=["Tr1cky!Pass"], echo=True)
def test_weak():
    "weak"
    expect_output("Password: abc\nAt least 8 characters\nNeeds a capital letter\nNeeds a digit\nNeeds a symbol\nScore: 1/5", inputs=["abc"], echo=True)
def test_middle():
    "missing a symbol"
    expect_output("Password: Password123\nNeeds a symbol\nScore: 4/5", inputs=["Password123"], echo=True)
def test_spaces():
    "spaces aren't symbols"
    expect_output("Password: AAAA bbbb 1\nNeeds a symbol\nScore: 4/5", inputs=["AAAA bbbb 1"], echo=True)
@@hint
Four flags, all starting False: `has_upper`, `has_lower`, `has_digit`, `has_symbol`. One loop sets them. Then five `if`s print the problems.
@@hint
A symbol is `not ch.isalnum() and not ch.isspace()`, or spell it out with `isalpha` and `isdigit`.
@@solution
pw = input("Password: ")
has_upper = has_lower = has_digit = has_symbol = False
for ch in pw:
    if ch.isupper():
        has_upper = True
    elif ch.islower():
        has_lower = True
    elif ch.isdigit():
        has_digit = True
    elif not ch.isspace():
        has_symbol = True
score = 0
if len(pw) >= 8:
    score += 1
else:
    print("At least 8 characters")
if has_upper:
    score += 1
else:
    print("Needs a capital letter")
if has_lower:
    score += 1
else:
    print("Needs a lower-case letter")
if has_digit:
    score += 1
else:
    print("Needs a digit")
if has_symbol:
    score += 1
else:
    print("Needs a symbol")
if score == 5:
    print("Strong password")
else:
    print(f"Score: {score}/5")
:::
