:::exercise id=mix_pow points=10 title="Fast powers"
Write `power(x, n)` for a whole number `n` of 0 or more by divide and conquer: work out `half = power(x, n // 2)` once, then the answer is `half * half`, times one more `x` if `n` is odd. It must not use `**` or `pow`, and must handle `n` in the millions quickly (that's about 20 levels deep).
@@starter

@@tests
def test_values():
    "several"
    assert power(2, 10) == 1024 and power(3, 0) == 1 and power(5, 1) == 5
    assert power(7, 13) == 7 ** 13
    assert power(1, 5_000_000) == 1 and power(-1, 1_000_001) == -1
    assert "**" not in source and "pow(" not in source
@@solution
def power(x, n):
    if n == 0:
        return 1
    half = power(x, n // 2)
    result = half * half
    if n % 2 == 1:
        result *= x
    return result
:::

:::exercise id=mix_blocked points=10 title="Routes round the rocks"
A grid is given as a list of strings, with `"#"` for rocks. Count the routes from the top-left square to the bottom-right square moving only right or down, never onto a rock. Use memoised recursion on `(r, c)`. If either corner is a rock, there are 0 routes.
@@starter
from functools import cache

@@tests
def test_values():
    "several"
    assert routes(["...", "...", "..."]) == 6
    assert routes(["...", ".#.", "..."]) == 2
    assert routes(["#.", ".."]) == 0
    assert routes(["." * 16] * 16) == 155117520
@@solution
from functools import cache

def routes(grid):
    rows, cols = len(grid), len(grid[0])
    @cache
    def go(r, c):
        if r >= rows or c >= cols or grid[r][c] == "#":
            return 0
        if (r, c) == (rows - 1, cols - 1):
            return 1
        return go(r + 1, c) + go(r, c + 1)
    return go(0, 0)
:::

:::exercise id=mix_pins points=10 title="Safer codes"
A door code is a string of `n` digits in which no two neighbouring digits are the same (so `"1213"` is allowed and `"1123"` isn't). Write `codes(n, digits)` returning every such code using the given digits, in the order a recursion that tries the digits in the given order produces, and `count_codes(n, k)` returning how many there are with `k` different digits, **without** listing them.
@@starter

@@tests
def test_values():
    "several"
    assert codes(2, "12") == ["12", "21"]
    assert codes(3, "123")[:4] == ["121", "123", "131", "132"] and len(codes(3, "123")) == 12
    assert codes(0, "12") == [""]
    assert count_codes(3, 3) == 12 and count_codes(4, 10) == 7290 and count_codes(0, 5) == 1
@@hint
For `count_codes`: the first digit has `k` choices, and each digit after it has `k - 1`.
@@solution
def codes(n, digits):
    found = []
    def go(sofar):
        if len(sofar) == n:
            found.append(sofar)
            return
        for d in digits:
            if not sofar or sofar[-1] != d:
                go(sofar + d)
    go("")
    return found

def count_codes(n, k):
    return 1 if n == 0 else k * (k - 1) ** (n - 1)
:::

:::exercise id=mix_count points=10 title="Pixel shapes"
An image is a list of strings, with `"#"` for ink. Write `shapes(image)` returning how many separate shapes there are, where squares that touch at a **corner** count as connected too (eight neighbours).
@@starter

@@tests
def test_values():
    "several"
    assert shapes(["#.#", ".#.", "#.#"]) == 1
    assert shapes(["#..#", "....", "#..#"]) == 4
    assert shapes(["....", "...."]) == 0
    assert shapes(["##..#", "#...#", "..#..", "....."]) == 3
@@solution
def shapes(image):
    seen = set()
    def fill(r, c):
        if not (0 <= r < len(image) and 0 <= c < len(image[0])):
            return
        if image[r][c] != "#" or (r, c) in seen:
            return
        seen.add((r, c))
        for dr in (-1, 0, 1):
            for dc in (-1, 0, 1):
                if dr or dc:
                    fill(r + dr, c + dc)
    count = 0
    for r in range(len(image)):
        for c in range(len(image[0])):
            if image[r][c] == "#" and (r, c) not in seen:
                count += 1
                fill(r, c)
    return count
:::

## Forge: a Sudoku solver

A Sudoku is a 9 by 9 grid split into nine 3 by 3 boxes. Some squares hold digits; the rest are empty. Fill every empty square with a digit from 1 to 9 so that every **row**, every **column** and every **box** contains each digit exactly once.

Here is a puzzle written as 9 lines of text, with `.` for an empty square:

```
53..7....
6..195...
.98....6.
8...6...3
4..8.3..1
7...2...6
.6....28.
...419..5
....8..79
```

A solver can work like a careful person with a pencil and an eraser: find an empty square, try each digit that doesn't clash with its row, column or box, and for each, try to solve the rest. If the rest can't be solved, rub the digit out and try the next. If no digit works, this square is a dead end, so report failure and let the call above try its next digit. That's backtracking.

In the board, empty squares are stored as `0`, so a board is a list of 9 lists of 9 ints.

:::exercise id=forge points=50 title="Forge: a Sudoku solver"
Write these functions.

1. `parse(text)`: turn 9 lines like those above into a board (a list of 9 lists of 9 ints, with `0` for `.`). Ignore blank lines and spaces at the ends of lines.
2. `options(board, r, c)`: the **set** of digits from 1 to 9 that could go in square `(r, c)`: those not already in its row, its column or its 3 by 3 box. (The box's top-left corner is at row `3 * (r // 3)`, column `3 * (c // 3)`.)
3. `solve(board)`: a **new**, fully solved board, or `None` if the puzzle has no solution. The board passed in must not be changed. Use backtracking, and choose the empty square with the **fewest** options each time (if one has none, this is a dead end at once). This makes it fast enough for hard puzzles.
4. `show(board)`: the board as a list of 11 strings, with digits separated by spaces, `.` for empty squares, a `| ` between boxes across, and a line of `------+-------+------` between boxes down. The first line of the puzzle above shows as `5 3 . | . 7 . | . . .`.
5. `count_solutions(board, limit=2)`: how many solutions the puzzle has, stopping as soon as `limit` have been found. A proper Sudoku has exactly one; this is how puzzle makers check.
@@starter

@@tests
import copy
PUZZLE = """
53..7....
6..195...
.98....6.
8...6...3
4..8.3..1
7...2...6
.6....28.
...419..5
....8..79
"""
SOLVED = [[5, 3, 4, 6, 7, 8, 9, 1, 2], [6, 7, 2, 1, 9, 5, 3, 4, 8], [1, 9, 8, 3, 4, 2, 5, 6, 7],
          [8, 5, 9, 7, 6, 1, 4, 2, 3], [4, 2, 6, 8, 5, 3, 7, 9, 1], [7, 1, 3, 9, 2, 4, 8, 5, 6],
          [9, 6, 1, 5, 3, 7, 2, 8, 4], [2, 8, 7, 4, 1, 9, 6, 3, 5], [3, 4, 5, 2, 8, 6, 1, 7, 9]]
HARD = """
8........
..36.....
.7..9.2..
.5...7...
....457..
...1...3.
..1....68
..85...1.
.9....4..
"""
def test_parse():
    "parse"
    b = parse(PUZZLE)
    assert len(b) == 9 and all(len(row) == 9 for row in b)
    assert b[0] == [5, 3, 0, 0, 7, 0, 0, 0, 0] and b[8][8] == 9
def test_options():
    "options"
    b = parse(PUZZLE)
    assert options(b, 0, 2) == {1, 2, 4}
    assert options(b, 4, 4) == {5}
    assert options(b, 8, 0) == {1, 2, 3}
def test_solve():
    "solve"
    b = parse(PUZZLE)
    before = copy.deepcopy(b)
    assert solve(b) == SOLVED
    assert b == before, "solve changed the board it was given"
    h = solve(parse(HARD))
    assert h is not None and h[0] == [8, 1, 2, 7, 5, 3, 6, 4, 9]
    bad = parse(PUZZLE)
    bad[0][2] = 5
    assert solve(bad) is None
def test_show():
    "show"
    lines = show(parse(PUZZLE))
    assert len(lines) == 11
    assert lines[0] == "5 3 . | . 7 . | . . ."
    assert lines[3] == "------+-------+------"
    assert lines[10] == ". . . | . 8 . | . 7 9"
def test_count():
    "count_solutions"
    assert count_solutions(parse(PUZZLE)) == 1
    empty = [[0] * 9 for _ in range(9)]
    assert count_solutions(empty) == 2 and count_solutions(empty, limit=5) == 5
@@hint
`options`: start from `set(range(1, 10))` and take away `set(board[r])`, the column's digits `{board[i][c] for i in range(9)}`, and the box's digits.
@@hint
`solve`: copy the board first (`[row[:] for row in board]`) and write a helper `go()` that returns `True` when the copy is complete. In `go`, find the empty square with the fewest options; if there are no empty squares, return `True`. For each option, put it in, and if `go()` succeeds return `True`; otherwise set the square back to 0. After trying them all, return `False`.
@@hint
`count_solutions` is the same search, but instead of stopping at the first solution it adds 1 and carries on, until it reaches `limit`.
@@solution
def parse(text):
    lines = [line.strip() for line in text.splitlines() if line.strip()]
    return [[0 if ch == "." else int(ch) for ch in line] for line in lines]

def options(board, r, c):
    used = set(board[r]) | {board[i][c] for i in range(9)}
    br, bc = 3 * (r // 3), 3 * (c // 3)
    used |= {board[i][j] for i in range(br, br + 3) for j in range(bc, bc + 3)}
    return set(range(1, 10)) - used

def _best_square(board):
    best = None
    for r in range(9):
        for c in range(9):
            if board[r][c] == 0:
                opts = options(board, r, c)
                if best is None or len(opts) < len(best[2]):
                    best = (r, c, opts)
    return best

def solve(board):
    work = [row[:] for row in board]
    def go():
        best = _best_square(work)
        if best is None:
            return True
        r, c, opts = best
        for d in sorted(opts):
            work[r][c] = d
            if go():
                return True
        work[r][c] = 0
        return False
    return work if go() else None

def show(board):
    lines = []
    for r in range(9):
        if r in (3, 6):
            lines.append("------+-------+------")
        cells = ["." if d == 0 else str(d) for d in board[r]]
        lines.append(" | ".join(" ".join(cells[i:i + 3]) for i in (0, 3, 6)))
    return lines

def count_solutions(board, limit=2):
    work = [row[:] for row in board]
    found = 0
    def go():
        nonlocal found
        best = _best_square(work)
        if best is None:
            found += 1
            return
        r, c, opts = best
        for d in sorted(opts):
            work[r][c] = d
            go()
            if found >= limit:
                break
        work[r][c] = 0
    go()
    return found
:::

:::think title="Why the fewest options first?"
Try `solve` on the hard puzzle choosing the **first** empty square each time instead of the one with the fewest options, and count the calls. Choosing the most constrained square means that a square with only one option is filled without any guessing, and a square with none ends a hopeless path straight away, before any more guesses are piled on top of it. People solving Sudoku with a pencil do the same thing. This "most constrained first" rule speeds up many backtracking searches, from timetables to puzzles.
:::

## Forge bonus: splitting words

Website addresses, hashtags and old telegrams run words together: `"thisisagoodday"`. Splitting them back into words is a branching search: the first word could be `"this"` or `"thi"` (if that were a word) or `"t"`, and each choice leaves a shorter string to split. Without memoisation, a long string with many ways to split can take for ever; with it, each starting position is worked out once.

:::exercise id=forge2 points=30 title="Forge bonus: splitting words"
Given a string `text` and a set `words`, write:

- `can_split(text, words)`: `True` if the whole of `text` can be split into words from `words` (each may be used any number of times). The empty string can always be split.
- `split(text, words)`: one way to split it, as a list of words, choosing at each position the **longest** word that still leads to a full split; `None` if there's no way.
- `count_splits(text, words)`: how many different ways there are. This must be fast for long strings, so memoise on the starting position.
@@starter
from functools import cache

@@tests
WORDS = {"this", "is", "a", "good", "day", "go", "od", "thi", "s", "an", "and", "sand", "cat", "cats", "dog"}
def test_can():
    "can_split"
    assert can_split("thisisagoodday", WORDS) is True
    assert can_split("", WORDS) is True
    assert can_split("catsdogx", WORDS) is False
def test_split():
    "split"
    assert split("thisisagoodday", WORDS) == ["this", "is", "a", "good", "day"]
    assert split("catsanddog", WORDS) == ["cats", "and", "dog"]
    assert split("dogz", WORDS) is None
def test_count():
    "count_splits"
    assert count_splits("catsanddog", WORDS) == 3
    assert count_splits("thisis", WORDS) == 2
    assert count_splits("a" * 200, {"a", "aa", "aaa"}) % 1_000_000 == 530641
@@hint
Write a helper `go(i)` meaning "the answer for `text[i:]`". For `count_splits`, it returns 1 when `i == len(text)`, and otherwise the sum of `go(j)` for every `j` such that `text[i:j]` is a word.
@@hint
For `split`, try the ends `j` from the longest down, and return `[text[i:j]] + rest` for the first `j` where the rest can be split.
@@solution
from functools import cache

def count_splits(text, words):
    longest = max((len(w) for w in words), default=0)
    @cache
    def go(i):
        if i == len(text):
            return 1
        return sum(go(j) for j in range(i + 1, min(len(text), i + longest) + 1) if text[i:j] in words)
    return go(0)

def can_split(text, words):
    return count_splits(text, words) > 0

def split(text, words):
    @cache
    def go(i):
        if i == len(text):
            return []
        for j in range(len(text), i, -1):
            if text[i:j] in words:
                rest = go(j)
                if rest is not None:
                    return [text[i:j]] + rest
        return None
    return go(0)
