## Warm-up

For each of these, which loop would you write, without writing it?

1. Is any mark below 40?
2. The total of all the prices.
3. The words that appear more than once.
4. The position of the first negative number.
5. The longest word.

You probably "saw" the answer to each one before thinking about the details: a check that stops early, a running total, a seen-set, a search that stops at the first match, a best-so-far. Those are **patterns**, and naming them makes them easier to reach for.

## The patterns you know

Here's your library so far, each with its skeleton. Every one of them has appeared in earlier weeks.

| Pattern | Use it when the problem says... | Skeleton |
|---|---|---|
| **Accumulate** | total, product, join all | `total = 0` / `for x in xs: total += x` |
| **Count** | how many | `n = 0` / `for x in xs: if cond: n += 1` |
| **Find first** | the first..., where is..., does it contain | `for i, x in enumerate(xs): if cond: return i` / `return -1` |
| **Best so far** | largest, smallest, longest, the most... | `best = xs[0]` / `for x in xs[1:]: if better(x, best): best = x` |
| **Filter** | only the ones that... | `[x for x in xs if cond]` |
| **Transform** | each one, changed | `[f(x) for x in xs]` |
| **Any / all** | is there any..., are they all... | `any(cond for x in xs)` |
| **Frequency map** | how many of each, most common | `counts[x] = counts.get(x, 0) + 1` |
| **Group** | for each X, the Ys | `groups.setdefault(key(x), []).append(x)` |
| **Seen-set** | duplicates, first repeat, unique | `if x in seen: ...` / `seen.add(x)` |
| **Neighbours** | each with the next, changes, rises | `for a, b in zip(xs, xs[1:]):` |
| **Stack** | matching, nesting, undo, most recent | `stack.append(x)` / `stack.pop()` |

:::example title="Five patterns, five lines each"
marks = [72, 38, 91, 55, 38, 64]
print("any below 40:", any(m < 40 for m in marks))
print("total:", sum(marks))
print("first below 40 at:", next((i for i, m in enumerate(marks) if m < 40), -1))
print("best:", max(marks))
seen, repeats = set(), set()
for m in marks:
    if m in seen:
        repeats.add(m)
    seen.add(m)
print("repeated:", repeats)
:::

`next(generator, default)` gives the first value a generator produces, or the default if there are none: a compact "find first".

:::key
When you meet a problem, ask: which words in it match a pattern? "How many of each" is a frequency map. "Is there any" is `any`. Most problems are two or three patterns combined.
:::

## Two pointers

Some problems on a sequence are easiest with **two positions** moving towards each other from the ends. The classic is checking a palindrome without making a reversed copy:

:::example
def is_palindrome(text):
    left, right = 0, len(text) - 1
    while left < right:
        if text[left] != text[right]:
            return False
        left += 1
        right -= 1
    return True

for t in ["level", "racecar", "python", "", "a", "abba"]:
    print(repr(t), is_palindrome(t))
:::

The real power shows on **sorted** lists. To find two numbers in a sorted list that add up to a target: start at both ends. If the sum is too small, the only way to make it bigger is to move the left pointer right; if it's too big, move the right one left.

:::example
def pair_with_sum(sorted_values, target):
    left, right = 0, len(sorted_values) - 1
    while left < right:
        total = sorted_values[left] + sorted_values[right]
        if total == target:
            return sorted_values[left], sorted_values[right]
        if total < target:
            left += 1
        else:
            right -= 1
    return None

print(pair_with_sum([1, 3, 4, 6, 8, 11], 10))
print(pair_with_sum([1, 3, 4, 6, 8, 11], 13))
:::

Each step moves one pointer, so the whole list is examined in one pass, instead of trying every pair. (You'll measure how much that matters in Week 17.)

## Sliding windows

Many problems ask about every run of `k` **neighbouring** items: the best 3-day total, the busiest hour, the longest stretch without a repeat. The slow way adds up each window from scratch. The **sliding window** way keeps the current window's total and updates it as the window slides: add the item coming in, subtract the item going out.

:::widget slidewindow caption="Slide the window along. Each step does two sums, one item out and one item in, however big the window is. Change the window size with the slider."
:::

:::example
def best_window(values, k):
    """The largest total of k neighbouring values, and where that window starts."""
    if not 1 <= k <= len(values):
        raise ValueError("k must be between 1 and the number of values")
    total = sum(values[:k])
    best, best_start = total, 0
    for i in range(k, len(values)):
        total += values[i] - values[i - k]
        if total > best:
            best, best_start = total, i - k + 1
    return best, best_start

sales = [4, 2, 12, 3, 8, 1, 7, 9, 2, 5]
print(best_window(sales, 3))
:::

Windows can also **stretch and shrink**: to find the longest run of different characters, grow the window on the right, and shrink it from the left whenever a repeat gets in. You'll do that in the daily challenge.

## Prefix sums

Suppose you'll be asked many questions like "what's the total from position 3 to position 7?". Adding up each range is slow if there are many questions. Instead, work out once the **running totals**, where `prefix[i]` is the sum of the first `i` items. Then any range total is one subtraction:

:::example
values = [4, 2, 12, 3, 8, 1, 7]
prefix = [0]
for v in values:
    prefix.append(prefix[-1] + v)
print(prefix)

def range_sum(i, j):
    """The sum of values[i] to values[j], including both."""
    return prefix[j + 1] - prefix[i]

print(range_sum(2, 4), sum(values[2:5]))
print(range_sum(0, 6), sum(values))
:::

`prefix` has one more item than `values`, starting with 0, so that the empty range and the range from the start need no special cases.

## Choosing a pattern

| The problem mentions... | Try |
|---|---|
| each item compared with the next | neighbours |
| a pair, in a sorted list, or the two ends | two pointers |
| every run of k neighbouring items, or the longest stretch with some property | sliding window |
| many questions about totals of ranges | prefix sums |
| matching, nesting, "most recent" | stack |
| "have I seen this before?" | seen-set |
| "how many of each?" | frequency map |

:::exercise id=reverse_words points=10 title="Two pointers: reverse in place"
Write `reverse_in_place(items)` that reverses a list **in place** using two pointers and swaps, without `reverse`, `reversed` or slicing with `[::-1]`. It returns `None`.
@@starter

@@tests

    "several"

        w = list(v)

@@solution
def reverse_in_place(items):
    left, right = 0, len(items) - 1
    while left < right:
        items[left], items[right] = items[right], items[left]
        left += 1
        right -= 1
:::

:::exercise id=clean_palindrome points=10 title="A sentence palindrome"

@@starter

@@tests

Inside the main loop, move `left` right while it's on a non-letter (and still `< right`); likewise move `right` left. Then compare the two letters in lower case.
@@solution
def sentence_palindrome(text):
    left, right = 0, len(text) - 1
    while left < right:
        if not text[left].isalpha():
            left += 1
        elif not text[right].isalpha():
            right -= 1
        elif text[left].lower() != text[right].lower():
            return False
        else:
            left += 1
            right -= 1
    return True
:::

:::exercise id=avg_window points=15 title="Moving averages"
Write `moving_averages(values, k)` that returns the average of every window of `k` neighbouring values, each rounded to 2 places, using a sliding window (a running total, not `sum` of each window). Raise a `ValueError` if `k` isn't from 1 to `len(values)`.
@@starter

@@tests
def test_values():
    "several"
    assert moving_averages([1, 2, 3, 4, 5], 2) == [1.5, 2.5, 3.5, 4.5]
    assert moving_averages([10, 20, 30], 3) == [20.0]
    assert moving_averages([4, 8], 1) == [4.0, 8.0]
    for v, k in (([1, 2], 3), ([1, 2], 0), ([], 1)):
        try:
            moving_averages(v, k)
        except ValueError:
            continue
        raise AssertionError(f"moving_averages({v}, {k}) should raise")
@@solution
def moving_averages(values, k):
    if not 1 <= k <= len(values):
        raise ValueError("bad window size")
    total = sum(values[:k])
    result = [round(total / k, 2)]
    for i in range(k, len(values)):
        total += values[i] - values[i - k]
        result.append(round(total / k, 2))
    return result
:::

:::exercise id=prefix_rain points=15 title="Rainfall questions"
Write `rainfall_answers(daily, questions)` where `daily` is a list of daily rainfall amounts and each question is a tuple `(i, j)` asking for the total from day `i` to day `j` inclusive (days counted from 0). Return the list of answers, building a prefix-sum list once.
@@starter

@@tests
def test_values():
    "several"
    daily = [3, 0, 12, 5, 0, 0, 8]
    assert rainfall_answers(daily, [(0, 6), (2, 3), (4, 5), (6, 6), (0, 0)]) == [28, 17, 0, 8, 3]

def rainfall_answers(daily, questions):
    prefix = [0]
    for amount in daily:
        prefix.append(prefix[-1] + amount)
    return [prefix[j + 1] - prefix[i] for i, j in questions]

def first_repeated_pair(words):
    seen = set()
    for pair in zip(words, words[1:]):
        if pair in seen:
            return pair
        seen.add(pair)
    return None

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: the longest run without repeats"
Write `longest_unique(text)` that returns the longest stretch of **neighbouring** characters in `text` with no character repeated (the first one, if several are equally long). For `"abcabcbb"` it's `"abc"`; for `"pwwkew"` it's `"wke"`. Use a window that stretches and shrinks: move the right edge along one character at a time, and whenever the new character is already in the window, move the left edge just past its previous position. Go through the text once.
@@starter

@@tests
def test_values():
    "several"
    assert longest_unique("abcabcbb") == "abc"
    assert longest_unique("pwwkew") == "wke"
    assert longest_unique("bbbbb") == "b"
    assert longest_unique("") == ""
    assert longest_unique("abba") == "ab"
    assert longest_unique("dvdf") == "vdf"
    assert longest_unique("python atlas") == "python a"
@@hint
Keep `last_seen`, a dictionary from character to its latest position, and `left`, the start of the window. For each position `right`, if the character was last seen at or after `left`, set `left` to that position plus one. Then the window is `text[left:right + 1]`.
@@solution
def longest_unique(text):
    last_seen = {}
    left = 0
    best = ""
    for right, ch in enumerate(text):
        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1
        last_seen[ch] = right
        if right - left + 1 > len(best):
            best = text[left:right + 1]
    return best
:::
