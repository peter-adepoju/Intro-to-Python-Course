## Mixed review

These exercises don't say which tool to use. Deciding is part of the practice.

:::exercise id=mix_change points=10 title="Change"
A customer pays for something. Ask for the price and the amount paid, both whole numbers, with the prompts `Price: ` and `Paid: `. If they paid enough, print `Change: ` and the change. Otherwise print `Short by ` and how much more they need.
@@starter

@@tests
def test_change():
    "paid too much"
    expect_output("Price: 750\nPaid: 1000\nChange: 250", inputs=["750", "1000"], echo=True)
def test_exact():
    "exact money"
    expect_output("Price: 750\nPaid: 750\nChange: 0", inputs=["750", "750"], echo=True)
def test_short():
    "not enough"
    expect_output("Price: 750\nPaid: 500\nShort by 250", inputs=["750", "500"], echo=True)
@@solution
price = int(input("Price: "))
paid = int(input("Paid: "))
if paid >= price:
    print("Change:", paid - price)
else:
    print("Short by", price - paid)
:::

:::exercise id=mix_time points=10 title="Minutes to hours"
Ask for a number of minutes with the prompt `Minutes: ` and print it as hours and minutes, like `2 h 05 min`. If it's under an hour, print just the minutes, like `45 min`.
@@starter

@@tests
def test_long():
    "125 minutes"
    expect_output("Minutes: 125\n2 h 05 min", inputs=["125"], echo=True)
def test_short():
    "45 minutes"
    expect_output("Minutes: 45\n45 min", inputs=["45"], echo=True)
def test_exact():
    "exactly an hour"
    expect_output("Minutes: 60\n1 h 00 min", inputs=["60"], echo=True)
@@hint
`//` and `%` from Week 1 split the minutes. `:02` in an f-string pads to two digits.
@@solution
total = int(input("Minutes: "))
if total < 60:
    print(f"{total} min")
else:
    print(f"{total // 60} h {total % 60:02} min")
:::

:::exercise id=mix_initial points=10 title="Initial check"
Ask for a name with the prompt `Name: `. Print `Early in the alphabet` if its first letter is from A to M (in either case), and `Late in the alphabet` otherwise.
@@starter

@@tests
def test_early():
    "Ada and mike"
    expect_output("Name: Ada\nEarly in the alphabet", inputs=["Ada"], echo=True)
    expect_output("Name: mike\nEarly in the alphabet", inputs=["mike"], echo=True)
def test_late():
    "Ngozi and zara"
    expect_output("Name: Ngozi\nLate in the alphabet", inputs=["Ngozi"], echo=True)
    expect_output("Name: zara\nLate in the alphabet", inputs=["zara"], echo=True)
@@hint
`name[0].lower()` gives the first letter in lower case. Then a chained comparison with `"a"` and `"m"`.
@@solution
name = input("Name: ")
first = name[0].lower()
if "a" <= first <= "m":
    print("Early in the alphabet")
else:
    print("Late in the alphabet")
:::

:::exercise id=mix_round points=10 title="Round to the nearest 50"
Prices are rounded to the nearest 50. Ask for a price (a whole number) with the prompt `Price: ` and print `Rounded: ` and the rounded price. Exactly half way (25 over) rounds **up**.
@@starter

@@tests
def test_cases():
    "several prices"
    for p, r in [(1210, 1200), (1225, 1250), (1240, 1250), (1250, 1250), (1274, 1250), (1275, 1300), (10, 0)]:
        expect_output(f"Price: {p}\nRounded: {r}", inputs=[str(p)], echo=True)
@@hint
`price % 50` is how far you are past the last multiple of 50. If it's 25 or more, go up to the next one.
@@solution
price = int(input("Price: "))
extra = price % 50
if extra >= 25:
    rounded = price - extra + 50
else:
    rounded = price - extra
print("Rounded:", rounded)
:::

## Forge: the ticket machine

Give yourself about an hour. Before you write code, do what you learned on Day 5: read the whole specification, write the decision table for the price, and write a short test plan. Then build the program **one piece at a time**, running it after each piece.

:::exercise id=forge points=50 title="Forge: the ticket machine"
A cinema's ticket machine works like this.

**1. Choose a film.** Print this menu, then ask `Choice: `.

```
1. The Long Night (15)
2. Robot Garden (U)
3. Deep Water (12)
```

If the choice isn't `1`, `2` or `3`, print `Invalid choice` and stop. (No other lines are printed after that.)

**2. Age.** Ask `Age: `. If it isn't a whole number, print `Invalid age` and stop.

**3. Age rating.** A film rated 15 needs the customer to be at least 15, and a film rated 12 needs at least 12. A film rated U has no limit. If they're too young, print `Sorry, this film is rated 15` (or 12) and stop.

**4. Price.** Ask `Student? (y/n) `. The price is:

- 1,000 for children under 12;
- 1,500 for students (any age, as long as they're 12 or over);
- 1,200 for ages 65 and over who aren't students;
- 2,500 for everyone else.

**5. Ticket.** Print a blank line, then the ticket. Lines are 28 characters wide, with the labels left-aligned in 10 and the values right-aligned in 18:

```

============================
Film            Robot Garden
Age                       70
Price                  1,200
============================
```

The whole conversation for that example was: choice `2`, age `70`, student `n`.
@@starter
print("1. The Long Night (15)")
print("2. Robot Garden (U)")
print("3. Deep Water (12)")
choice = input("Choice: ")

@@tests
MENU = "1. The Long Night (15)\n2. Robot Garden (U)\n3. Deep Water (12)\n"
def ticket(film, age, price):
    return f"\n\n{'=' * 28}\n{'Film':<10}{film:>18}\n{'Age':<10}{age:>18}\n{'Price':<10}{price:>18,}\n{'=' * 28}"
def test_example():
    "the example in the task"
    expect_output(MENU + "Choice: 2\nAge: 70\nStudent? (y/n) n" + ticket("Robot Garden", 70, 1200), inputs=["2", "70", "n"], echo=True)
def test_bad_choice():
    "an invalid film choice stops the program"
    expect_output(MENU + "Choice: 4\nInvalid choice", inputs=["4"], echo=True)
    expect_output(MENU + "Choice: two\nInvalid choice", inputs=["two"], echo=True)
def test_bad_age():
    "an invalid age stops the program"
    expect_output(MENU + "Choice: 2\nAge: old\nInvalid age", inputs=["2", "old"], echo=True)
def test_rating():
    "too young for the rating"
    expect_output(MENU + "Choice: 1\nAge: 14\nSorry, this film is rated 15", inputs=["1", "14"], echo=True)
    expect_output(MENU + "Choice: 3\nAge: 11\nSorry, this film is rated 12", inputs=["3", "11"], echo=True)
def test_rating_edges():
    "exactly old enough"
    expect_output(MENU + "Choice: 1\nAge: 15\nStudent? (y/n) n" + ticket("The Long Night", 15, 2500), inputs=["1", "15", "n"], echo=True)
    expect_output(MENU + "Choice: 3\nAge: 12\nStudent? (y/n) n" + ticket("Deep Water", 12, 2500), inputs=["3", "12", "n"], echo=True)
def test_prices():
    "every price band"
    expect_output(MENU + "Choice: 2\nAge: 8\nStudent? (y/n) n" + ticket("Robot Garden", 8, 1000), inputs=["2", "8", "n"], echo=True)
    expect_output(MENU + "Choice: 2\nAge: 8\nStudent? (y/n) y" + ticket("Robot Garden", 8, 1000), inputs=["2", "8", "y"], echo=True)
    expect_output(MENU + "Choice: 3\nAge: 20\nStudent? (y/n) y" + ticket("Deep Water", 20, 1500), inputs=["3", "20", "y"], echo=True)
    expect_output(MENU + "Choice: 1\nAge: 40\nStudent? (y/n) n" + ticket("The Long Night", 40, 2500), inputs=["1", "40", "n"], echo=True)
    expect_output(MENU + "Choice: 1\nAge: 70\nStudent? (y/n) y" + ticket("The Long Night", 70, 1500), inputs=["1", "70", "y"], echo=True)
    expect_output(MENU + "Choice: 1\nAge: 64\nStudent? (y/n) n" + ticket("The Long Night", 64, 2500), inputs=["1", "64", "n"], echo=True)
    expect_output(MENU + "Choice: 1\nAge: 65\nStudent? (y/n) n" + ticket("The Long Night", 65, 1200), inputs=["1", "65", "n"], echo=True)
@@hint
Work step by step. First get the film name and its minimum age into two variables with an `if`/`elif`/`elif`/`else` on the choice (`film = "Robot Garden"`, `min_age = 0`). The `else` prints `Invalid choice`.
@@hint
"Stop" means the rest of the program is inside an `else`. A shape that works: `if choice is bad: print... else: ask age; if age is bad: print... else: ...`. Each check nests one level deeper.
@@hint
The price is its own chain. Check the under-12s first, then students, then 65 and over, then everyone else.
@@hint
`f"{'Price':<10}{price:>18,}"` prints a price with a thousands comma.
@@solution
print("1. The Long Night (15)")
print("2. Robot Garden (U)")
print("3. Deep Water (12)")
choice = input("Choice: ")
if choice == "1":
    film, min_age = "The Long Night", 15
elif choice == "2":
    film, min_age = "Robot Garden", 0
elif choice == "3":
    film, min_age = "Deep Water", 12
else:
    film = ""

if film == "":
    print("Invalid choice")
else:
    text = input("Age: ")
    if not text.isdigit():
        print("Invalid age")
    else:
        age = int(text)
        if age < min_age:
            print(f"Sorry, this film is rated {min_age}")
        else:
            student = input("Student? (y/n) ") == "y"
            if age < 12:
                price = 1000
            elif student:
                price = 1500
            elif age >= 65:
                price = 1200
            else:
                price = 2500
            print()
            print("=" * 28)
            print(f"{'Film':<10}{film:>18}")
            print(f"{'Age':<10}{age:>18}")
            print(f"{'Price':<10}{price:>18,}")
            print("=" * 28)
:::

:::think title="Look back at your Forge"
How deeply nested did your program get? Each "stop" added a level. Next week you'll meet `while` loops, and in Week 6 functions, and both give you cleaner ways to stop early. For now, deep nesting is the honest price of doing it with only `if`.
:::

## Forge bonus: the triangle classifier

:::exercise id=forge2 points=30 title="Forge bonus: the triangle classifier"
Ask for three whole-number side lengths with the prompts `a: `, `b: ` and `c: `. Print exactly one line:

- `Not a triangle` if the lengths can't make a triangle (each side must be shorter than the other two added together);
- `Equilateral` if all three sides are equal;
- `Right-angled` if the square of the longest side equals the sum of the squares of the other two;
- `Isosceles` if exactly two sides are equal;
- `Scalene` otherwise.

Check them in that order. For example `3, 4, 5` is `Right-angled`, and `5, 5, 8` is `Isosceles`.
@@starter

@@tests
def run3(a, b, c):
    return run(inputs=[str(a), str(b), str(c)], echo=True).strip().splitlines()[-1]
def test_not():
    "not a triangle"
    for sides in [(1, 2, 3), (1, 10, 2), (0, 0, 0)]:
        assert run3(*sides) == "Not a triangle", f"{sides} can't make a triangle."
def test_equilateral():
    "equilateral"
    assert run3(4, 4, 4) == "Equilateral"
def test_right():
    "right-angled, with the longest side anywhere"
    for sides in [(3, 4, 5), (5, 3, 4), (13, 5, 12), (6, 10, 8)]:
        assert run3(*sides) == "Right-angled", f"{sides} is right-angled; the longest side can be in any position."
def test_isosceles():
    "isosceles"
    for sides in [(5, 5, 8), (8, 5, 5), (5, 8, 5)]:
        assert run3(*sides) == "Isosceles", f"{sides} has exactly two equal sides."
def test_scalene():
    "scalene"
    assert run3(4, 5, 6) == "Scalene"
@@hint
Any of the three sides could be the longest, so check all three possibilities: `a*a + b*b == c*c or a*a + c*c == b*b or b*b + c*c == a*a`.
@@hint
"Exactly two equal" is `a == b or b == c or a == c`, once you already know they aren't all equal.
@@solution
a = int(input("a: "))
b = int(input("b: "))
c = int(input("c: "))
if not (a < b + c and b < a + c and c < a + b):
    print("Not a triangle")
elif a == b == c:
    print("Equilateral")
elif a * a + b * b == c * c or a * a + c * c == b * b or b * b + c * c == a * a:
    print("Right-angled")
elif a == b or b == c or a == c:
    print("Isosceles")
else:
    print("Scalene")
:::

## Weekly quiz

This quiz covers the whole week. Questions you miss come back in your **daily review**.

:::quiz id=weekly
- q: What is the type of `False`?
  type: text
  answer: ["bool", "<class 'bool'>"]
  explain: "There are exactly two bool values, True and False."
- q: What does this print?
  type: output
  code: |
    print(3 == 3.0, "3" == 3)
  answer: "True False"
  explain: "int and float compare by value; a string never equals a number."
- q: Which is True?
  options: ['`"apple" < "Banana"`', '`"Banana" < "apple"`', '`"apple" == "APPLE"`']
  answer: 1
  explain: "Capital B (66) comes before lower-case a (97)."
- q: What does this print?
  type: output
  code: |
    x = 5
    print(1 < x <= 5)
  answer: "True"
  explain: "Both 1 < 5 and 5 <= 5 hold."
- q: What does this print?
  type: output
  code: |
    print(not True or False and True)
  answer: "False"
  explain: "not first: False or (False and True), which is False or False."
- q: What does `x == "a" or "b"` give when x is "z"?
  options: ["False", "True", '"b"', "an error"]
  answer: 2
  explain: "It's (x == 'a') or 'b', and the left side is False, so you get 'b'."
- q: Which line is safe when d is 0?
  options: ["`10 / d > 2 and d != 0`", "`d != 0 and 10 / d > 2`", "both", "neither"]
  answer: 1
  explain: "Short-circuit: the guard must come first."
- q: What does `"" or "none"` give?
  type: text
  answer: ["none", "'none'", '"none"']
  explain: "The empty string is falsy."
- q: What does this print?
  type: output
  code: |
    n = 10
    if n > 5:
        print("A")
    elif n > 8:
        print("B")
    else:
        print("C")
  answer: "A"
  explain: "The first true condition wins."
- q: What does this print?
  type: output
  code: |
    n = 10
    if n > 5:
        print("A")
    if n > 8:
        print("B")
  answer: "A\nB"
  explain: "Separate ifs are separate decisions."
- q: What error do you get from a missing colon after `if x > 3`?
  type: text
  answer: ["SyntaxError", "syntax error"]
  explain: "Python can't read the line."
- q: A rule says "under 18". Which three ages are the boundary tests?
  options: ["17, 18, 19", "0, 18, 100", "16, 17, 18, 19, 20", "18 only"]
  answer: 0
  explain: "Just below, exactly on, and just above."
- q: What does `"7a".isdigit()` give?
  type: text
  answer: "False"
  explain: "Every character must be a digit."
- q: What does this give?
  code: |
    "even" if 7 % 2 == 0 else "odd"
  type: text
  answer: ["odd", "'odd'", '"odd"']
  explain: "7 % 2 is 1, so the condition is False."
- q: Which is the simplest correct way to write this?
  code: |
    if score >= 50:
        passed = True
    else:
        passed = False
  options: ["`passed = score >= 50`", "`passed = True if score else False`", "`passed = bool(score)`"]
  answer: 0
  explain: "The comparison already is True or False."
:::
