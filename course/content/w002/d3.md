## Warm-up

:::predict
a, b = 4, 0
print(a > 2 and b > 2)
print(a > 2 or b > 2)
print(b != 0 and a / b > 1)
print(not a)
:::

The third line is the guard from yesterday: `b != 0` is `False`, so Python never divides by zero. Today you'll use questions like these to decide which lines run at all.

## Making a choice: if

Here is your first program that doesn't always do the same thing:

:::example title="Run it twice: with 25, then with 15" try=25,15
age = int(input("Age: "))
if age >= 18:
    print("You can vote.")
print("Thanks for checking.")
:::

Run it with `25`, then again with `15`. With 15, the middle message never appears. Now press **X-ray** and step through both times. Watch the yellow line: with 15, it jumps straight from the `if` line to the last line.

The parts of an `if` statement:

```python
if age >= 18:
    print("You can vote.")
```

1. The word `if`.
2. A **condition**: any expression Python can treat as true or false. Everything you learned this week fits here.
3. A **colon** `:`. It means "here comes the part that depends on this".
4. An **indented block**: one or more lines, each pushed in by 4 spaces. These run only when the condition is true.

The line after the block, `print("Thanks for checking.")`, is back at the left edge. That's how Python knows the block has ended, so it runs whatever the answer was.

:::key
Python runs an `if` block only when its condition is true. Otherwise it skips the whole block and carries on with the first line after it.
:::

## Blocks can hold many lines

Every line indented under the `if` belongs to it:

:::example title="A block of three lines" try=12000
total = int(input("Order total: "))
if total >= 10000:
    discount = total // 10
    total = total - discount
    print("You saved", discount)
print("Pay:", total)
:::

Try `12000`, then `5000`. With 5000, all three indented lines are skipped together.

## else: one or the other

Often you want one thing when the answer is yes and something else when it's no. That's `else`:

:::example try=7,10
n = int(input("Number: "))
if n % 2 == 0:
    print(n, "is even")
else:
    print(n, "is odd")
print("Done")
:::

`else` has no condition of its own: it means "if the condition above was false". It lines up with its `if`, ends with a colon, and has its own indented block. Exactly **one** of the two blocks runs, every time.

## Indentation is part of the language

In most languages, indentation is just for looks. In Python it's how you say which lines belong to which block. The standard is **4 spaces** per level; the editors on this site insert them for you when you press Tab or Enter after a colon.

Compare these two programs. The only difference is one indent:

:::example title="Version A" try=3
n = int(input("Number: "))
if n > 5:
    print("Big")
    print("Really big")
:::

:::example title="Version B" try=3
n = int(input("Number: "))
if n > 5:
    print("Big")
print("Really big")
:::

With `3`, Version A prints nothing and Version B prints `Really big`. In B the last line isn't part of the block, so it always runs.

### When indentation goes wrong

Python is strict about it, and these are the errors you'll see:

:::example error=yes title="No block at all"
x = 5
if x > 3:
print("yes")
:::

:::example error=yes title="An indent where none belongs"
x = 5
    print(x)
:::

:::example error=yes title="Forgot the colon"
x = 5
if x > 3
    print("yes")
:::

:::example error=yes title="Indents that don't line up"
x = 5
if x > 3:
    print("yes")
  print("still yes?")
:::

:::tip
Every line in a block must start at exactly the same column. If an error mentions indentation, look at the **left edge** of the reported line and the line above it.
:::

## Any condition will do

The condition can be anything from the last two days: a comparison, a combination with `and` and `or`, a `bool` variable, or any value at all, which Python treats by its truthiness.

:::example title="A bool variable as the condition" try=y
has_coupon = input("Coupon? (y/n) ") == "y"
price = 2000
if has_coupon:
    price = price - 500
print("Price:", price)
:::

:::example title="Truthiness: an empty string is false" try=""
name = input("Name: ")
if name:
    print("Hello,", name)
else:
    print("You didn't type a name.")
:::

`if name:` reads as "if there is a name". Python treats the empty string as false.

:::mistake
`if x = 5:` is a `SyntaxError`. A condition asks a question, so it needs `==`.
:::

## Giving a variable a value in every branch

If a variable is created inside a block, it only exists if that block ran:

:::example error=yes title="Works for some inputs only" try=12
age = int(input("Age: "))
if age >= 18:
    message = "Welcome"
print(message)
:::

Run it with 30 and it works. Run it with 12 and the block is skipped, `message` is never created, and the last line raises a `NameError`. The fix is to make sure **every path** gives it a value:

:::example title="Fixed" try=12
age = int(input("Age: "))
if age >= 18:
    message = "Welcome"
else:
    message = "Sorry, adults only"
print(message)
:::

Another common fix is to give a default first, and change it only when needed:

:::example title="Also fixed" try=12
age = int(input("Age: "))
message = "Sorry, adults only"
if age >= 18:
    message = "Welcome"
print(message)
:::

## Some classic patterns

### The larger of two numbers

:::example
a, b = 17, 42
if a > b:
    largest = a
else:
    largest = b
print(largest)
:::

Python has `max()` for this, but writing it yourself is how you learn to think in branches.

### Absolute value

:::example
n = -8
if n < 0:
    n = -n
print(n)
:::

### Checking input before using it

:::example try=0
d = int(input("Divide 100 by: "))
if d == 0:
    print("You can't divide by zero.")
else:
    print(100 / d)
:::

This is the same guard as yesterday, now written as a decision.

## Conditional expressions

When both branches only choose between two **values**, Python has a one-line form:

:::example
n = 7
kind = "even" if n % 2 == 0 else "odd"
print(kind)
:::

Read it as: "`kind` is `"even"` if `n` is even, else `"odd"`." It's an expression, so it can go anywhere a value can, even inside an f-string:

:::example
items = 1
print(f"You have {items} {'item' if items == 1 else 'items'}.")
items = 3
print(f"You have {items} {'item' if items == 1 else 'items'}.")
:::

:::tip
Use the one-line form only for choosing between two simple values. If either branch needs to *do* something, or the line gets long, write a normal `if`/`else`.
:::

## Quiz

:::quiz id=quiz
- q: What ends the line `if x > 3`?
  options: ["A semicolon", "A colon", "Nothing", "A full stop"]
  answer: 1
  explain: "if, else and every line that introduces a block end with a colon."
- q: How does Python know which lines are inside an if block?
  options: ["They are in curly brackets", "They are indented under it", "They end with a colon", "They come straight after it"]
  answer: 1
  explain: "Indentation is how Python groups lines into blocks."
- q: What does this print?
  type: output
  code: |
    x = 2
    if x > 5:
        print("big")
    print("done")
  answer: "done"
  explain: "The condition is False, so only the line after the block runs."
- q: What does this print?
  type: output
  code: |
    x = 8
    if x > 5:
        print("big")
    else:
        print("small")
  answer: "big"
  explain: "Exactly one branch runs: the condition is True."
- q: 'Which error does `if x == 3` (no colon) give?'
  type: text
  answer: ["SyntaxError", "syntax error"]
  explain: "Python can't read the line, so it's a SyntaxError."
- q: What does this print?
  type: output
  code: |
    n = 0
    if n:
        print("yes")
    else:
        print("no")
  answer: "no"
  explain: "0 is falsy."
- q: What does `"odd" if 4 % 2 else "even"` give?
  type: text
  answer: ["even", "'even'", '"even"']
  explain: "4 % 2 is 0, which is falsy, so the else value is chosen."
- q: Why might this crash?
  code: |
    if score > 50:
        result = "good"
    print(result)
  options: ["result is a reserved word", "If score is 50 or less, result is never created", "print can't take a variable", "It never crashes"]
  answer: 1
  explain: "Every path to print(result) must give result a value."
- q: How many spaces is one level of indentation by convention?
  type: text
  answer: ["4", "four"]
  explain: "PEP 8, Python's style guide, says 4 spaces."
- q: What does this print?
  type: output
  code: |
    a = 5
    if a > 3:
        a = a * 2
    if a > 8:
        a = a + 1
    print(a)
  answer: "11"
  explain: "Both ifs are checked separately: a becomes 10, then 11."
