## Warm-up

:::predict
s = "Hello"
print(len(s))
print(s.upper())
print(s)
:::

`len(s)` and `s.upper()` look different, and the difference matters. The last line shows the other thing to notice: after `s.upper()`, `s` is still `"Hello"`.

## What a method is

A **function** like `len` or `print` stands on its own: you hand it a value in brackets. A **method** belongs to a value. You write the value, a dot, and the method's name:

```python
len(word)         # a function: word goes inside the brackets
word.upper()      # a method: upper belongs to word
```

Every string has the same set of methods, because they come with the `str` type. You've already met a few: `.lower()`, `.upper()`, `.isdigit()`, `.isalpha()`. Today you'll meet the rest of the everyday ones. Python has about 47; nobody memorises them all. You learn the dozen you use most and look up the others.

:::tip
In any Python, `dir(str)` lists every string method, and `help(str.replace)` explains one. Try them in the playground.
:::

## Changing case

:::example
s = "the Python language"
print(s.upper())
print(s.lower())
print(s.title())
print(s.capitalize())
print(s.swapcase())
:::

`.lower()` is the one you'll use most: comparing text without caring about capitals, as you did in Week 2.

## Trimming: strip

Text typed by people, or read from files, often has stray spaces at the ends. `.strip()` removes whitespace (spaces, tabs and new lines) from **both ends**, but never from the middle:

:::example
raw = "   Ada Lovelace   "
print("[" + raw + "]")
print("[" + raw.strip() + "]")
print("[" + raw.lstrip() + "]")
print("[" + raw.rstrip() + "]")
:::

`lstrip` trims only the left end and `rstrip` only the right. Give `strip` an argument to remove other characters from the ends instead:

:::example
print("***SALE***".strip("*"))
print("www.example.com".strip("w.moc"))
:::

The second one surprises people. The argument is a **set of characters** to remove, not a word: `strip` keeps peeling off any of `w`, `.`, `m`, `o` and `c` from both ends until it meets a character that isn't in the set.

:::tip
Strip user input as a habit: `name = input("Name: ").strip()`. A stray space at the end of `"yes "` would otherwise make `answer == "yes"` false.
:::

## Searching: find, index, count

:::example
s = "banana"
print(s.find("an"))
print(s.find("an", 2))
print(s.find("z"))
print(s.count("a"))
print(s.count("an"))
:::

- `.find(sub)` gives the position where `sub` **first** starts, or `-1` if it isn't there. An optional second argument says where to start looking.
- `.rfind(sub)` is the same but searches from the **right**: the last occurrence.
- `.count(sub)` counts how many times `sub` appears, without overlapping.
- `.index(sub)` is like `find`, but raises a `ValueError` if `sub` isn't there:

:::example error=yes
print("banana".index("z"))
:::

Use `find` when "not there" is normal and you'll check for `-1`. Use `index` when "not there" would be a bug that you want to hear about loudly.

`find` and slicing work beautifully together:

:::example title="Split an email address" try=ada@maths.example
email = input("Email: ").strip()
at = email.find("@")
print("User:", email[:at])
print("Domain:", email[at + 1:])
:::

## Replacing

`.replace(old, new)` gives a copy with every `old` replaced by `new`. An optional third argument limits how many are replaced:

:::example
s = "I like cats. cats are great."
print(s.replace("cats", "dogs"))
print(s.replace("cats", "dogs", 1))
print(s.replace(" ", ""))
:::

Replacing with `""` deletes, which is handy for removing every space or every comma.

## Starts and ends with

:::example
filename = "report_final.pdf"
print(filename.endswith(".pdf"))
print(filename.startswith("report"))
print(filename.endswith(".PDF"))
:::

These are clearer and safer than slicing: `filename[-4:] == ".pdf"` breaks if you change the extension to one of a different length.

## Testing what a string contains

These methods all return `True` or `False`, and all return `False` for an empty string:

| Method | True when every character is... |
|---|---|
| `.isalpha()` | a letter |
| `.isdigit()` | a digit 0 to 9 |
| `.isalnum()` | a letter or a digit |
| `.isspace()` | whitespace |
| `.isupper()` | upper case (and there's at least one letter) |
| `.islower()` | lower case (and there's at least one letter) |

:::example
for s in ["abc", "abc123", "123", "  ", "ABC", "Abc", ""]:
    print(repr(s), s.isalpha(), s.isalnum(), s.isdigit(), s.isupper())
:::

`repr(s)` shows a string with its quotes, so you can see empty strings and spaces.

## Methods return new strings

Strings can **never** be changed. Every method that seems to change a string actually builds and returns a new one. If you don't store the result, it's lost:

:::example title="The classic mistake"
name = "ada"
name.upper()
print(name)
:::

:::example title="Store the result"
name = "ada"
name = name.upper()
print(name)
:::

`name = name.upper()` points the label `name` at the new string. The old one is thrown away.

:::key
String methods never change the string they belong to. To keep the result, assign it: `s = s.strip()`.
:::

## Chaining methods

Since a method returns a string, you can call another method on the result straight away. Python works from left to right:

:::example
raw = "   YES please  "
print(raw.strip().lower())
print(raw.strip().lower().startswith("yes"))
:::

Read it as a pipeline: start with `raw`, strip it, make that lower case, then ask whether *that* starts with `"yes"`. Order can matter:

:::example
s = "  Hello  "
print(repr(s.strip().center(11, "*")))
print(repr(s.center(11, "*").strip()))
:::

## Quiz

:::quiz id=quiz
- q: What does this print?
  type: output
  code: |
    s = "abc"
    s.upper()
    print(s)
  answer: "abc"
  explain: "The result of upper() was never stored."
- q: What does `"banana".find("n")` give?
  type: text
  answer: "2"
  explain: "The first n is at position 2."
- q: What does `"banana".find("x")` give?
  type: text
  answer: "-1"
  explain: "find returns -1 when the text isn't there."
- q: What happens with `"banana".index("x")`?
  options: ["-1", "None", "A ValueError", "0"]
  answer: 2
  explain: "index raises an error instead of returning -1."
- q: What does `"  hi  ".strip()` give?
  type: text
  answer: ["hi", "'hi'", '"hi"']
  explain: "Whitespace is removed from both ends."
- q: What does `"a-b-c".replace("-", "")` give?
  type: text
  answer: ["abc", "'abc'", '"abc"']
  explain: "Replacing with an empty string deletes."
- q: Which is True?
  options: ['`"abc1".isalpha()`', '`"".isdigit()`', '`"abc1".isalnum()`', '`" ".isalpha()`']
  answer: 2
  explain: "Letters and digits count as alphanumeric."
- q: What does this print?
  type: output
  code: |
    print("  Yes ".strip().lower() == "yes")
  answer: "True"
  explain: "Strip first, then lower case."
- q: How do you call a method on a string s?
  options: ["method(s)", "s.method()", "s->method()", "s[method]"]
  answer: 1
  explain: "The value, a dot, and the method name."
- q: What does `"hello world".title()` give?
  type: text
  answer: ["Hello World", "'Hello World'", '"Hello World"']
  explain: "Each word starts with a capital."

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: make a URL slug"
Blogs turn titles into web addresses called **slugs**: `Hello, World! Learning Python in 2026` becomes `hello-world-learning-python-in-2026`. The rules:

- lower case;
- letters and digits are kept;
- every run of other characters (spaces, punctuation) becomes a **single** `-`;
- no `-` at the start or end.

Ask for a title with the prompt `Title: ` and print the slug.
@@starter

@@tests
def test_cases():
    "several titles"
    for t, s in [("Hello, World! Learning Python in 2026", "hello-world-learning-python-in-2026"),
                 ("  10 Tips & Tricks!!  ", "10-tips-tricks"), ("Simple", "simple"), ("C++ vs. Rust", "c-vs-rust")]:
        expect_output(f"Title: {t}\n{s}", inputs=[t], echo=True)
@@hint
Loop over the lower-case title. Keep each letter or digit. For anything else, add a `-` only if the slug so far doesn't already end with one.
@@hint
At the end, `.strip("-")` removes a dash from either end.
@@solution
title = input("Title: ").lower()
slug = ""
for ch in title:
    if ch.isalnum():
        slug += ch
    elif not slug.endswith("-"):
        slug += "-"
print(slug.strip("-"))
:::
