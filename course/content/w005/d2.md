## split: one string into many

:::example
sentence = "the quick brown fox"
words = sentence.split()
print(words)
print(len(words))
print(words[0], words[-1])
:::

`.split()` cuts the string wherever there's whitespace and gives back the pieces. The result, written with square brackets, is a **list**: an ordered collection of values. Lists get two whole weeks of their own (Weeks 8 and 9). For now you only need three things, and they all work the way they do for strings:

- `len(words)` is how many pieces there are;
- `words[0]` is the first piece, `words[-1]` the last;
- `for w in words:` visits each piece in turn.

:::example title="Visit each word"
for word in "split makes this easy".split():
    print(word.upper(), len(word))
:::

### With no argument, or with a separator

With **no argument**, `split()` treats any run of whitespace (spaces, tabs, new lines) as one break, and ignores whitespace at the ends. That's what you want for words:

:::example
print("  lots   of    space  ".split())
:::

With **an argument**, it splits on exactly that text, every time it appears. Two separators in a row give an **empty** piece between them:

:::example
print("2026-10-26".split("-"))
print("a,b,,c".split(","))
print("a  b".split(" "))
:::

:::key
`split()` with no argument is for words: runs of whitespace count as one break. `split(sep)` is for data with a fixed separator: every single separator makes a break, even if that gives empty pieces.
:::

You can limit the number of cuts with a second argument:

:::example
print("key=value=with=equals".split("=", 1))
:::

## join: many strings into one

`join` is the opposite of `split`. You call it on the **separator**, and pass it the pieces:

:::example
words = ["the", "quick", "brown", "fox"]
print(" ".join(words))
print("-".join(words))
print("".join(words))
print(", ".join(words))
:::

It reads a little backwards at first: `"-".join(words)` means "join the words, with `-` between them". The separator goes **between** pieces, never at the start or end, so there's no trailing comma to remove.

`split` and `join` together make a powerful pair:

:::example title="Tidy the spaces in a sentence"
messy = "  too    many     spaces   here "
print(" ".join(messy.split()))
:::

:::example title="Reverse the order of the words"
s = "one two three four"
backwards = ""
for word in s.split():
    backwards = word + " " + backwards
print(backwards.strip())
:::

(In Week 8 you'll learn a one-step way to reverse a list.)

:::mistake
`join` only joins **strings**. Joining numbers raises a `TypeError`. Convert them first, with `str()`.
:::

:::example error=yes
print(", ".join([1, 2, 3]))
:::

## Reading several values from one line

Until now, each `input()` read one value. With `split`, the user can type several on one line:

:::example title="Two numbers on one line" try="12 30"
a, b = input("Two numbers: ").split()
print(int(a) + int(b))
:::

`a, b = ...` unpacks the two pieces into two names, just like `a, b = 1, 2` in Week 1. It needs exactly as many names as pieces, or Python raises a `ValueError`.

When you don't know how many values are coming, loop over the pieces:

:::example title="Any number of numbers" try="4 8 15 16 23 42"
total = 0
count = 0
for piece in input("Numbers: ").split():
    total += int(piece)
    count += 1
print("Sum:", total, "Average:", total / count)
:::

### Data with separators

Lots of real data looks like `name:score` or `21/10/2026`. Split on the separator, then pick out the parts:

:::example title="Reformat a date"
date = "26/10/2026"
day, month, year = date.split("/")
print(f"{year}-{month}-{day}")
:::

:::example title="Name and score" try=Ada:93
entry = input("name:score ")
name, score = entry.split(":")
print(name.strip(), "scored", int(score))
:::

## Strings can't be changed

You've seen hints of this all week. Now the rule: once a string exists, it can **never** be changed. Not one character of it.

:::example error=yes
word = "jello"
word[0] = "h"
:::

`TypeError: 'str' object does not support item assignment`. To get `"hello"`, you build a **new** string and point the name at it:

:::example
word = "jello"
word = "h" + word[1:]
print(word)
:::

This is called **immutability**, and it's deliberate. Remember from Week 1 that names are labels on objects. If two names point at the same string and strings could change, changing it through one name would silently change it for the other. Because strings are immutable, sharing them is always safe:

:::example title="Sharing is safe"
a = "python"
b = a
a = a.upper()
print(a, b)
:::

`a.upper()` made a new string, and `a = ...` moved the label `a` to it. `b` still points at the original. In Week 8 you'll meet lists, which **can** change, and this exact situation becomes a famous source of bugs.

:::note
Building a long string one piece at a time with `+=` creates a new string every time. For a few hundred pieces it doesn't matter. For millions, collect the pieces and `join` them once; you'll see how in Week 8.
:::

## Quiz

:::quiz id=quiz
- q: What does `"a  b c".split()` give?
  type: text
  answer: ["['a', 'b', 'c']", '["a", "b", "c"]']
  explain: "Runs of whitespace count as one break."
- q: What does `"a,,b".split(",")` give?
  type: text
  answer: ["['a', '', 'b']", '["a", "", "b"]']
  explain: "Two separators in a row leave an empty piece."
- q: What does `"+".join(["1", "2", "3"])` give?
  type: text
  answer: ["1+2+3", "'1+2+3'", '"1+2+3"']
  explain: "The separator goes between the pieces."
- q: What happens with `"-".join([1, 2])`?
  options: ["'1-2'", "A TypeError", "'12'", "3"]
  answer: 1
  explain: "join only joins strings."
- q: What does this print?
  type: output
  code: |
    a, b = "7 9".split()
    print(a + b)
  answer: "79"
  explain: "The pieces are strings, so + joins them."
- q: What happens with `word[0] = "X"`?
  options: ["The first letter changes", "A TypeError: strings can't be changed", "A new string is made", "Nothing"]
  answer: 1
  explain: "Strings are immutable."
- q: How many pieces does `"a b c".split(" ", 1)` give?
  type: text
  answer: ["2", "two"]
  explain: "Only one cut: ['a', 'b c']."
- q: What does this print?
  type: output
  code: |
    a = "hi"
    b = a
    a = a + "!"
    print(b)
  answer: "hi"
  explain: "a now points at a new string; b still points at the old one."
- q: Which line tidies all the spaces in s into single spaces?
  options: ['`s.replace(" ", "")`', '`" ".join(s.split())`', '`s.strip()`', '`s.split(" ")`']
  answer: 1
  explain: "split() then join with one space."
- q: What does `len("".split())` give?
  type: text
  answer: "0"
  explain: "An empty string has no words."
:::

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: Pig Latin"
Pig Latin is a word game. To translate a word:

- if it starts with a vowel (a, e, i, o, u), add `way` to the end: `apple` → `appleway`;
- otherwise, move all the consonants **before the first vowel** to the end and add `ay`: `string` → `ingstray`, `pig` → `igpay`;
- a word with no vowels at all just gets `ay`: `rhythm` → `rhythmay`.

Ask for a sentence (lower-case words, no punctuation) with the prompt `Sentence: ` and print it in Pig Latin, words separated by single spaces.
@@starter

@@tests
def pig(w):
    for i in range(len(w)):
        if w[i] in "aeiou":
            return w + "way" if i == 0 else w[i:] + w[:i] + "ay"
    return w + "ay"
def test_cases():
    "several sentences"
    for s in ["pig latin is fun", "apple string rhythm", "  the   quick brown fox  "]:
        expect_output(f"Sentence: {s}\n" + " ".join(pig(w) for w in s.split()), inputs=[s], echo=True)
@@hint
For each word, find the position of the first vowel with a loop (find first). Then the answer is a slice after it, plus a slice before it, plus `ay`.
@@solution
s = input("Sentence: ")
out = ""
for w in s.split():
    first = -1
    for i in range(len(w)):
        if w[i] in "aeiou":
            first = i
            break
    if first == 0:
        piece = w + "way"
    elif first == -1:
        piece = w + "ay"
    else:
        piece = w[first:] + w[:first] + "ay"
    out = piece if out == "" else out + " " + piece
print(out)
:::
