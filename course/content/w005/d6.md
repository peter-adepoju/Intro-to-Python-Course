## Mixed review

:::exercise id=mix_camel points=10 title="camelCase to snake_case"
Some languages name things in `camelCase`; Python uses `snake_case`. Ask for a camelCase name with the prompt `Name: ` and print it in snake_case: every capital letter becomes an underscore followed by the lower-case letter. `totalPriceInNaira` becomes `total_price_in_naira`.
@@starter

@@tests
def test_cases():
    "several names"
    for c, s in [("totalPriceInNaira", "total_price_in_naira"), ("x", "x"), ("numberOfStudents", "number_of_students"), ("getURL", "get_u_r_l")]:
        expect_output(f"Name: {c}\n{s}", inputs=[c], echo=True)
@@solution
name = input("Name: ")
out = ""
for ch in name:
    if ch.isupper():
        out += "_" + ch.lower()
    else:
        out += ch
print(out)
:::

:::exercise id=mix_sentences points=10 title="Count the sentences"
Ask for some text with the prompt `Text: ` and print `Sentences: ` and the number of sentences. A sentence ends with `.`, `!` or `?`, but a run of them like `?!` or `...` ends only one sentence.
@@starter

@@tests
def test_cases():
    "several texts"
    for t, n in [("Hi. How are you? Great!", 3), ("Wait... What?!", 2), ("No end", 0), ("One.", 1)]:
        expect_output(f"Text: {t}\nSentences: {n}", inputs=[t], echo=True)
@@hint
Compare with the previous character: count an ending character only if the previous one wasn't also an ending character.
@@solution
text = input("Text: ")
count = 0
prev = ""
for ch in text:
    if ch in ".!?" and prev not in ".!?":
        count += 1
    prev = ch
print("Sentences:", count)
:::

:::exercise id=mix_mask points=10 title="Mask a card number"

@@starter

@@tests

@@solution

        seen += 1
        out += "*" if seen <= total - 4 else ch

        out += ch
print(out)

## Forge: the receipt maker

About an hour. Shops often receive orders as one line of text. Your program turns that line into a receipt. Plan the parsing first: what do you split on, and in what order? Then plan the layout: which widths depend on the data?

:::exercise id=forge points=50 title="Forge: the receipt maker"
Ask for an order with the prompt `Order: `. An order is a list of items separated by `;`. Each item looks like `name x quantity @ price`, with any amount of space around the parts, for example:

```
Rice (5kg) x 2 @ 8500; bread x1@950 ;  Palm oil x 3 @ 1200.50
```

Print a receipt like this:

```
Item          Qty      Price      Total
---------------------------------------
Rice (5kg)      2   8,500.00  17,000.00
Bread           1     950.00     950.00
Palm Oil        3   1,200.50   3,601.50
---------------------------------------
Subtotal                      21,551.50
VAT 7.5%                       1,616.36
TOTAL                         23,167.86
```

The rules:

- Item names are stripped and written in title case.
- The item column is as wide as the longest item name or the word `Item`, whichever is longer. Then a space, then `Qty` right-aligned in 4, `Price` and `Total` right-aligned in 11, all money with thousands separators and 2 decimal places.
- The dashed lines are as wide as the whole table.
- The `Subtotal`, `VAT 7.5%` and `TOTAL` labels are left-aligned in a column as wide as the table minus 11, then the amount right-aligned in 11.
- Empty items (for example from a `;` at the very end) are skipped.
- If any item can't be read (missing `x` or `@`, or a quantity that isn't a whole number), print `Can't read: ` and that item exactly as it appeared, stripped, and print **no** receipt.
@@starter
order = input("Order: ")

@@tests
def build(line):
    items = []
    for raw in line.split(";"):
        raw = raw.strip()
        if not raw:
            continue
        x = raw.find(" x")
        at = raw.find("@")
        if x == -1 or at == -1 or at < x:
            return "Can't read: " + raw
        name = raw[:x].strip().title()
        q = raw[x + 2:at].strip()
        if not q.isdigit():
            return "Can't read: " + raw
        items.append((name, int(q), float(raw[at + 1:].strip())))
    w = max([len("Item")] + [len(n) for n, _, _ in items])
    width = w + 1 + 4 + 11 + 11
    rows = [f"{'Item':<{w}} {'Qty':>4}{'Price':>11}{'Total':>11}", "-" * width]
    sub = 0
    for n, q, p in items:
        rows.append(f"{n:<{w}} {q:>4}{p:>11,.2f}{q * p:>11,.2f}")
        sub += q * p
    vat = sub * 0.075
    rows += ["-" * width, f"{'Subtotal':<{width - 11}}{sub:>11,.2f}", f"{'VAT 7.5%':<{width - 11}}{vat:>11,.2f}", f"{'TOTAL':<{width - 11}}{sub + vat:>11,.2f}"]
    return "\n".join(rows)
def check(line):
    expect_output("Order: " + line + "\n" + build(line), inputs=[line], echo=True)
def test_example():
    "the example"
    check("Rice (5kg) x 2 @ 8500; bread x1@950 ;  Palm oil x 3 @ 1200.50")
def test_one():
    "a single item, trailing semicolon"
    check("tea x 4 @ 150;")
def test_long_name():
    "a long name widens the table"
    check("extra large family size pizza x 1 @ 15000; cola x 6 @ 400")
def test_bad():
    "an item that can't be read"
    check("rice x 2 @ 8500; bread 950; tea x 1 @ 100")
    check("rice x two @ 8500")
@@hint
For each item, find `" x"` (a space then x, so a name like `Xylophone` or `box` doesn't confuse it) and `"@"`. The name is before `" x"`, the quantity is between, and the price is after `@`.
@@hint
You need two passes: one to read and check every item and find the longest name, and one to print. Since you don't have lists yet, the simplest way is to loop over `order.split(";")` twice: the first time to validate and measure, the second to print.
@@hint
Width of the table: `w + 1 + 4 + 11 + 11`, where `w` is the item column width.
@@solution
order = input("Order: ")
w = len("Item")
bad = ""
for raw in order.split(";"):
    raw = raw.strip()
    if raw == "":
        continue
    x = raw.find(" x")
    at = raw.find("@")
    if x == -1 or at == -1 or at < x or not raw[x + 2:at].strip().isdigit():
        bad = raw
        break
    w = max(w, len(raw[:x].strip()))
if bad:
    print("Can't read:", bad)
else:
    width = w + 1 + 4 + 11 + 11
    print(f"{'Item':<{w}} {'Qty':>4}{'Price':>11}{'Total':>11}")
    print("-" * width)
    subtotal = 0
    for raw in order.split(";"):
        raw = raw.strip()
        if raw == "":
            continue
        x = raw.find(" x")
        at = raw.find("@")
        name = raw[:x].strip().title()
        qty = int(raw[x + 2:at].strip())
        price = float(raw[at + 1:].strip())
        print(f"{name:<{w}} {qty:>4}{price:>11,.2f}{qty * price:>11,.2f}")
        subtotal += qty * price
    vat = subtotal * 0.075
    print("-" * width)
    print(f"{'Subtotal':<{width - 11}}{subtotal:>11,.2f}")
    print(f"{'VAT 7.5%':<{width - 11}}{vat:>11,.2f}")
    print(f"{'TOTAL':<{width - 11}}{subtotal + vat:>11,.2f}")
:::

:::think title="The cost of not having lists"
You had to split the order twice, and work out each item's parts twice. In Week 8, lists let you read every item once, store the pieces, and use them as often as you like. Remember this program: you will rewrite it then, in half the code.
:::

## Forge bonus: Morse code

:::exercise id=forge2 points=30 title="Forge bonus: Morse code"
Morse code writes each letter as dots and dashes. Here are the codes for `a` to `z`, in order, in one string:

```python
MORSE = ".- -... -.-. -.. . ..-. --. .... .. .--- -.- .-.. -- -. --- .--. --.- .-. ... - ..- ...- .-- -..- -.-- --.."
```

`MORSE.split()` turns it into a lookup table: piece number 0 is the code for `a`, piece number 1 is for `b`, and so on, so the code for a letter is `codes[ord(letter) - ord("a")]`.

Ask for a mode with the prompt `Mode (to/from): `, then a message with the prompt `Message: `.

- **to**: translate the message into Morse. Letters are separated by single spaces and words by ` / `. Ignore anything that isn't a letter or a space, and ignore case. `Hi there!` becomes `.... .. / - .... . .-. .`.
- **from**: translate Morse back into lower-case text. Codes are separated by spaces, and `/` separates words. An unknown code becomes `?`.
@@starter
MORSE = ".- -... -.-. -.. . ..-. --. .... .. .--- -.- .-.. -- -. --- .--. --.- .-. ... - ..- ...- .-- -..- -.-- --.."
codes = MORSE.split()

@@tests
M = ".- -... -.-. -.. . ..-. --. .... .. .--- -.- .-.. -- -. --- .--. --.- .-. ... - ..- ...- .-- -..- -.-- --..".split()
def to_m(t):
    words = []
    for w in t.lower().split():
        letters = [M[ord(c) - 97] for c in w if "a" <= c <= "z"]
        if letters:
            words.append(" ".join(letters))
    return " / ".join(words)
def from_m(m):
    out = []
    for w in m.split("/"):
        out.append("".join(chr(M.index(c) + 97) if c in M else "?" for c in w.split()))
    return " ".join(out)
def test_to():
    "into Morse"
    for t in ["Hi there!", "SOS", "Python Atlas"]:
        expect_output(f"Mode (to/from): to\nMessage: {t}\n{to_m(t)}", inputs=["to", t], echo=True)
def test_from():
    "from Morse"
    for m in [".... .. / - .... . .-. .", "... --- ...", ".--. -.-- / ......"]:
        expect_output(f"Mode (to/from): from\nMessage: {m}\n{from_m(m)}", inputs=["from", m], echo=True)
@@hint
**to**: loop over the words from `split()`; for each word, build its letters' codes joined by spaces; then join the words with `" / "`. Skip words that end up empty.
@@hint
**from**: split on `/` to get words, then split each word into codes. To find which letter a code is, loop `for i in range(26)` and compare with `codes[i]`; the letter is `chr(i + ord("a"))`.
@@solution
MORSE = ".- -... -.-. -.. . ..-. --. .... .. .--- -.- .-.. -- -. --- .--. --.- .-. ... - ..- ...- .-- -..- -.-- --.."
codes = MORSE.split()
mode = input("Mode (to/from): ")
msg = input("Message: ")
if mode == "to":
    out = ""
    for word in msg.lower().split():
        w = ""
        for ch in word:
            if "a" <= ch <= "z":
                w = w + " " + codes[ord(ch) - ord("a")] if w else codes[ord(ch) - ord("a")]
        if w:
            out = out + " / " + w if out else w
    print(out)
else:
    out = ""
    for word in msg.split("/"):
        text = ""
        for code in word.split():
            letter = "?"
            for i in range(26):
                if codes[i] == code:
                    letter = chr(i + ord("a"))
                    break
            text += letter
        out = out + " " + text if out else text
    print(out)
:::
