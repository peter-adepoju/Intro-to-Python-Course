## The format spec, part by part

Inside an f-string, `{value:spec}` formats `value` according to `spec`. A spec can have up to seven parts, and they always come **in this order**:

```
{value:  fill  align  sign  width  grouping  .precision  type}
         *     >      +     10     ,         .2          f
```

Every part is optional. Here's that whole example, and some of its parts on their own:

:::example
x = 1234.5678
print(f"[{x:*>+10,.2f}]")
print(f"[{x:10.2f}]")
print(f"[{x:<10.1f}]")
print(f"[{x:^12,.0f}]")
:::

The parts:

| Part | Options | Meaning |
|---|---|---|
| fill | any one character | what pads the empty space (only with an align) |
| align | `<` `>` `^` `=` | left, right, centre; `=` pads after the sign |
| sign | `+` `-` space | show `+` on positives; only `-` (the default); a space for positives |
| width | a number | the minimum total width |
| grouping | `,` or `_` | thousands separators |
| precision | `.` then a number | digits after the point for `f`; maximum length for strings |
| type | `f` `e` `%` `d` `b` `o` `x` `X` `s` ... | how to write the value |

The figure from Week 1 builds specs for you. Try a sign and a fill together:

:::widget fstringlab caption="Build a spec from its parts and see Python's exact output. Padding is underlined in yellow."
{"value": "-1234.5", "name": "x"}
:::

:::key
Numbers are right-aligned by default and strings are left-aligned. Give an explicit `<`, `>` or `^` whenever the default isn't what you want.
:::

### Precision on strings

For a string, the precision is a **maximum length**. It truncates:

:::example
title = "A Very Long Book Title Indeed"
print(f"[{title:.10}]")
print(f"[{title:15.10}]")
:::

## Numbers: signs, bases and scientific

### Signs

:::example
for change in [3.25, -1.5, 0]:
    print(f"{change:+.1f}%   [{change: .1f}]")
:::

`+` is perfect for changes, scores and temperatures, where a plus sign carries meaning.

### Percentages and scientific notation

`%` multiplies by 100 and adds a percent sign. `e` writes numbers in scientific notation, which is how scientists write very large and very small numbers:

:::example
print(f"{0.4567:.1%}")
print(f"{299792458:.3e}")
print(f"{0.000000123:.2e}")
print(f"{6.02214076e23:.4g}")
:::

`2.998e+08` means 2.998 × 10⁸. The `g` type ("general") chooses between plain and scientific automatically.

### Binary, octal and hexadecimal

In Week 1 you saw that computers store everything in binary. Format codes write integers in other bases: `b` for binary (base 2), `o` for octal (base 8), `x` and `X` for hexadecimal (base 16, using the digits 0 to 9 and a to f):

:::example
n = 2026
print(f"{n:b}")
print(f"{n:o}")
print(f"{n:x}  {n:X}")
print(f"{n:#x}  {n:#b}")
print(f"{5:08b}")
:::

The `#` adds the prefix Python uses for that base (`0b`, `0o`, `0x`). `08b` pads with zeros to 8 binary digits, which is one **byte**.

Hexadecimal is everywhere in computing because each hex digit is exactly 4 bits. Web colours are written as three hex bytes, for red, green and blue:

:::example title="A colour as hex"
r, g, b = 242, 194, 48
print(f"#{r:02x}{g:02x}{b:02x}")
:::

That's the yellow this site uses to show the line that's about to run.

Going the other way, `int(text, base)` reads a string written in another base:

:::example
print(int("11111101010", 2))
print(int("7ea", 16))
print(int("ff", 16))
:::

## Widths from variables

Sometimes the width isn't known when you write the code. Put a variable in its own braces **inside** the spec:

:::example title="Nested braces"
width = 12
for word in ["cat", "giraffe", "ox"]:
    print(f"[{word:>{width}}]")
digits = 3
print(f"{3.14159265:.{digits}f}")
:::

### Showing exactly what a value is: !r

`!r` formats a value with `repr()` instead of `str()`, which shows quotes on strings and makes spaces and escape characters visible. It's the best way to debug a string you don't trust:

:::example
answer = "yes \n"
print(f"Got {answer}!")
print(f"Got {answer!r}!")
print(f"{answer=}")
:::

The `=` shortcut from Week 3 uses `!r` automatically.

## Tables that fit their data

A table with fixed widths breaks the moment a value is longer than you planned. The professional approach takes **two passes**: first find the longest value in each column, then print every row using those widths.

:::example title="Columns that fit"
names = "Ada,Grace,Alan,Katherine"
scores = "93,88,97,100"
w = len("Name")
for name in names.split(","):
    w = max(w, len(name))
print(f"{'Name':<{w}}  {'Score':>5}")
print("-" * (w + 7))
name_list = names.split(",")
score_list = scores.split(",")
for i in range(len(name_list)):
    print(f"{name_list[i]:<{w}}  {int(score_list[i]):>5}")
:::

Change one of the names to something much longer and run it again. Every column adjusts.

### Bars and boxes

Repetition and widths together make simple charts:

:::example title="A progress bar"
done = 7
total = 20
width = 30
filled = round(width * done / total)
print(f"[{'#' * filled}{'.' * (width - filled)}] {done / total:.0%}")
:::

:::example title="A box around a message"
msg = "Python Atlas"
print("+" + "-" * (len(msg) + 2) + "+")
print(f"| {msg} |")
print("+" + "-" * (len(msg) + 2) + "+")
:::

## Older styles you'll meet

f-strings arrived in Python 3.6, in 2016. Code written before then, and some code written since, uses two older styles. You don't need to write them, but you'll need to read them:

:::example
name, score = "Ada", 93.456
print("%s scored %.1f" % (name, score))
print("{} scored {:.1f}".format(name, score))
print(f"{name} scored {score:.1f}")
:::

All three print the same thing. The format specs after the colon in the `.format()` style are exactly the ones you learned today.

## Quiz

:::quiz id=quiz
- q: In what order do the parts of a format spec come?
  options: ["width, align, fill, type", "fill, align, sign, width, grouping, precision, type", "type, precision, width", "any order"]
  answer: 1
  explain: "Fill and align first, type last."
- q: What does `f"{7:+}"` give?
  type: text
  answer: ["+7", "'+7'"]
  explain: "The + sign option shows a plus on positive numbers."
- q: What does `f"{10:b}"` give?
  type: text
  answer: ["1010", "'1010'"]
  explain: "10 in binary."
- q: What does `int("ff", 16)` give?
  type: text
  answer: "255"
  explain: "f is 15: 15 x 16 + 15."
- q: What does `f"{'python':.3}"` give?
  type: text
  answer: ["pyt", "'pyt'"]
  explain: "For strings, precision is a maximum length."
- q: What does `f"{0.5:.0%}"` give?
  type: text
  answer: ["50%", "'50%'"]
  explain: "% multiplies by 100."
- q: How do you take the width from a variable w?
  options: ['`f"{x:w}"`', '`f"{x:{w}}"`', '`f"{x:(w)}"`', '`f"{x}:{w}"`']
  answer: 1
  explain: "A variable inside the spec needs its own braces."
- q: What does `!r` do in `f"{s!r}"`?
  options: ["Reverses s", "Formats s with repr(), showing quotes and escapes", "Rounds s", "Right-aligns s"]
  answer: 1
  explain: "Great for seeing hidden spaces."
- q: How are strings aligned by default in a width?
  options: ["Left", "Right", "Centre"]
  answer: 0
  explain: "Numbers go right, strings go left."
- q: What does `"%.2f" % 3.14159` give?
  type: text
  answer: ["3.14", "'3.14'"]
  explain: "The old style with the same precision code."

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: the auto-sized multiplication table"
Ask for `n` with the prompt `n: ` and print an `n` by `n` multiplication table with a header row and header column, separated by lines. **Every** column is exactly as wide as the largest number in the whole table, plus one space in front. For `n = 4`:

```
n: 4
  x |  1  2  3  4
----+------------
  1 |  1  2  3  4
  2 |  2  4  6  8
  3 |  3  6  9 12
  4 |  4  8 12 16
```

The left column (with `x` and the row numbers) uses the same width plus one, then ` |`. The dashed line has a `+` under the `|`.
@@starter

@@tests
def table(n):
    w = len(str(n * n))
    rows = [f"{'x':>{w + 1}} |" + "".join(f"{c:>{w + 1}}" for c in range(1, n + 1))]
    rows.append("-" * (w + 2) + "+" + "-" * ((w + 1) * n))
    for r in range(1, n + 1):
        rows.append(f"{r:>{w + 1}} |" + "".join(f"{r * c:>{w + 1}}" for c in range(1, n + 1)))
    return "\n".join(rows)
def test_cases():
    "several sizes"
    for n in [4, 1, 10, 12]:
        expect_output(f"n: {n}\n" + table(n), inputs=[str(n)], echo=True)
@@hint
The largest number is `n * n`, so the width is `len(str(n * n))`. Every cell, including the header cells, is `f"{value:>{w + 1}}"`.
@@hint
Build each row as a string in an inner loop, then print it.
@@solution
n = int(input("n: "))
w = len(str(n * n))
header = f"{'x':>{w + 1}} |"
for c in range(1, n + 1):
    header += f"{c:>{w + 1}}"
print(header)
print("-" * (w + 2) + "+" + "-" * ((w + 1) * n))
for r in range(1, n + 1):
    row = f"{r:>{w + 1}} |"
    for c in range(1, n + 1):
        row += f"{r * c:>{w + 1}}"
    print(row)
:::
