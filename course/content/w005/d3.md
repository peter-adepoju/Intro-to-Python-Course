## Warm-up

:::predict
text = "banana"
print(text[1:4])
print(text[1:4] == "ana")
print(text.count("ana"))
:::

`count` says `"ana"` appears once, but look again: it starts at position 1 **and** at position 3. The two overlap, and `count` doesn't count overlaps. Today you'll write your own search that does.

## Searching for a pattern yourself

`in`, `.find()` and `.count()` all search for a pattern. Underneath, the simplest way to search is this: put the pattern at every position in the text, and check whether the slice there matches.

:::example title="Every position, including overlaps"
text = "banana"
pattern = "ana"
for i in range(len(text) - len(pattern) + 1):
    if text[i:i + len(pattern)] == pattern:
        print("Found at", i)
:::

The range stops at `len(text) - len(pattern) + 1` because the pattern has to fit: the last place it can start is `len(text) - len(pattern)`. Watch the search work character by character:

:::widget textsearch caption="The pattern slides along the text. At each position the characters are compared from the left, stopping at the first difference. Green shows matches found so far. Try a text with lots of near misses, like aaaaaaab and aab."
{"text": "abracadabra", "pattern": "abra"}
:::

:::note
This simple method can be slow for long patterns with many near misses: for every position it might compare almost the whole pattern. Python's own `find` uses cleverer algorithms. You'll study them in Phase 4.
:::

## Sliding windows

The search above looks at a **window** of the text, `len(pattern)` characters wide, at every position. The window idea is useful on its own:

:::example title="Every three-letter chunk"
word = "python"
for i in range(len(word) - 2):
    print(word[i:i + 3])
:::

:::example title="The pair of digits with the biggest sum" try=3829461
digits = input("Digits: ")
best = -1
best_at = 0
for i in range(len(digits) - 1):
    s = int(digits[i]) + int(digits[i + 1])
    if s > best:
        best = s
        best_at = i
print(digits[best_at:best_at + 2], "add up to", best)
:::

Windows are how spell checkers suggest corrections, how DNA sequences are searched, and how you spot the hottest week in a year of temperature readings.

## Line by line

Text often has several **lines**. Inside a string, a line break is the single character `\n`. A string written with three quotes can span lines directly:

:::example
poem = """Roses are red,
Violets are blue,
Python is fun,
And so are you."""
print(len(poem.splitlines()), "lines")
for line in poem.splitlines():
    print(len(line), line)
:::

`.splitlines()` splits at every line break and returns the lines without the `\n` characters. Each line is an ordinary string: you can split it into words, strip it, search it.

:::example title="The longest line, and its number"
text = """first line
the second is longer
short
fourth"""
best = ""
best_n = 0
n = 0
for line in text.splitlines():
    n += 1
    if len(line) > len(best):
        best = line
        best_n = n
print("Line", best_n, "is longest:", best)
:::

Next week's files, and every log file and data file you'll ever read, are handled this way: one line at a time.

## Counting every letter

How often does each letter appear in a text? With what you know now, loop over the alphabet and count each letter:

:::example title="Letter frequencies"
text = "the quick brown fox jumps over the lazy dog"
for letter in "abcdefghijklmnopqrstuvwxyz":
    n = text.count(letter)
    if n > 1:
        print(letter, "#" * n)
:::

(That sentence uses every letter of the alphabet at least once. A sentence like that is called a **pangram**.)

In Week 10 you'll meet dictionaries, which make counting anything much easier. For letters, the alphabet loop is fine.

### Anagrams

Two words are **anagrams** if they use exactly the same letters the same number of times: `listen` and `silent`. With letter counts, the check is simple: the words are anagrams when every letter has the same count in both.

:::example title="Anagram check" try=Listen,Silent
a = input("First: ").lower()
b = input("Second: ").lower()
same = len(a) == len(b)
for letter in "abcdefghijklmnopqrstuvwxyz":
    if a.count(letter) != b.count(letter):
        same = False
        break
print("Anagrams" if same else "Not anagrams")
:::

## Checking a format

Many strings must follow a fixed **format**: a time like `14:05`, a postcode, a product code. Checking one means checking its length, then each part:

:::example title="Is it a valid 24-hour time?" try=23:59
t = input("Time (HH:MM): ")
ok = (len(t) == 5 and t[2] == ":" and t[:2].isdigit() and t[3:].isdigit()
      and int(t[:2]) <= 23 and int(t[3:]) <= 59)
print("Valid" if ok else "Invalid")
:::

Notice the brackets around the long condition: inside brackets, Python lets you continue on the next line. And notice the order: the length is checked first, so the slices are safe, and `.isdigit()` is checked before `int()`, so it can't crash. Short-circuit evaluation from Week 2 is doing real work here.

:::tip
Check a format from the outside in: the length first, then the fixed characters (like `:`), then each part's kind, and only then its value.
:::

## Daily challenge

:::exercise id=challenge points=25 title="Challenge: word wrap"
Text editors **wrap** long lines so they fit a width. Ask for a paragraph with the prompt `Text: ` and a width with the prompt `Width: `, and print the text wrapped: put as many whole words on each line as fit within the width (counting single spaces between words), then start a new line. A word longer than the width goes on a line of its own.

```
Text: the quick brown fox jumps over the lazy dog
Width: 10
the quick
brown fox
jumps over
the lazy
dog
```
@@starter

@@tests
def wrap(text, w):
    lines, cur = [], ""
    for word in text.split():
        if cur == "":
            cur = word
        elif len(cur) + 1 + len(word) <= w:
            cur += " " + word
        else:
            lines.append(cur)
            cur = word
    if cur:
        lines.append(cur)
    return "\n".join(lines)
def test_cases():
    "several wraps"
    for t, w in [("the quick brown fox jumps over the lazy dog", 10), ("a b c d e f g", 3), ("supercalifragilistic is long", 8), ("fits on one line", 40)]:
        expect_output(f"Text: {t}\nWidth: {w}\n" + wrap(t, w), inputs=[t, str(w)], echo=True)
@@hint
Keep the current line in a string. For each word: if the line is empty, the word starts it. Otherwise, if the line plus a space plus the word fits, add them; if not, print the line and start a new one with the word.
@@hint
After the loop, print the last line if there is one.
@@solution
text = input("Text: ")
width = int(input("Width: "))
line = ""
for word in text.split():
    if line == "":
        line = word
    elif len(line) + 1 + len(word) <= width:
        line += " " + word
    else:
        print(line)
        line = word
if line:
    print(line)
:::
